# 离子键与离子化合物

## 定义

**化学键**：相邻原子或离子之间强烈的相互作用，称为化学键。

**离子键**：阴离子与阳离子之间通过静电作用（既有吸引又有排斥，达到平衡时稳定）所形成的化学键。

**离子化合物**：由离子键构成的化合物。

## 核心内容

### 1. 离子键的形成条件

活泼金属与活泼非金属化合时，容易形成离子键：
- 活泼金属：通常为第ⅠA族（Li、Na、K等）、第ⅡA族（Mg、Ca等）
- 活泼非金属：通常为第ⅥA族（O、S等）、第ⅦA族（F、Cl、Br等）

本质：原子间电负性差值大，发生电子转移。

### 2. NaCl的形成过程

$$\text{Na}(2,8,1) \xrightarrow{\text{失去1个}e^-} \text{Na}^+(2,8)$$

$$\text{Cl}(2,8,7) \xrightarrow{\text{得到1个}e^-} \text{Cl}^-(2,8,8)$$

$\text{Na}^+$ 与 $\text{Cl}^-$ 通过静电引力结合形成 $\text{NaCl}$。

### 3. 用电子式表示NaCl的形成过程

$$\text{Na}^{\cdot} + \dot{\ddot{\text{Cl}}} \ddot{:} \longrightarrow \text{Na}^+ [\ddot{:}\ddot{\text{Cl}}\ddot{:}]^-$$

注意：离子化合物的电子式中，阴离子需加方括号并标注电荷。

### 4. 离子键的本质

离子键的本质是**静电作用**：
- 阴、阳离子之间既有静电**吸引**（异性电荷），也有静电**排斥**（电子云之间、原子核之间）
- 当吸引力与排斥力平衡时，体系能量最低，形成稳定结构

### 5. 离子化合物的性质

| 性质 | 说明 |
|------|------|
| 熔沸点 | 高（离子键强，需要大量能量破坏） |
| 硬度 | 较大 |
| 导电性 | 固态不导电；熔融或溶于水时可导电 |

导电原理：离子键被破坏 → 产生自由移动的离子 → 定向移动形成电流。

### 6. 典型离子化合物

- 强碱：$\text{NaOH}$、$\text{KOH}$、$\text{Ca(OH)}_2$
- 大多数盐：$\text{NaCl}$、$\text{KBr}$、$\text{MgF}_2$、$\text{Na}_2\text{SO}_4$
- 活泼金属氧化物：$\text{CaO}$、$\text{Na}_2\text{O}$

### 7. NaOH中的化学键

$\text{NaOH}$ 是离子化合物：
- $\text{Na}^+$ 与 $\text{OH}^-$ 之间：**离子键**
- $\text{OH}^-$ 内部 $\text{O}$ 与 $\text{H}$ 之间：**共价键**

这说明离子化合物中也可以存在共价键。

## 例题

<details>
<summary>例题1：判断化学键类型</summary>

**题目**：下列化合物中，含有离子键的是（  ）
A. $\text{HCl}$　B. $\text{H}_2\text{O}$　C. $\text{CaCl}_2$　D. $\text{CO}_2$

**解析**：
- A. HCl：非金属与非金属 → 共价键
- B. H₂O：非金属与非金属 → 共价键
- C. CaCl₂：活泼金属Ca与活泼非金属Cl → 离子键 ✓
- D. CO₂：非金属与非金属 → 共价键

**答案**：C

</details>

<details>
<summary>例题2：用电子式表示离子化合物的形成</summary>

**题目**：用电子式表示 $\text{MgCl}_2$ 的形成过程。

**解析**：
- Mg原子最外层2个电子，失去后形成 $\text{Mg}^{2+}$
- 2个Cl原子各得1个电子，形成 $\text{Cl}^-$

$$\dot{\text{Mg}} \dot{} + 2\dot{\ddot{\text{Cl}}}\ddot{:} \longrightarrow \text{Mg}^{2+}[\ddot{:}\ddot{\text{Cl}}\ddot{:}]^- _2$$

**要点**：
- 阳离子直接写离子符号（不加方括号）
- 阴离子需要加方括号并标注电荷
- 形成过程用箭头连接，不用等号

</details>

<details>
<summary>例题3：解释离子化合物导电性</summary>

**题目**：NaCl固体不导电，但NaCl溶液能导电，请从化学键角度解释。

**解析**：
- NaCl固体中，$\text{Na}^+$ 和 $\text{Cl}^-$ 通过离子键结合，离子被束缚在晶格位置，不能自由移动，故不导电。
- NaCl溶于水时，水分子破坏了 $\text{Na}^+$ 与 $\text{Cl}^-$ 之间的离子键，产生可自由移动的 $\text{Na}^+$ 和 $\text{Cl}^-$，在电场作用下定向移动，形成电流。

$$\text{NaCl} \xrightarrow{\text{H}_2\text{O}} \text{Na}^+ + \text{Cl}^-$$

</details>

## 易错点

1. **离子键 ≠ 只有吸引力**：离子键的本质是静电作用，包含吸引和排斥的平衡，不能片面说是"吸引力"。

2. **铵盐是离子化合物**：$\text{NH}_4\text{Cl}$ 虽不含金属元素，但 $\text{NH}_4^+$ 与 $\text{Cl}^-$ 之间是离子键，属于离子化合物。

3. **电子式书写错误**：
   - 阴离子忘加方括号和电荷
   - 形成过程中错用等号代替箭头
   - 忘记标出Cl等原子未参与成键的孤对电子

4. **离子化合物不一定只含离子键**：如 $\text{NaOH}$ 中既有离子键（Na⁺与OH⁻之间）又有共价键（O-H之间）。

5. **活泼金属+活泼非金属不是绝对规则**：$\text{AlCl}_3$ 虽为金属与非金属组成，但实际上是共价化合物（Al的极化作用强）。
