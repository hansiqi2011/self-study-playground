# 原子结构示意图与电子式

## 定义

**原子结构示意图**是用圆圈、弧线和数字表示原子核外电子排布的简化图示。**电子式**（Lewis结构）是在元素符号周围用小黑点或叉号表示最外层电子的化学表示方法。

## 核心内容

### 原子结构示意图

原子结构示意图由三部分组成：

1. **圆圈**：代表原子核，圈内写 $+Z$（$Z$ 为质子数/核电荷数）
2. **弧线**：代表各电子层，由内到外依次排列
3. **数字**：标注在弧线上，表示该层电子数

示例：
- Na（$Z=11$）：圆圈内 $+11$，三条弧线分别标注 2, 8, 1
- Cl（$Z=17$）：圆圈内 $+17$，三条弧线分别标注 2, 8, 7

### 电子式的书写规则

1. **原子的电子式**：元素符号周围用 $\cdot$ 或 $\times$ 表示**最外层电子**
   - 先在上、下、左、右四个方向各放一个电子（单电子）
   - 超过4个后再配对
   - 例：$\text{Na}$ 的电子式为 $\cdot\text{Na}$（1个点）；$\text{Cl}$ 的电子式为 $:\!\overset{..}{\text{Cl}}\!\cdot$（7个点）

2. **阳离子的电子式**：直接写离子符号
   - $\text{Na}^+$、$\text{Mg}^{2+}$、$\text{Al}^{3+}$

3. **阴离子的电子式**：加方括号并标注负电荷
   - $[\!:\!\overset{..}{\text{Cl}}\!:\!]^-$、$[\!:\!\overset{..}{\text{O}}\!:\!]^{2-}$

### 稳定结构的判断

原子达到稳定结构的条件：
- 最外层电子数 = 8（对K层为最外层的情况，= 2）
- 稀有气体的电子排布即为稳定结构

### 重要得失电子实例

$$\text{Na}(2, 8, 1) \xrightarrow{-1e^-} \text{Na}^+(2, 8)$$
$$\text{Cl}(2, 8, 7) \xrightarrow{+1e^-} \text{Cl}^-(2, 8, 8)$$

- Na失去1个最外层电子后，次外层变为最外层（8电子），达稳定结构
- Cl得到1个电子后，最外层达到8电子，达稳定结构

### 等电子微粒（10电子与18电子）

**10电子微粒族**（与Ne电子排布相同）：

| 类别 | 微粒 |
|---|---|
| 原子 | Ne |
| 阳离子 | $\text{Na}^+$, $\text{Mg}^{2+}$, $\text{Al}^{3+}$, $\text{NH}_4^+$, $\text{H}_3\text{O}^+$ |
| 阴离子 | $\text{O}^{2-}$, $\text{F}^-$ |
| 分子 | $\text{NH}_3$, $\text{H}_2\text{O}$, $\text{HF}$, $\text{CH}_4$ |

**18电子微粒族**（与Ar电子排布相同）：

| 类别 | 微粒 |
|---|---|
| 原子 | Ar |
| 阳离子 | $\text{K}^+$, $\text{Ca}^{2+}$ |
| 阴离子 | $\text{Cl}^-$, $\text{S}^{2-}$ |
| 分子 | $\text{H}_2\text{S}$, $\text{HCl}$, $\text{PH}_3$, $\text{SiH}_4$ |

### 电子式与结构示意图的对比

| 项目 | 原子结构示意图 | 电子式 |
|---|---|---|
| 表示内容 | 全部电子层的电子分布 | 仅最外层电子 |
| 关注重点 | 电子分层排布情况 | 成键能力与化学性质 |
| 适用对象 | 原子 | 原子、离子、分子 |

## 例题

<details>
<summary>例题1：画出原子结构示意图并判断稳定性</summary>

**题目**：画出 $\text{O}$（$Z=8$）和 $\text{Ar}$（$Z=18$）的原子结构示意图，并判断其是否具有稳定结构。

**解析**：

- O（$Z=8$）：电子排布为 2, 6。最外层6个电子 $\neq 8$，**不是**稳定结构。O原子倾向得到2个电子形成 $\text{O}^{2-}$（2, 8）。
- Ar（$Z=18$）：电子排布为 2, 8, 8。最外层8个电子，**是**稳定结构。Ar为稀有气体，化学性质稳定。

**答案**：O不具有稳定结构；Ar具有稳定结构。

</details>

<details>
<summary>例题2：书写电子式</summary>

**题目**：写出下列微粒的电子式：
- (1) $\text{S}$ 原子
- (2) $\text{Ca}^{2+}$
- (3) $\text{S}^{2-}$

**解析**：

(1) S原子最外层6个电子，先在四个方向各放1个，剩余2个配对：
$$:\!\overset{..}{\text{S}}\!\cdot\!\cdot$$
即上下各一对（2个），左右各一个单电子。

(2) $\text{Ca}^{2+}$ 为阳离子，电子式直接写离子符号：$\text{Ca}^{2+}$

(3) $\text{S}^{2-}$ 为阴离子（最外层8个电子），需加方括号标电荷：
$$[\!:\!\overset{..}{\text{S}}\!:\!]^{2-}$$

**答案**：如上所示。

</details>

<details>
<summary>例题3：等电子微粒的判断</summary>

**题目**：下列微粒中，与 $\text{F}^-$ 具有相同电子数的是（  ）
- A. $\text{Na}^+$
- B. $\text{Cl}^-$
- C. $\text{N}^{3-}$
- D. $\text{Ar}$

**解析**：
- $\text{F}^-$：$Z=9$，得1个电子，电子数 = $9 + 1 = 10$
- A. $\text{Na}^+$：$Z=11$，失1个电子，电子数 = $11 - 1 = 10$ ✓
- B. $\text{Cl}^-$：$Z=17$，得1个电子，电子数 = $17 + 1 = 18$ ✗
- C. $\text{N}^{3-}$：$Z=7$，得3个电子，电子数 = $7 + 3 = 10$ ✓
- D. $\text{Ar}$：$Z=18$，电子数 = $18$ ✗

**答案**：AC

</details>

## 易错点

1. **阳离子电子式不加括号**：$\text{Na}^+$ 直接写符号，不需画电子点；而阴离子如 $[\!:\!\overset{..}{\text{Cl}}\!:\!]^-$ 必须加方括号和电荷。
2. **电子式中电子的分布**：最外层电子先单占四个方向，超过4个再配对，不能全部画在同一侧。
3. **等电子微粒的计算**：阳离子电子数 = $Z - \text{电荷数}$，阴离子电子数 = $Z + \text{电荷数}$，多原子离子需加上所有原子的电子再加减电荷。
4. **结构示意图中圆圈内写的是核电荷数**（带+号），不是质量数，不能写成 $+23$（Na的质量数）而应写 $+11$（核电荷数）。
5. **10电子微粒中 $\text{NH}_4^+$ 和 $\text{H}_3\text{O}^+$ 易遗漏**：$\text{NH}_4^+$ 电子数 = $7 + 4 \times 1 - 1 = 10$；$\text{H}_3\text{O}^+$ 电子数 = $8 + 3 \times 1 - 1 = 10$。
