# 物质的量浓度与配制溶液

## 定义

**物质的量浓度** $c_B$：单位体积溶液中所含溶质 B 的物质的量。

$$c_B = \frac{n_B}{V}$$

- $c_B$：物质的量浓度，单位 $\text{mol·L}^{-1}$
- $n_B$：溶质 B 的物质的量，单位 $\text{mol}$
- $V$：溶液体积，单位 $\text{L}$

**示例**：将 58.5 g NaCl（$M = 58.5\ \text{g·mol}^{-1}$）溶解配成 1 L 溶液：

$$c = \frac{n}{V} = \frac{58.5/58.5}{1} = 1\ \text{mol·L}^{-1}$$

## 核心内容

### 容量瓶

配制**一定体积、一定浓度**溶液的专用量器。

| 特征 | 说明 |
|------|------|
| 规格 | 50 mL、100 mL、250 mL、500 mL、1000 mL |
| 细颈设计 | 减小液面读数误差 |
| 标注 20°C | 温度影响液体体积，在标定温度下使用 |

### 配制步骤（以 100 mL $1.000\ \text{mol·L}^{-1}$ NaCl 为例）

1. **计算**：$m = c \times V \times M = 1.000 \times 0.1 \times 58.5 = 5.850\ \text{g}$
2. **称量**：电子天平称取 5.850 g NaCl
3. **溶解**：在烧杯中加适量蒸馏水溶解，玻璃棒搅拌，**冷却至室温**
4. **转移**：沿玻璃棒将溶液转入 100 mL 容量瓶
5. **洗涤**：用蒸馏水洗涤烧杯和玻璃棒 2-3 次，洗涤液全部转入容量瓶
6. **定容**：加蒸馏水至刻度线下 1-2 cm，改用**胶头滴管**逐滴加水，至凹液面最低点与刻度线相切
7. **摇匀**：盖好瓶塞，上下颠倒摇匀

### 稀释公式

稀释前后溶质物质的量不变：

$$c_1 V_1 = c_2 V_2$$

## 例题

<details>
<summary>配制 100 mL 0.1000 mol/L NaOH 溶液，已有 2.000 mol/L NaOH 溶液，需量取多少 mL？</summary>

**解**：由稀释公式 $c_1V_1 = c_2V_2$：

$$V_1 = \frac{c_2 V_2}{c_1} = \frac{0.1000 \times 100}{2.000} = 5.00\ \text{mL}$$

**操作**：用量筒（或移液管）量取 5.00 mL 2.000 mol/L NaOH 溶液，转入 100 mL 容量瓶中，加蒸馏水定容至刻度线。

</details>

## 易错点

1. 容量瓶**只能配制其标定体积**的溶液（如 100 mL 容量瓶只能配 100 mL），不能量取任意体积
2. 转移前溶液必须**冷却至室温**——热溶液体积膨胀，冷却后体积缩小导致浓度偏高
3. 定容时**俯视**刻度线 → 液面实际偏低 → 浓度**偏高**；**仰视** → 液面实际偏高 → 浓度**偏低**
4. **不能在容量瓶中溶解固体或稀释浓酸**——放热导致瓶体受热变形，影响精度
5. 洗涤液**必须全部转入**容量瓶——否则溶质损失，浓度偏低
