# 物质的制备

## 定义

物质的制备是指通过化学反应或物理方法，从原料出发合成目标物质的过程。实验室制备需要综合考虑原料选择、反应路径设计、条件控制及产品分离。

## 核心内容

### 制备原则

- 原料易得
- 原理绿色（减少污染）
- 条件温和（常温常压优先）
- 装置简单
- 分离方便

### 制备流程

$$\text{选择原料} \rightarrow \text{设计反应路径} \rightarrow \text{控制反应条件} \rightarrow \text{分离提纯产品}$$

### 实验安全

- 遵守实验规则，谨慎处理易燃、易爆、有毒、有腐蚀性物质
- 化学品安全标识（GHS）：爆炸物、易燃、氧化性、加压气体、毒性、腐蚀等

### 气体制备装置

气体制备装置通常包括四部分：

1. **发生装置**：产生目标气体
2. **净化装置**：除去杂质气体和水蒸气
3. **收集装置**：排水集气法或向上/向下排空气法
4. **尾气处理装置**：防止有毒气体排入空气

### 实验室制备氯气

反应原理：

$$\text{MnO}_2 + 4\text{HCl}(\text{浓}) \xrightarrow{\Delta} \text{MnCl}_2 + \text{Cl}_2\uparrow + 2\text{H}_2\text{O}$$

尾气处理（用 NaOH 溶液吸收）：

$$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

## 例题

<details>
<summary>设计实验室制取纯净干燥氯气的装置连接顺序</summary>

**装置顺序：** 发生 → 除杂 → 干燥 → 收集 → 尾气处理

1. **发生装置**：圆底烧瓶中放 $\text{MnO}_2$，分液漏斗中盛浓盐酸，加热
2. **除杂装置**：饱和食盐水（除去 HCl 气体）
3. **干燥装置**：浓硫酸（除去水蒸气）
4. **收集装置**：向上排空气法（$\text{Cl}_2$ 密度大于空气）
5. **尾气处理**：NaOH 溶液吸收多余 $\text{Cl}_2$

**关键要点**：饱和食盐水既能除 HCl 又不大量吸收 $\text{Cl}_2$（因为已被 NaCl 饱和）。

</details>

## 易错点

1. 加热制备气体时**先检查装置气密性**再加药品，否则漏气导致实验失败
2. 收集气体前需**排尽装置内空气**，否则产品不纯
3. **尾气处理不能省略**——$\text{Cl}_2$ 有毒，直接排放污染环境且危害健康
4. 浓盐酸随反应进行变稀后反应会停止（稀盐酸不能被 $\text{MnO}_2$ 氧化）
