# 溴和碘的提取方法

## 定义

溴和碘在自然界中以离子形式（$\text{Br}^-$、$\text{I}^-$）存在于海水、盐湖水及海洋生物中。工业提取的核心思路为：**富集 → 氧化 → 分离**。

## 核心内容

### 从海水中提溴

1. **浓缩（富集）**：海水晒盐后得到的苦卤中 $\text{Br}^-$ 浓度已显著提高
2. **氧化**：向苦卤中通入 $\text{Cl}_2$，将 $\text{Br}^-$ 氧化为 $\text{Br}_2$

$$\text{Cl}_2 + 2\text{Br}^- \rightarrow 2\text{Cl}^- + \text{Br}_2$$

3. **提取（吹出）**：鼓入热空气或水蒸气 → $\text{Br}_2$ 随蒸气逸出 → 冷凝得粗溴
4. **精制**：
   - 用 $\text{SO}_2$ 水溶液吸收粗溴（将 $\text{Br}_2$ 还原为 $\text{HBr}$）：

$$\text{Br}_2 + \text{SO}_2 + 2\text{H}_2\text{O} \rightarrow 2\text{HBr} + \text{H}_2\text{SO}_4$$

   - 再次通入 $\text{Cl}_2$ 氧化 $\text{HBr}$ 为 $\text{Br}_2$
   - 蒸馏得纯 $\text{Br}_2$

### 从海带中提碘

1. **灼烧**：将干海带灼烧灰化
2. **浸泡**：用水浸泡灰烬，$\text{I}^-$ 进入溶液，过滤得含 $\text{I}^-$ 的滤液
3. **氧化**：向滤液中通入 $\text{Cl}_2$，将 $\text{I}^-$ 氧化为 $\text{I}_2$

$$\text{Cl}_2 + 2\text{I}^- \rightarrow 2\text{Cl}^- + \text{I}_2$$

4. **分离**：用 $\text{CCl}_4$ 萃取 $\text{I}_2$（$\text{I}_2$ 在 $\text{CCl}_4$ 中溶解度远大于水中），或用离子交换法提取

### 核心思路对比

| 步骤 | 提溴 | 提碘 |
|------|------|------|
| 富集 | 苦卤（晒盐副产物） | 海带灼烧→水浸 |
| 氧化 | $\text{Cl}_2$ 氧化 $\text{Br}^-$ | $\text{Cl}_2$ 氧化 $\text{I}^-$ |
| 分离 | 吹出 + 冷凝 | $\text{CCl}_4$ 萃取 |

## 例题

<details>
<summary>例题 1：提溴流程分析</summary>

**题目**：工业提溴流程中，为什么先用 $\text{SO}_2$ 水溶液吸收粗溴，再用 $\text{Cl}_2$ 重新氧化？

**解答**：

第一次吹出得到的粗溴含有水蒸气和其他杂质。用 $\text{SO}_2$ 水溶液吸收 $\text{Br}_2$，将其还原为 $\text{HBr}$ 溶液：

$$\text{Br}_2 + \text{SO}_2 + 2\text{H}_2\text{O} \rightarrow 2\text{HBr} + \text{H}_2\text{SO}_4$$

这一步实现了**再次富集**（$\text{Br}$ 元素以 $\text{HBr}$ 形式集中在溶液中）。

再通 $\text{Cl}_2$ 氧化并蒸馏，即可获得高纯度 $\text{Br}_2$。

本质：通过"氧化 → 还原 → 再氧化"的循环实现纯化。

</details>

## 易错点

1. 提取溴用的氧化剂是 $\text{Cl}_2$（活泼性强于 $\text{Br}_2$，能将 $\text{Br}^-$ 氧化）
2. $\text{SO}_2$ 在吸收粗溴步骤中作**还原剂**（将 $\text{Br}_2$ 还原为 $\text{HBr}$），$\text{SO}_2$ 本身被氧化为 $\text{H}_2\text{SO}_4$
3. 不直接从海水提碘——$\text{I}^-$ 在海水中浓度极低（约 $0.05\,\text{mg/L}$），需通过海带等海洋生物**富集**后再提取
4. 萃取碘时 $\text{CCl}_4$（四氯化碳）密度大于水，有机层在**下层**
