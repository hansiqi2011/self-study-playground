# 次氯酸与次氯酸盐

## 定义

次氯酸（$\text{HClO}$）是氯元素 +1 价的含氧酸，是一种弱酸和强氧化剂；次氯酸盐（如 $\text{NaClO}$、$\text{Ca(ClO)}_2$）是其对应的盐类，广泛用于漂白和消毒。

## 核心内容

### 次氯酸（HClO）

| 性质 | 说明 |
|------|------|
| 酸性 | 弱酸（弱于碳酸） |
| 氧化性 | 强氧化性，能漂白有机色素、杀菌消毒 |
| 稳定性 | 不稳定，光照易分解 |

光照分解：

$$2\text{HClO} \xrightarrow{\text{光照}} 2\text{HCl} + \text{O}_2\uparrow$$

> $\text{HClO}$ 既是氧化剂又是还原剂（歧化的逆过程——归中反应）

### 次氯酸钠（NaClO）

- 制备：$\text{Cl}_2$ 与 $\text{NaOH}$ 反应

$$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

- 比 $\text{HClO}$ 稳定，水溶液显碱性
- **84 消毒液**的主要有效成分为 $\text{NaClO}$

### 漂白粉

- 制备：$\text{Cl}_2$ 与 $\text{Ca(OH)}_2$ 反应

$$2\text{Cl}_2 + 2\text{Ca(OH)}_2 \rightarrow \text{CaCl}_2 + \text{Ca(ClO)}_2 + 2\text{H}_2\text{O}$$

- **组成**：$\text{CaCl}_2$ 和 $\text{Ca(ClO)}_2$ 的混合物
- **有效成分**：$\text{Ca(ClO)}_2$（提供 $\text{ClO}^-$ 发挥漂白杀菌作用）

### 漂白粉的失效

漂白粉在空气中吸收 $\text{CO}_2$ 和水分会缓慢失效：

$$\text{Ca(ClO)}_2 + \text{CO}_2 + \text{H}_2\text{O} \rightarrow \text{CaCO}_3\downarrow + 2\text{HClO}$$

> 生成的 $\text{HClO}$ 不稳定，继续分解为 $\text{HCl}$ 和 $\text{O}_2$，最终漂白粉完全失效。因此应**密封避光保存**。

### 漂白粉与酸反应

加入盐酸可加速释放 $\text{HClO}$（增强漂白效果）：

$$\text{Ca(ClO)}_2 + 2\text{HCl} \rightarrow \text{CaCl}_2 + 2\text{HClO}$$

> 原理：强酸制弱酸（$\text{HCl}$ 酸性强于 $\text{HClO}$）

## 例题

<details>
<summary>解释为什么漂白粉需要密封保存，且使用时常加入少量稀盐酸</summary>

**解答**：

**密封保存的原因**：

漂白粉中的有效成分 $\text{Ca(ClO)}_2$ 会与空气中的 $\text{CO}_2$ 和水反应：

$$\text{Ca(ClO)}_2 + \text{CO}_2 + \text{H}_2\text{O} \rightarrow \text{CaCO}_3\downarrow + 2\text{HClO}$$

$$2\text{HClO} \xrightarrow{\text{光照}} 2\text{HCl} + \text{O}_2\uparrow$$

有效成分逐渐分解消耗，漂白粉失效。

**使用时加稀盐酸的原因**：

$$\text{Ca(ClO)}_2 + 2\text{HCl} \rightarrow \text{CaCl}_2 + 2\text{HClO}$$

加入盐酸后，利用强酸制弱酸原理，使 $\text{Ca(ClO)}_2$ 转化为 $\text{HClO}$，$\text{HClO}$ 直接发挥漂白杀菌作用，效果更快更强。

</details>

## 易错点

1. 漂白粉是**混合物**（$\text{CaCl}_2$ 和 $\text{Ca(ClO)}_2$ 的混合物）不是纯净物
2. 漂白粉的有效成分是 $\text{Ca(ClO)}_2$ **不是** $\text{CaCl}_2$——$\text{CaCl}_2$ 没有漂白能力
3. 漂白粉应**密封避光保存**——防止与空气中 $\text{CO}_2$、$\text{H}_2\text{O}$ 反应以及 $\text{HClO}$ 光照分解
4. 84 消毒液的主要成分是 $\text{NaClO}$——不能与酸性清洁剂（如洁厕灵含 $\text{HCl}$）混用，否则产生有毒 $\text{Cl}_2$：$\text{NaClO} + 2\text{HCl} \rightarrow \text{NaCl} + \text{Cl}_2\uparrow + \text{H}_2\text{O}$
