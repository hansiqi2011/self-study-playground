# 氯气的性质

## 定义

氯气（$\text{Cl}_2$）是一种黄绿色、有刺激性气味的有毒气体，化学性质活泼，是重要的化工原料和强氧化剂。

## 核心内容

### 物理性质

| 性质 | 数值 |
|------|------|
| 颜色与状态 | 黄绿色气体，有刺激性气味 |
| 密度 | $2.98 \text{ g/L}$（比空气大） |
| 液化温度 | $-34.6°\text{C}$ |
| 固化温度 | $-101°\text{C}$ |
| 水溶性 | 1 体积水约溶解 2 体积 $\text{Cl}_2$ |
| 毒性 | 有毒，能损伤呼吸道 |

### 与金属反应

$\text{Cl}_2$ 与多数金属反应（体现强氧化性，将金属氧化为高价态）：

$$2\text{Fe} + 3\text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{FeCl}_3$$

> 铁在 $\text{Cl}_2$ 中燃烧，产生**棕黄色烟**

$$2\text{Na} + \text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{NaCl}$$

$$\text{Cu} + \text{Cl}_2 \xrightarrow{\text{点燃}} \text{CuCl}_2$$

### 与非金属反应

$$\text{H}_2 + \text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{HCl}$$

> 纯净 $\text{H}_2$ 在 $\text{Cl}_2$ 中燃烧：**苍白色火焰**
> $\text{H}_2$ 和 $\text{Cl}_2$ 混合气体光照：**爆炸**

### 与水反应

$$\text{Cl}_2 + \text{H}_2\text{O} \rightleftharpoons \text{HCl} + \text{HClO}$$

这是一个**可逆反应**，氯水（$\text{Cl}_2$ 的水溶液）中含有：

- **分子**：$\text{Cl}_2$、$\text{H}_2\text{O}$、$\text{HClO}$
- **离子**：$\text{H}^+$、$\text{Cl}^-$、$\text{ClO}^-$、$\text{OH}^-$

### 与碱反应

$$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

> 实验室用 $\text{NaOH}$ 溶液进行**尾气处理**，防止多余 $\text{Cl}_2$ 污染空气。

$$2\text{Cl}_2 + 2\text{Ca(OH)}_2 \rightarrow \text{CaCl}_2 + \text{Ca(ClO)}_2 + 2\text{H}_2\text{O}$$

> 工业制漂白粉

### 干燥 Cl₂ 与漂白

- **干燥** $\text{Cl}_2$（不含水）**不能漂白**有色布条
- 湿润的 $\text{Cl}_2$ 能漂白——因为 $\text{Cl}_2$ 与水反应生成 $\text{HClO}$，$\text{HClO}$ 才是漂白的有效物质
- 漂白原理：$\text{HClO}$ 的强氧化性破坏有机色素

## 例题

<details>
<summary>将干燥的Cl₂和湿润的Cl₂分别通入干燥的有色布条和湿润的有色布条，分析四种情况的现象</summary>

**分析**：

| 实验条件 | 现象 | 解释 |
|----------|------|------|
| 干燥 $\text{Cl}_2$ + 干燥布条 | 不褪色 | 无水无法生成 $\text{HClO}$ |
| 干燥 $\text{Cl}_2$ + 湿润布条 | 褪色 | 布条上的水与 $\text{Cl}_2$ 反应生成 $\text{HClO}$ |
| 湿润 $\text{Cl}_2$ + 干燥布条 | 褪色 | $\text{Cl}_2$ 中的水与 $\text{Cl}_2$ 反应生成 $\text{HClO}$ |
| 湿润 $\text{Cl}_2$ + 湿润布条 | 褪色 | 水充足，$\text{HClO}$ 充分生成 |

**结论**：起漂白作用的是 $\text{HClO}$ 而非 $\text{Cl}_2$ 本身，必须有水参与。

</details>

## 易错点

1. $\text{Fe}$ 在 $\text{Cl}_2$ 中燃烧生成 $\text{FeCl}_3$（**+3 价**）不是 $\text{FeCl}_2$——$\text{Cl}_2$ 氧化性强，将 Fe 氧化为最高价
2. **干燥** $\text{Cl}_2$ **不能漂白**有色布条——需要水的参与生成 $\text{HClO}$ 才能漂白
3. 氯水中起漂白作用的是 $\text{HClO}$（次氯酸）**不是** $\text{Cl}_2$
4. $\text{H}_2$ 与 $\text{Cl}_2$ 混合光照会**爆炸**，点燃则安静燃烧产生苍白色火焰——注意区分反应条件
5. 氯水是混合物，含有多种微粒；$\text{HClO}$ 是弱酸，电离程度小，所以氯水中仍存在 $\text{HClO}$ 分子
