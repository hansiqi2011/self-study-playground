# 电解饱和食盐水

## 定义

电解饱和食盐水（氯碱工业的核心反应）是在直流电作用下，将饱和 $\text{NaCl}$ 溶液分解为 $\text{NaOH}$、$\text{H}_2$ 和 $\text{Cl}_2$ 三种重要化工产品的过程。

## 核心内容

### 总反应方程式

$$2\text{NaCl} + 2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{NaOH} + \text{H}_2\uparrow + \text{Cl}_2\uparrow$$

### 电极反应

| 电极 | 反应 | 产物 |
|------|------|------|
| 阳极（+） | $2\text{Cl}^- - 2e^- \rightarrow \text{Cl}_2\uparrow$ | $\text{Cl}_2$（氯气） |
| 阴极（−） | $2\text{H}_2\text{O} + 2e^- \rightarrow \text{H}_2\uparrow + 2\text{OH}^-$ | $\text{H}_2$（氢气）和 $\text{OH}^-$ |

### 离子膜电解法

- 阳极室：饱和食盐水，$\text{Cl}^-$ 放电生成 $\text{Cl}_2$
- 阴极室：水电解生成 $\text{H}_2$ 和 $\text{OH}^-$，$\text{Na}^+$ 通过离子膜迁移至阴极室形成 $\text{NaOH}$
- **离子膜作用**：只允许 $\text{Na}^+$ 通过，阻止 $\text{Cl}^-$ 和 $\text{OH}^-$ 互相迁移，防止 $\text{Cl}_2$ 与 $\text{NaOH}$ 接触反应

### 氯碱工业三大产品及用途

| 产品 | 主要用途 |
|------|----------|
| $\text{Cl}_2$ | 制盐酸（$\text{HCl}$）、制聚氯乙烯（PVC）、消毒 |
| $\text{NaOH}$ | 造纸、制肥皂、炼铝、石油精炼 |
| $\text{H}_2$ | 清洁燃料、合成 $\text{HCl}$、加氢反应 |

## 例题

<details>
<summary>用离子膜电解法电解饱和食盐水，写出电极反应式并说明离子膜的作用</summary>

**解答**：

阳极反应（氧化）：

$$2\text{Cl}^- - 2e^- = \text{Cl}_2\uparrow$$

阴极反应（还原）：

$$2\text{H}_2\text{O} + 2e^- = \text{H}_2\uparrow + 2\text{OH}^-$$

总反应：

$$2\text{NaCl} + 2\text{H}_2\text{O} \xrightarrow{\text{电解}} 2\text{NaOH} + \text{H}_2\uparrow + \text{Cl}_2\uparrow$$

**离子膜的作用**：
- 允许 $\text{Na}^+$ 和水分子通过，阻止 $\text{Cl}^-$ 和 $\text{OH}^-$ 通过
- 隔开阳极产物 $\text{Cl}_2$ 和阴极产物 $\text{NaOH}$，防止它们反应生成 $\text{NaClO}$
- 获得高纯度 $\text{NaOH}$ 溶液

</details>

## 易错点

1. 电解的是**饱和食盐水**（溶液）而不是 $\text{NaCl}$ 固体——电解需要自由移动的离子，固体中离子不能自由移动
2. **离子膜的作用**是隔开阴阳极产物，防止 $\text{Cl}_2$ 和 $\text{NaOH}$ 直接反应（$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$）
3. $\text{H}_2$ 在**阴极**产生（不是阳极）——水在阴极得电子被还原
4. 阳极放电的是 $\text{Cl}^-$ 而不是 $\text{OH}^-$——虽然 $\text{OH}^-$ 放电能力更强，但饱和食盐水中 $\text{Cl}^-$ 浓度极高，实际优先放电
