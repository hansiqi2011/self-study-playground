# 电解质与电离

## 定义

- **电解质**：在水溶液中或熔融状态下能导电的**化合物**。
- **非电解质**：在水溶液中和熔融状态下均不能导电的**化合物**（如蔗糖、乙醇）。

> 注意：单质和混合物既不是电解质也不是非电解质——电解质/非电解质的讨论范围**仅限化合物**。

## 核心内容

### 导电的微观条件

物质导电需要存在**自由移动的带电粒子**（自由移动的离子或自由电子）。

| 物质状态 | 能否导电 | 原因 |
|---|---|---|
| $\text{NaCl}$ 固体 | 不能 | 离子被束缚在晶格中，不能自由移动 |
| $\text{NaCl}$ 水溶液 | 能 | 电离产生自由移动的 $\text{Na}^+$ 和 $\text{Cl}^-$ |
| 熔融 $\text{NaCl}$ | 能 | 高温破坏晶格，离子可自由移动 |

### 电离

电解质在水溶液中或熔融状态下产生**自由移动离子**的过程。

### 强电解质与弱电解质

| 类型 | 电离程度 | 举例 | 电离方程式符号 |
|---|---|---|---|
| 强电解质 | 完全电离 | 强酸、强碱、大多数盐 | $\rightarrow$ 或 $=$ |
| 弱电解质 | 部分电离（可逆） | 弱酸、弱碱、水 | $\rightleftharpoons$ |

### 电离方程式示例

$$\text{NaCl} \rightarrow \text{Na}^+ + \text{Cl}^-$$

$$\text{H}_2\text{SO}_4 \rightarrow 2\text{H}^+ + \text{SO}_4^{2-}$$

$$\text{NaOH} \rightarrow \text{Na}^+ + \text{OH}^-$$

$$\text{CH}_3\text{COOH} \rightleftharpoons \text{H}^+ + \text{CH}_3\text{COO}^-$$

## 例题

<details>
<summary>例题：判断下列物质是否为电解质：Cu、NaCl溶液、HCl气体、蔗糖</summary>

**分析**：

1. **Cu**：铜是单质，不是化合物 → **既不是电解质也不是非电解质**（不在讨论范围内）
2. **NaCl溶液**：溶液是混合物，不是化合物 → **既不是电解质也不是非电解质**（但其中的 $\text{NaCl}$ 是电解质）
3. **HCl气体**：$\text{HCl}$ 是化合物；虽然气态不导电，但溶于水后能完全电离导电 → **$\text{HCl}$ 是电解质**（强电解质）
4. **蔗糖**：化合物；在水溶液和熔融状态下均不导电 → **非电解质**

</details>

## 易错点

1. **电解质必须是化合物**——铜能导电但不是电解质（因为铜是单质）。
2. **$\text{NaCl}$ 溶液导电，但 $\text{NaCl}$ 溶液不是电解质**——$\text{NaCl}$ 才是电解质；溶液是混合物，不讨论电解质归属。
3. **$\text{HCl}$ 气体不导电，但 $\text{HCl}$ 是电解质**——判断电解质看的是"能否"在水溶液/熔融状态下导电，不是看当前状态。
4. 电离是物理过程还是化学过程不影响判断——离子化合物溶解是物理过程中电离，共价化合物（如 $\text{HCl}$）溶于水是化学变化中电离，但两者都是电解质。
