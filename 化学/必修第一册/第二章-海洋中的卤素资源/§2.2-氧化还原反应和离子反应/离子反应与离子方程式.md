# 离子反应与离子方程式

## 定义

**离子反应**：有离子参加或有离子生成的反应。在水溶液中进行的复分解反应和部分氧化还原反应都属于离子反应。

## 核心内容

### 离子反应发生的条件

生成下列产物之一即可发生（复分解反应的驱动力）：

1. **生成沉淀**：如 $\text{BaSO}_4\downarrow$、$\text{AgCl}\downarrow$、$\text{CaCO}_3\downarrow$
2. **生成气体**：如 $\text{CO}_2\uparrow$、$\text{H}_2\uparrow$、$\text{SO}_2\uparrow$
3. **生成弱电解质**：如 $\text{H}_2\text{O}$、$\text{CH}_3\text{COOH}$、$\text{NH}_3 \cdot \text{H}_2\text{O}$

### 离子方程式书写四步法

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1. 写 | 写出正确的化学方程式 | 确保配平 |
| 2. 拆 | 易溶强电解质拆成离子 | 难溶物、气体、弱电解质、单质**保留分子式** |
| 3. 删 | 删去两边相同的离子 | 即"旁观离子" |
| 4. 查 | 检查守恒 | **原子守恒 + 电荷守恒** |

### 示例

化学方程式：

$$\text{CaCO}_3 + 2\text{HCl} \rightarrow \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$

拆：$\text{CaCO}_3$（难溶，不拆）+ $2\text{H}^+ + 2\text{Cl}^-$ → $\text{Ca}^{2+} + 2\text{Cl}^-$ + $\text{H}_2\text{O}$（弱电解质，不拆）+ $\text{CO}_2\uparrow$（气体，不拆）

删去两边的 $2\text{Cl}^-$：

$$\text{CaCO}_3 + 2\text{H}^+ \rightarrow \text{Ca}^{2+} + \text{H}_2\text{O} + \text{CO}_2\uparrow$$

查：左边原子 Ca 1, C 1, O 3, H 2 ✓；左边电荷 $+2$，右边电荷 $+2$ ✓

### 经典离子方程式

**强酸 + 强碱**（生成可溶盐和水）的本质：

$$\text{H}^+ + \text{OH}^- \rightarrow \text{H}_2\text{O}$$

### 一个离子方程式代表一类反应

上述 $\text{H}^+ + \text{OH}^- \rightarrow \text{H}_2\text{O}$ 可以代表所有强酸与强碱生成可溶盐的中和反应，如：

- $\text{HCl} + \text{NaOH}$
- $\text{HNO}_3 + \text{KOH}$
- $\text{HCl} + \text{KOH}$

## 例题

<details>
<summary>例题：写出 $\text{Na}_2\text{CO}_3$ 溶液与稀盐酸反应的离子方程式</summary>

**解答**：

1. 写化学方程式：$\text{Na}_2\text{CO}_3 + 2\text{HCl} \rightarrow 2\text{NaCl} + \text{H}_2\text{O} + \text{CO}_2\uparrow$

2. 拆：$2\text{Na}^+ + \text{CO}_3^{2-} + 2\text{H}^+ + 2\text{Cl}^- \rightarrow 2\text{Na}^+ + 2\text{Cl}^- + \text{H}_2\text{O} + \text{CO}_2\uparrow$

3. 删去 $2\text{Na}^+$ 和 $2\text{Cl}^-$：

$$\text{CO}_3^{2-} + 2\text{H}^+ \rightarrow \text{H}_2\text{O} + \text{CO}_2\uparrow$$

4. 查：原子守恒 ✓；电荷左边 $-2+2=0$，右边 $0$ ✓

</details>

## 易错点

1. **难溶物不拆**：$\text{CaCO}_3$、$\text{BaSO}_4$、$\text{AgCl}$、$\text{Cu(OH)}_2$ 等沉淀保留分子式。
2. **弱电解质不拆**：$\text{H}_2\text{O}$、$\text{CH}_3\text{COOH}$、$\text{NH}_3 \cdot \text{H}_2\text{O}$ 保留分子式。
3. **浓 $\text{H}_2\text{SO}_4$ 不拆**：浓硫酸未完全电离，只有**稀硫酸**才拆成 $2\text{H}^+ + \text{SO}_4^{2-}$。
4. **电荷守恒容易被忽略**：写完后必须检查左右两边电荷总数相等。
5. **$\text{Cu(OH)}_2$ 是难溶物不拆**——虽然 $\text{NaOH}$、$\text{KOH}$ 可拆，但 $\text{Cu(OH)}_2$ 难溶，必须保留。
