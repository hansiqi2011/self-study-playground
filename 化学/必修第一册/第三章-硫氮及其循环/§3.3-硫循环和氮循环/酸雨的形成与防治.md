# 酸雨的形成与防治

## 定义

酸雨是指 $\text{pH} < 5.6$ 的大气降水。正常降水因溶解 $\text{CO}_2$ 而呈弱酸性，$\text{pH}$ 约为 $5.6 \sim 7$：

$$\text{CO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3$$

因此判断酸雨的标准是 $\text{pH} < 5.6$，而非 $\text{pH} < 7$。

## 核心内容

### 酸雨成因

**硫酸型酸雨**（主要由 $\text{SO}_2$ 引起）：

- 途径一：$\text{SO}_2$ 溶于水后被氧化

$$\text{SO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{SO}_3$$

$$2\text{H}_2\text{SO}_3 + \text{O}_2 \longrightarrow 2\text{H}_2\text{SO}_4$$

- 途径二：$\text{SO}_2$ 在大气中被催化氧化后溶于水

$$2\text{SO}_2 + \text{O}_2 \xrightarrow{\text{催化剂}} 2\text{SO}_3$$

$$\text{SO}_3 + \text{H}_2\text{O} \longrightarrow \text{H}_2\text{SO}_4$$

**硝酸型酸雨**（主要由 $\text{NO}_x$ 引起）：

$$\text{N}_2 + \text{O}_2 \xrightarrow{\text{高温}} 2\text{NO}$$

$$2\text{NO} + \text{O}_2 = 2\text{NO}_2$$

$$3\text{NO}_2 + \text{H}_2\text{O} = 2\text{HNO}_3 + \text{NO}$$

### 污染物来源

| 污染物 | 主要来源 |
|--------|----------|
| $\text{SO}_2$ | 化石燃料（煤、石油）燃烧、火山喷发、金属冶炼 |
| $\text{NO}_x$ | 汽车尾气（高温下 $\text{N}_2 + \text{O}_2 \to 2\text{NO}$）、工业燃烧 |

### 酸雨危害

1. **腐蚀建筑材料**：大理石（主要成分 $\text{CaCO}_3$）被酸雨溶解
$$\text{CaCO}_3 + \text{H}_2\text{SO}_4 \longrightarrow \text{CaSO}_4 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$
2. **腐蚀金属**：加速钢铁等金属的电化学腐蚀
3. **土壤酸化**：破坏植被，影响农作物生长
4. **水体酸化**：湖泊河流 $\text{pH}$ 下降，危害水生生物
5. **地下水酸化**：重金属离子（如 $\text{Al}^{3+}$、$\text{Pb}^{2+}$）溶出，危害人体健康

### 防治措施

- 使用低硫燃料或天然气替代高硫煤
- 煤的脱硫处理（燃烧前脱硫）
- 烟气脱硫（燃烧后脱硫），如用 $\text{CaO}$ 或 $\text{Ca(OH)}_2$ 吸收 $\text{SO}_2$：
$$\text{CaO} + \text{SO}_2 \longrightarrow \text{CaSO}_3$$
$$\text{Ca(OH)}_2 + \text{SO}_2 \longrightarrow \text{CaSO}_3 + \text{H}_2\text{O}$$
- 开发新能源（太阳能、风能、核能等）
- 安装尾气净化装置（汽车三元催化器将 $\text{NO}_x$ 还原为 $\text{N}_2$）

### 硫循环概述

硫在岩石圈、大气圈、水圈、生物圈之间循环：

- 火山喷发释放 $\text{SO}_2$ 和 $\text{H}_2\text{S}$ 进入大气
- 生物腐败产生 $\text{H}_2\text{S}$
- 大气中 $\text{SO}_2$ 经降水回到地表水和土壤
- 硫酸盐沉积形成含硫矿物（如石膏 $\text{CaSO}_4 \cdot 2\text{H}_2\text{O}$）

### 氮循环概述

$$\text{N}_2 \xrightarrow{\text{固氮}} \text{NH}_3 / \text{NO}_3^- \xrightarrow{\text{植物吸收}} \text{有机氮} \xrightarrow{\text{动物摄取}} \text{动物体内氮} \xrightarrow{\text{分解}} \text{NH}_4^+$$

- **硝化作用**：$\text{NH}_4^+ \xrightarrow{\text{硝化细菌氧化}} \text{NO}_3^-$（需氧条件）
- **反硝化作用**：$\text{NO}_3^- \xrightarrow{\text{反硝化细菌还原}} \text{N}_2$（缺氧条件）
- 固氮方式：生物固氮（根瘤菌）、工业固氮（合成氨）、高能固氮（闪电）

## 例题

<details>
<summary>例题1：酸雨成因分析</summary>

**题目**：某地区酸雨的 $\text{pH}$ 为 $4.2$，分析其中可能含有的酸性物质，并写出 $\text{SO}_2$ 转化为 $\text{H}_2\text{SO}_4$ 的两条途径的化学方程式。

**解答**：

酸雨中可能含有 $\text{H}_2\text{SO}_4$ 和 $\text{HNO}_3$。

途径一（液相氧化）：

$$\text{SO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{SO}_3$$

$$2\text{H}_2\text{SO}_3 + \text{O}_2 = 2\text{H}_2\text{SO}_4$$

途径二（气相催化氧化）：

$$2\text{SO}_2 + \text{O}_2 \xrightarrow{\text{催化剂}} 2\text{SO}_3$$

$$\text{SO}_3 + \text{H}_2\text{O} = \text{H}_2\text{SO}_4$$

</details>

<details>
<summary>例题2：脱硫反应计算</summary>

**题目**：某火电厂用 $\text{Ca(OH)}_2$ 浆液进行烟气脱硫，每天排放含 $\text{SO}_2$ 体积分数为 $0.2\%$ 的烟气 $1.0 \times 10^7 \text{ L}$（标准状况），求每天至少需要 $\text{Ca(OH)}_2$ 的质量。

**解答**：

$\text{SO}_2$ 的体积：$V(\text{SO}_2) = 1.0 \times 10^7 \times 0.2\% = 2.0 \times 10^4 \text{ L}$

$\text{SO}_2$ 的物质的量：$n(\text{SO}_2) = \dfrac{2.0 \times 10^4}{22.4} \approx 893 \text{ mol}$

由 $\text{Ca(OH)}_2 + \text{SO}_2 \to \text{CaSO}_3 + \text{H}_2\text{O}$ 知：

$$n(\text{Ca(OH)}_2) = n(\text{SO}_2) = 893 \text{ mol}$$

$$m(\text{Ca(OH)}_2) = 893 \times 74 \approx 66.1 \text{ kg}$$

</details>

<details>
<summary>例题3：氮循环判断</summary>

**题目**：下列关于氮循环的说法正确的是（　　）

A. 硝化作用是将 $\text{NO}_3^-$ 转化为 $\text{NH}_4^+$

B. 反硝化作用需要在缺氧条件下进行

C. 闪电固氮生成的是 $\text{NH}_3$

D. 所有植物都能进行生物固氮

**答案**：B

**解析**：

- A 错误：硝化作用是将 $\text{NH}_4^+$ 氧化为 $\text{NO}_3^-$，方向相反
- B 正确：反硝化细菌在缺氧条件下将 $\text{NO}_3^-$ 还原为 $\text{N}_2$
- C 错误：闪电固氮生成 $\text{NO}$，即 $\text{N}_2 + \text{O}_2 \xrightarrow{\text{放电}} 2\text{NO}$
- D 错误：只有豆科植物等具有根瘤菌的植物才能进行生物固氮

</details>

## 易错点

1. **酸雨判断标准**：酸雨的标准是 $\text{pH} < 5.6$，而不是 $\text{pH} < 7$。正常雨水因溶解 $\text{CO}_2$ 本身就呈弱酸性（$\text{pH} \approx 5.6$），只有酸性明显强于此的降水才称为酸雨。

2. **酸雨成因不只是 $\text{SO}_2$**：$\text{SO}_2$ 和 $\text{NO}_x$ 都是酸雨的成因气体，硝酸型酸雨在汽车尾气排放严重的地区尤为突出。

3. **大理石与花岗岩的区别**：大理石主要成分是 $\text{CaCO}_3$，能与酸反应被腐蚀；花岗岩主要成分是 $\text{SiO}_2$，不与一般酸反应（除 $\text{HF}$ 外），因此耐酸雨腐蚀。

4. **$\text{SO}_2$ 与 $\text{SO}_3$ 的区分**：$\text{SO}_2$ 溶于水生成 $\text{H}_2\text{SO}_3$（亚硫酸，弱酸），$\text{SO}_3$ 溶于水生成 $\text{H}_2\text{SO}_4$（硫酸，强酸），两者不可混淆。

5. **硝化与反硝化方向**：硝化作用是 $\text{NH}_4^+ \to \text{NO}_3^-$（氧化过程），反硝化是 $\text{NO}_3^- \to \text{N}_2$（还原过程），注意方向不要记反。
