# 氮的氧化物

## 定义

氮的氧化物是氮元素与氧元素形成的一系列化合物，常见的有 $\text{NO}$（一氧化氮）和 $\text{NO}_2$（二氧化氮）。它们是大气污染物，也是工业制硝酸的重要中间产物。

## 核心内容

### 一氧化氮（$\text{NO}$）

| 性质 | 描述 |
|------|------|
| 颜色气味 | **无色**气体，无味 |
| 毒性 | 有毒 |
| 溶解性 | 难溶于水 |
| 化合价 | N 为 $+2$ 价 |

关键反应——常温下极易被氧化：

$$2\text{NO} + \text{O}_2 = 2\text{NO}_2$$

**收集方法**：只能用**排水法**（不能用排空气法，因为 NO 在空气中立即被氧化为 $\text{NO}_2$）

### 二氧化氮（$\text{NO}_2$）

| 性质 | 描述 |
|------|------|
| 颜色气味 | **红棕色**气体，有刺激性气味 |
| 毒性 | 有毒 |
| 溶解性 | 易溶于水（与水反应） |
| 化合价 | N 为 $+4$ 价 |

与水反应（工业制硝酸原理之一）：

$$3\text{NO}_2 + \text{H}_2\text{O} = 2\text{HNO}_3 + \text{NO}$$

**收集方法**：**向上排空气法**（不能用排水法，因为 $\text{NO}_2$ 与水反应）

### NO 与 $\text{NO}_2$ 对比

| 比较项目 | $\text{NO}$ | $\text{NO}_2$ |
|---------|------------|--------------|
| 颜色 | 无色 | 红棕色 |
| 溶解性 | 难溶于水 | 易溶于水（与水反应） |
| 与 $\text{O}_2$ | 易被氧化 | — |
| 与 $\text{H}_2\text{O}$ | 不反应 | 反应生成 $\text{HNO}_3$ 和 NO |
| 收集 | 排水法 | 向上排空气法 |

### 转化链

$$\text{N}_2 \xrightarrow{\text{放电}} \text{NO} \xrightarrow{+\text{O}_2} \text{NO}_2 \xrightarrow{+\text{H}_2\text{O}} \text{HNO}_3$$

### 重要计算：$\text{NO}_2$ 与水完全反应

若要使 $\text{NO}_2$ 和水反应最终全部转化为硝酸（无 NO 剩余），需通入 $\text{O}_2$：

$$4\text{NO}_2 + \text{O}_2 + 2\text{H}_2\text{O} = 4\text{HNO}_3$$

$\text{NO}_2$、$\text{O}_2$ 和 $\text{H}_2\text{O}$ 以 $4:1:2$ 的物质的量之比恰好完全转化为硝酸。

## 例题

<details>
<summary>例题1：NO₂与水反应的计算</summary>

**题目：** 将 $1.12\ \text{L}$（标准状况）$\text{NO}_2$ 气体通入足量水中，求生成 $\text{HNO}_3$ 的物质的量和剩余气体的体积。

**解析：**

$n(\text{NO}_2) = \dfrac{1.12}{22.4} = 0.05\ \text{mol}$

由 $3\text{NO}_2 + \text{H}_2\text{O} = 2\text{HNO}_3 + \text{NO}$：

$$n(\text{HNO}_3) = \frac{2}{3} \times 0.05 = \frac{1}{30}\ \text{mol} \approx 0.033\ \text{mol}$$

$$n(\text{NO}) = \frac{1}{3} \times 0.05 = \frac{1}{60}\ \text{mol}$$

$$V(\text{NO}) = \frac{1}{60} \times 22.4 \approx 0.373\ \text{L}$$

**答案：** 生成 $\text{HNO}_3$ 约 $0.033\ \text{mol}$，剩余 NO 气体约 $0.373\ \text{L}$。
</details>

<details>
<summary>例题2：NO₂和O₂混合气体通入水中</summary>
</details>

**题目：** 将 $\text{NO}_2$ 和 $\text{O}_2$ 以体积比 $4:1$ 混合后通入足量水中，求反应后的产物。

**解析：**

当 $\text{NO}_2:\text{O}_2 = 4:1$ 时，恰好满足：

$$4\text{NO}_2 + \text{O}_2 + 2\text{H}_2\text{O} = 4\text{HNO}_3$$

此时 $\text{NO}_2$ 全部转化为 $\text{HNO}_3$，无 NO 生成，无气体剩余。

**答案：** 气体被完全吸收，产物只有 $\text{HNO}_3$。

**拓展：** 若 $V(\text{NO}_2):V(\text{O}_2) > 4:1$，则 $\text{O}_2$ 不足，会有 NO 剩余；若 $< 4:1$，则 $\text{O}_2$ 过量，会有 $\text{O}_2$ 剩余。

## 易错点

1. **NO 是无色的**（不是红棕色！）——红棕色的是 $\text{NO}_2$
2. **$\text{NO}_2$ 是红棕色**——容易和 $\text{Br}_2$ 蒸气混淆（两者都是红棕色气体），鉴别方法：通入 $\text{AgNO}_3$ 溶液，$\text{Br}_2$ 产生淡黄色沉淀而 $\text{NO}_2$ 不会
3. **$\text{NO}_2$ 与水反应生成 NO**——$\text{NO}_2$ 不能完全被水吸收（有 $\frac{1}{3}$ 转化为 NO 逸出），要完全吸收需同时通入 $\text{O}_2$
4. **NO 不溶于水但能被 $\text{O}_2$ 氧化**——收集 NO 用排水法（不与水反应），不能用排空气法（会被氧化）
5. **收集方法互换是常见错误**：NO→排水法；$\text{NO}_2$→向上排空气法，两者恰好相反
