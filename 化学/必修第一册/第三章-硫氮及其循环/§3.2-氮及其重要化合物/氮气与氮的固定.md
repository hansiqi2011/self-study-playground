# 氮气与氮的固定

## 定义

氮的固定是指将游离态的 $\text{N}_2$ 转化为化合态氮的过程。氮气是大气中含量最多的气体（约78%体积分数），由于 $\text{N}\equiv\text{N}$ 三键键能极大（$946\ \text{kJ/mol}$），常温下化学性质非常稳定。

## 核心内容

### $\text{N}_2$ 的物理性质

| 性质 | 描述 |
|------|------|
| 颜色气味 | 无色无味气体 |
| 液化温度 | $-195.8\ ^\circ\text{C}$ |
| 密度 | 略小于空气（$M = 28\ \text{g/mol}$） |
| 溶解性 | 难溶于水 |

### $\text{N}_2$ 的化学性质

常温下很稳定，但在高温、放电或催化剂条件下可发生反应：

$$\text{N}_2 + \text{O}_2 \xrightarrow{\text{放电}} 2\text{NO}$$

$$\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3 \quad (\text{高温高压、催化剂})$$

$$\text{N}_2 + 3\text{Mg} \xrightarrow{\text{点燃}} \text{Mg}_3\text{N}_2$$

### 氮的固定分类

**自然固氮：**

1. **生物固氮**：豆科植物根瘤菌通过固氮酶在常温常压下将 $\text{N}_2$ 转化为含氮化合物
2. **大气固氮**：雷电提供放电条件
$$\text{N}_2 + \text{O}_2 \xrightarrow{\text{放电}} 2\text{NO}$$

**人工固氮：**

工业合成氨（哈伯法）：

$$\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3$$

条件：高温（$400\text{-}500\ ^\circ\text{C}$）、高压（$2\times10^4 \sim 5\times10^4\ \text{kPa}$）、催化剂（铁触媒）

### $\text{N}_2$ 的用途

- 液氮做冷冻剂（医疗冷冻、超导材料冷却）
- 保护气（焊接金属、灯泡填充惰性气氛）
- 合成氨的原料

## 例题

<details>
<summary>例题1：下列过程属于氮的固定的是</summary>

**题目：** 下列过程中属于氮的固定的是（　）

A. $\text{N}_2 + 3\text{H}_2 \rightleftharpoons 2\text{NH}_3$

B. $\text{NH}_3 + \text{HCl} = \text{NH}_4\text{Cl}$

C. $2\text{NO}_2 + \text{H}_2\text{O} = \text{HNO}_3 + \text{NO}$

D. $\text{NH}_4\text{HCO}_3 \xrightarrow{\Delta} \text{NH}_3\uparrow + \text{H}_2\text{O}\uparrow + \text{CO}_2\uparrow$

**解析：**

氮的固定定义：将**游离态** $\text{N}_2$ 转化为**化合态**氮的过程。

- A：$\text{N}_2$（游离态）→ $\text{NH}_3$（化合态），✓ 属于氮的固定
- B：$\text{NH}_3$ 本身已是化合态氮，不涉及 $\text{N}_2$，✗
- C：$\text{NO}_2$ 已是化合态氮，✗
- D：$\text{NH}_4\text{HCO}_3$ 分解，不涉及 $\text{N}_2$，✗

**答案：A**
</details>

<details>
<summary>例题2：氮气的化学性质分析</summary>

**题目：** 下列关于 $\text{N}_2$ 的说法正确的是（　）

A. $\text{N}_2$ 常温下不与任何物质反应

B. $\text{N}_2$ 的化学性质不活泼是因为 $\text{N}\equiv\text{N}$ 键能大

C. $\text{N}_2$ 只能做氧化剂

D. 充入氮气可以防止食品氧化变质，是利用了 $\text{N}_2$ 的还原性

**解析：**

- A：错误。生物固氮在常温常压下进行（根瘤菌固氮酶降低活化能）
- B：正确。$\text{N}\equiv\text{N}$ 三键键能为 $946\ \text{kJ/mol}$，断裂需要很高能量
- C：错误。$\text{N}_2$ 中 N 为 0 价，既能升高（做还原剂，如与 $\text{O}_2$ 反应），也能降低（做氧化剂，如与 $\text{H}_2$、Mg 反应）
- D：错误。利用的是 $\text{N}_2$ 化学性质稳定（不活泼），不是还原性

**答案：B**
</details>

## 易错点

1. **$\text{N}_2$ 常温下稳定 ≠ 完全不反应**：生物固氮（根瘤菌）在常温常压下即可进行，是酶降低了反应活化能
2. **固氮的定义要准确**：固氮特指 $\text{N}_2$（游离态）→ 含 N 化合物（化合态）的过程；$\text{NH}_3 \to \text{NH}_4\text{Cl}$ 等化合态氮之间的转化不属于固氮
3. **$\text{N}_2$ 化合价为 0**，既可做氧化剂（如与 $\text{H}_2$ 反应化合价降低为 $-3$），也可做还原剂（如与 $\text{O}_2$ 反应化合价升高为 $+2$）
