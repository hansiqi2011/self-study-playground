# 铵盐的性质与铵根离子检验

## 定义

铵盐是由铵根离子（$\text{NH}_4^+$）和酸根离子组成的离子化合物。铵盐都易溶于水，受热易分解，能与碱反应释放 $\text{NH}_3$，是重要的氮肥来源。

## 核心内容

### 铵盐的通性

- 外观：白色晶体
- 溶解性：**全部易溶于水**（铵盐无难溶物）
- 水溶液呈酸性（$\text{NH}_4^+$ 水解）

### 铵盐受热分解

$$\text{NH}_4\text{Cl} \xrightarrow{\Delta} \text{NH}_3\uparrow + \text{HCl}\uparrow$$

冷却后 $\text{NH}_3$ 和 $\text{HCl}$ 重新化合生成 $\text{NH}_4\text{Cl}$，看似"升华"，**实为分解+化合**。

$$\text{NH}_4\text{HCO}_3 \xrightarrow{\Delta} \text{NH}_3\uparrow + \text{H}_2\text{O}\uparrow + \text{CO}_2\uparrow$$

碳铵（$\text{NH}_4\text{HCO}_3$）受热完全分解，因此作氮肥时要**深施覆土**，避免氮素损失。

### 铵盐与碱反应

$$\text{NH}_4^+ + \text{OH}^- \xrightarrow{\Delta} \text{NH}_3\uparrow + \text{H}_2\text{O}$$

这是制备 $\text{NH}_3$ 和检验 $\text{NH}_4^+$ 的化学依据。

### 检验 $\text{NH}_4^+$ 的方法

**操作步骤：**

1. 取少量待测样品于试管中
2. 加入浓 $\text{NaOH}$ 溶液
3. 加热
4. 将**湿润的红色石蕊试纸**置于试管口
5. 若试纸变**蓝** → 证明产生 $\text{NH}_3$ → 原样品含 $\text{NH}_4^+$

### 常见铵态氮肥

| 名称 | 化学式 | 含氮量 | 特点 |
|------|--------|--------|------|
| 碳铵 | $\text{NH}_4\text{HCO}_3$ | $17.7\%$ | 受热易分解，深施覆土 |
| 硫铵 | $(\text{NH}_4)_2\text{SO}_4$ | $21.2\%$ | 长期使用使土壤酸化 |
| 硝铵 | $\text{NH}_4\text{NO}_3$ | $35.0\%$ | 含两种形态氮，易爆 |
| 氯铵 | $\text{NH}_4\text{Cl}$ | $26.2\%$ | 忌氯作物不宜使用 |
| 尿素 | $\text{CO(NH}_2)_2$ | $46.7\%$ | 含氮量最高的固体氮肥 |

**含氮量排序：**

$$\text{CO(NH}_2)_2\ (46.7\%) > \text{NH}_4\text{NO}_3\ (35.0\%) > (\text{NH}_4)_2\text{SO}_4\ (21.2\%)$$

### 使用注意事项

铵态氮肥**不能与碱性物质混合施用**（如草木灰 $\text{K}_2\text{CO}_3$、生石灰 $\text{CaO}$）：

$$\text{NH}_4^+ + \text{OH}^- \to \text{NH}_3\uparrow + \text{H}_2\text{O}$$

碱性环境促使 $\text{NH}_3$ 释放，造成氮素损失。

## 例题

<details>
<summary>例题1：NH₄Cl受热是升华吗？</summary>

**题目：** 加热 $\text{NH}_4\text{Cl}$ 固体，在试管口有白色固体出现。有人说这是升华现象，请判断并说明理由。

**解析：**

**不是升华**。升华是物质直接由固态变为气态的物理变化，物质本身不变。

$\text{NH}_4\text{Cl}$ 加热时发生的是**化学变化**：

$$\text{NH}_4\text{Cl} \xrightarrow{\Delta} \text{NH}_3\uparrow + \text{HCl}\uparrow \quad (\text{分解反应})$$

在试管口温度较低处：

$$\text{NH}_3 + \text{HCl} = \text{NH}_4\text{Cl} \quad (\text{化合反应})$$

虽然现象与升华类似（固体→气体→固体），但过程中物质经历了化学变化（先分解后化合），因此**不是升华**。

**答案：** 不是升华，是分解反应和化合反应的连续过程。
</details>

<details>
<summary>例题2：铵根离子检验的实验设计</summary>

**题目：** 某化肥样品可能含有 $\text{NH}_4^+$，设计实验方案检验。

**解析：**

**实验方案：**

①取少量化肥样品于试管中

②加入足量浓 $\text{NaOH}$ 溶液

③加热试管

④在试管口放置一张湿润的红色石蕊试纸

**预期现象与结论：**

- 若试纸变蓝 → 有 $\text{NH}_3$ 生成 → 样品含 $\text{NH}_4^+$
- 若试纸不变色 → 样品不含 $\text{NH}_4^+$

**注意事项：**
- 必须用**浓** $\text{NaOH}$（碱性强，促进反应）
- 必须**加热**（加速 $\text{NH}_3$ 逸出）
- 试纸必须**湿润**（$\text{NH}_3$ 需溶于水才能使石蕊变色）

**答案：** 加浓NaOH溶液并加热，用湿润红色石蕊试纸检验产生的气体是否使其变蓝。
</details>

## 易错点

1. **$\text{NH}_4\text{Cl}$ 受热"升华"是错误说法**：实际是分解反应（$\text{NH}_4\text{Cl} \to \text{NH}_3 + \text{HCl}$）后在低温处重新化合，是化学变化不是物理变化
2. **检验 $\text{NH}_4^+$ 必须加碱且加热**：不加热时 $\text{NH}_3$ 产生量小、速度慢，可能检测不到；不加碱则不会产生 $\text{NH}_3$
3. **尿素不是铵盐但也是氮肥**：$\text{CO(NH}_2)_2$ 中不含 $\text{NH}_4^+$，不是离子化合物，但含氮量最高（$46.7\%$）
4. **$\text{NH}_4\text{NO}_3$ 中含两种形态的氮**：$\text{NH}_4^+$ 中 N 为 $-3$ 价，$\text{NO}_3^-$ 中 N 为 $+5$ 价
5. **铵盐全部易溶于水**：没有难溶的铵盐，这是一个重要的溶解性规律
