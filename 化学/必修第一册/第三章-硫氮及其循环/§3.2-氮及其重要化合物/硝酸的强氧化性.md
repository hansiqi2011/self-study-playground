# 硝酸的强氧化性

## 定义

硝酸（$\text{HNO}_3$）是一元强酸，具有酸的通性。其最显著特征是**强氧化性**——无论浓硝酸还是稀硝酸都具有强氧化性，这是由 $\text{NO}_3^-$ 中 $+5$ 价氮决定的。

## 核心内容

### 硝酸的酸性（通性）

$\text{HNO}_3$ 是强酸，在水溶液中完全电离：

$$\text{HNO}_3 = \text{H}^+ + \text{NO}_3^-$$

具有酸的通性：使指示剂变色、与碱反应、与碱性氧化物反应等。

### 硝酸的强氧化性

#### 浓 $\text{HNO}_3$ 与 Cu 反应（加热）

$$\text{Cu} + 4\text{HNO}_3(\text{浓}) \xrightarrow{\Delta} \text{Cu(NO}_3)_2 + 2\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

- 现象：铜片溶解，溶液变蓝，产生**红棕色**气体（$\text{NO}_2$）
- 还原产物：$\text{NO}_2$（N：$+5 \to +4$）

#### 稀 $\text{HNO}_3$ 与 Cu 反应

$$3\text{Cu} + 8\text{HNO}_3(\text{稀}) = 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$$

- 现象：铜片溶解，溶液变蓝，产生**无色**气体（$\text{NO}$，遇空气变红棕色）
- 还原产物：$\text{NO}$（N：$+5 \to +2$）

#### 规律总结

| 条件 | 还原产物 | 气体颜色 |
|------|---------|---------|
| 浓 $\text{HNO}_3$ | $\text{NO}_2$ | 红棕色 |
| 稀 $\text{HNO}_3$ | $\text{NO}$ | 无色 |

**核心结论：金属与 $\text{HNO}_3$ 反应绝对不生成 $\text{H}_2$！**

在 $\text{HNO}_3$ 溶液中，被还原的是 $\text{NO}_3^-$ 中的 $+5$ 价 N，而不是 $\text{H}^+$。

### 常温钝化

常温下，浓 $\text{HNO}_3$ 使 $\text{Fe}$、$\text{Al}$ 表面形成致密的氧化膜（**钝化**），阻止反应继续进行。

- 钝化 ≠ 不反应（加热后可剧烈反应）
- 因此可以用铁制容器或铝制容器在常温下盛放浓硝酸

### 王水

$$\text{浓 HNO}_3 : \text{浓 HCl} = 1:3 \quad (\text{体积比})$$

王水能溶解 $\text{Au}$（金）、$\text{Pt}$（铂）等单独不溶于硝酸的贵金属。

### 硝酸的不稳定性

$$4\text{HNO}_3 \xrightarrow{\Delta \text{ 或光照}} 4\text{NO}_2\uparrow + \text{O}_2\uparrow + 2\text{H}_2\text{O}$$

- 见光或受热分解，生成的 $\text{NO}_2$ 溶于硝酸中使之**发黄**
- 保存方法：**棕色瓶**，阴凉避光处

## 例题

<details>
<summary>例题1：Cu与稀硝酸反应的计算</summary>

**题目：** 将 $6.4\ \text{g}$ Cu 完全溶解于足量稀 $\text{HNO}_3$ 中，求生成 NO 的体积（标准状况）。

**解析：**

$$3\text{Cu} + 8\text{HNO}_3(\text{稀}) = 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$$

$n(\text{Cu}) = \dfrac{6.4}{64} = 0.1\ \text{mol}$

由化学计量数关系：$n(\text{NO}) = \dfrac{2}{3} \times n(\text{Cu}) = \dfrac{2}{3} \times 0.1 = \dfrac{1}{15}\ \text{mol}$

$$V(\text{NO}) = \frac{1}{15} \times 22.4 \approx 1.49\ \text{L}$$

**答案：** 生成 NO 约 $1.49\ \text{L}$（标准状况）。
</details>

<details>
<summary>例题2：区分浓硝酸与稀硝酸的反应</summary>

**题目：** 足量铜片放入一定量浓 $\text{HNO}_3$ 中，反应过程中观察到的现象变化是什么？为什么？

**解析：**

**反应过程分析：**

①初始阶段（浓 $\text{HNO}_3$）：

$$\text{Cu} + 4\text{HNO}_3(\text{浓}) \xrightarrow{\Delta} \text{Cu(NO}_3)_2 + 2\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

现象：剧烈反应，产生大量**红棕色**气体，溶液变为蓝绿色。

②后期阶段（$\text{HNO}_3$ 变稀）：

随着反应进行，$\text{HNO}_3$ 浓度降低变为稀硝酸：

$$3\text{Cu} + 8\text{HNO}_3(\text{稀}) = 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$$

现象：气体变为**无色**（NO），遇瓶口空气变红棕色，反应速率减慢。

**答案：** 先产生红棕色气体（$\text{NO}_2$），后产生无色气体（$\text{NO}$，遇空气变红棕色），溶液始终变蓝。
</details>

## 易错点

1. **金属与 $\text{HNO}_3$ 反应绝对不生成 $\text{H}_2$**：被还原的是 $+5$ 价的 N（生成 $\text{NO}_2$ 或 $\text{NO}$），而不是 $\text{H}^+$
2. **浓 $\text{HNO}_3$ 产生 $\text{NO}_2$（红棕色），不是 NO**；**稀 $\text{HNO}_3$ 产生 NO（无色），不是 $\text{NO}_2$**——浓稀对应的产物不要记反
3. **Fe 在常温浓 $\text{HNO}_3$ 中钝化 ≠ 不反应**：钝化是形成氧化膜，加热后仍会剧烈反应；稀 $\text{HNO}_3$ 可以直接溶解 Fe
4. **$\text{HNO}_3$ 必须用棕色瓶保存**：因为 $\text{HNO}_3$ 见光分解产生 $\text{NO}_2$，使溶液发黄
5. **王水的比例**：浓 $\text{HNO}_3$:浓 $\text{HCl} = 1:3$（体积比），不要记反
