# 浓硫酸的特性

## 定义

浓硫酸（质量分数 $\geq 98\%$ 的 $\text{H}_2\text{SO}_4$）是一种强氧化性酸，除具有酸的通性外，还具有**吸水性、脱水性、强氧化性**三大特性，与稀硫酸性质有本质区别。

## 核心内容

### 物理性质

| 性质 | 描述 |
|------|------|
| 外观 | 无色黏稠油状液体 |
| 密度 | $1.84\text{ g/cm}^3$ |
| 沸点 | $338\text{°C}$（高沸点酸） |
| 溶解性 | 与水**任意比**互溶，溶解时**放出大量热** |

### 特性一：吸水性

浓硫酸能吸收**游离态水分子**（包括气体中的水蒸气、结晶水等）。

**应用**：作气体干燥剂

- 可干燥：$\text{H}_2$、$\text{O}_2$、$\text{CO}_2$、$\text{Cl}_2$、$\text{SO}_2$、$\text{HCl}$ 等
- **不能干燥**：$\text{NH}_3$（碱性气体，与酸反应）

### 特性二：脱水性

浓硫酸能将有机物中的 H 和 O 按**水的组成比**（$2:1$）脱去，使有机物炭化。

**经典实验——蔗糖变黑**：

$$\text{C}_{12}\text{H}_{22}\text{O}_{11} \xrightarrow{\text{浓 H}_2\text{SO}_4} 12\text{C} + 11\text{H}_2\text{O}$$

实验现象：蔗糖变黑、体积膨胀（"黑面包"实验），同时闻到刺激性气味（生成的 C 被浓硫酸氧化产生 $\text{SO}_2$）。

### 特性三：强氧化性

浓硫酸中 S 为 $+6$ 价，具有强氧化性（**起氧化作用的是 $\text{SO}_4^{2-}$ 中的 S，不是 $\text{H}^+$**）。

#### 与铜反应（需加热）

$$\text{Cu} + 2\text{H}_2\text{SO}_4(\text{浓}) \xrightarrow{\Delta} \text{CuSO}_4 + \text{SO}_2\uparrow + 2\text{H}_2\text{O}$$

现象：铜片溶解，溶液变蓝色，产生有刺激性气味气体。

#### 与碳反应（需加热）

$$\text{C} + 2\text{H}_2\text{SO}_4(\text{浓}) \xrightarrow{\Delta} \text{CO}_2\uparrow + 2\text{SO}_2\uparrow + 2\text{H}_2\text{O}$$

#### 常温钝化 Fe、Al

浓硫酸在常温下使铁和铝表面形成**致密的氧化膜**，阻止反应继续进行。

$$\text{应用：可用铁制或铝制容器在常温下储运浓硫酸}$$

### 稀释方法

将浓硫酸沿容器壁**缓慢加入水中**，同时用玻璃棒不断搅拌。

> ⚠️ **酸入水**（密度大的加入密度小的），绝不能水入酸！水入酸会导致局部沸腾、酸液飞溅。

### 浓硫酸与稀硫酸的区别

| 对比项 | 浓硫酸 | 稀硫酸 |
|--------|--------|--------|
| 与 Cu 反应 | 加热可反应 | **不反应** |
| 与 Fe 反应 | 常温钝化 | 生成 $\text{FeSO}_4 + \text{H}_2\uparrow$ |
| 氧化性来源 | $+6$ 价 S | $\text{H}^+$ |

## 例题

<details>
<summary>例题 1：Cu 与浓硫酸反应的计算</summary>

**题目**：将足量铜片放入 $50\text{ mL}$ $18.4\text{ mol/L}$ 的浓硫酸中加热，反应停止后，求生成 $\text{SO}_2$ 的物质的量是否等于 $0.46\text{ mol}$？

**解答**：

不等于。$n(\text{H}_2\text{SO}_4) = 0.05 \times 18.4 = 0.92\text{ mol}$

但随着反应进行，浓硫酸变为稀硫酸后**反应停止**（稀硫酸不能与 Cu 反应），所以实际消耗的 $\text{H}_2\text{SO}_4$ 少于总量，$n(\text{SO}_2) < 0.46\text{ mol}$。

</details>

<details>
<summary>例题 2：黑面包实验产物验证</summary>

**题目**：蔗糖与浓硫酸反应后产生的气体如何验证含有 $\text{SO}_2$ 和 $\text{CO}_2$？

**解答**：

气体依次通过：

1. **品红溶液**：褪色 → 含 $\text{SO}_2$（加热恢复确认）
2. **酸性 $\text{KMnO}_4$ 溶液**：除去 $\text{SO}_2$
3. **品红溶液**：不褪色 → 确认 $\text{SO}_2$ 已除尽
4. **澄清石灰水**：变浑浊 → 含 $\text{CO}_2$

</details>

## 易错点

1. **钝化不是"不反应"**——是反应生成致密氧化膜后阻止继续反应，属于化学变化
2. **浓硫酸与 Cu 反应必须加热**——常温下不反应
3. **稀硫酸不能溶解 Cu**——稀硫酸没有强氧化性，$\text{H}^+$ 不能氧化 Cu
4. **稀释时"酸入水"不是"水入酸"**——浓硫酸密度大，加入水中沉底散热；反之水浮于酸面局部剧烈放热
5. 浓硫酸与 Cu 反应，随反应进行浓度降低变为稀硫酸后反应**自动停止**，硫酸不能完全反应
