# 硫单质的性质

## 定义

硫（S）是第 VIA 族非金属元素，单质硫为黄色固体，具有多种同素异形体（斜方硫 $S_8$、单斜硫等），化学性质上既能表现氧化性又能表现还原性。

## 核心内容

### 物理性质

| 性质 | 描述 |
|------|------|
| 颜色状态 | 黄色或淡黄色固体，俗称**硫黄** |
| 硬度 | 质脆，易研磨成粉末 |
| 溶解性 | 不溶于水，微溶于酒精，易溶于 $CS_2$ |

### 化学性质——与金属反应

硫的氧化性弱于 $Cl_2$，只能将变价金属氧化到**低价态**：

$$\text{Fe} + \text{S} \xrightarrow{\Delta} \text{FeS}$$

铁被氧化为 $+2$ 价（对比 $2\text{Fe} + 3\text{Cl}_2 \rightarrow 2\text{FeCl}_3$，氯气氧化到 $+3$ 价）

$$2\text{Cu} + \text{S} \xrightarrow{\Delta} \text{Cu}_2\text{S}$$

铜被氧化为 $+1$ 价（不是 $\text{CuS}$）

$$2\text{Na} + \text{S} \rightarrow \text{Na}_2\text{S}$$

### 化学性质——与非金属反应

$$\text{S} + \text{O}_2 \xrightarrow{\text{点燃}} \text{SO}_2$$

在空气中燃烧产生**淡蓝色火焰**，生成有刺激性气味的气体。

$$\text{H}_2 + \text{S} \xrightarrow{\Delta} \text{H}_2\text{S}$$

### 硫的化合价

硫在化合物中常见化合价：$-2$、$0$、$+4$、$+6$

- $-2$ 价：$\text{H}_2\text{S}$、$\text{Na}_2\text{S}$
- $0$ 价：单质 $\text{S}$
- $+4$ 价：$\text{SO}_2$、$\text{H}_2\text{SO}_3$
- $+6$ 价：$\text{SO}_3$、$\text{H}_2\text{SO}_4$

### 自然界存在形式

- **游离态**：单质硫（火山口附近）
- **化合态——硫化物**：黄铁矿 $\text{FeS}_2$、辉铜矿 $\text{Cu}_2\text{S}$
- **化合态——硫酸盐**：石膏 $\text{CaSO}_4 \cdot 2\text{H}_2\text{O}$、芒硝 $\text{Na}_2\text{SO}_4 \cdot 10\text{H}_2\text{O}$

## 例题

<details>
<summary>例题 1：比较 S 与 Cl₂ 氧化性强弱</summary>

**题目**：铁分别与硫、氯气反应，产物有何不同？说明了什么问题？

**解答**：

- $\text{Fe} + \text{S} \xrightarrow{\Delta} \text{FeS}$（Fe 被氧化为 $+2$ 价）
- $2\text{Fe} + 3\text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{FeCl}_3$（Fe 被氧化为 $+3$ 价）

说明 $Cl_2$ 的氧化性强于 $S$，氧化性强的非金属能将变价金属氧化到高价态。

</details>

<details>
<summary>例题 2：硫的化合价判断</summary>

**题目**：判断下列物质中硫元素的化合价：$\text{Na}_2\text{S}$、$\text{SO}_2$、$\text{Na}_2\text{SO}_4$、$\text{S}$

**解答**：

- $\text{Na}_2\text{S}$：Na 为 $+1$，设 S 为 $x$，$2(+1)+x=0$，$x=-2$
- $\text{SO}_2$：O 为 $-2$，$x+2(-2)=0$，$x=+4$
- $\text{Na}_2\text{SO}_4$：$2(+1)+x+4(-2)=0$，$x=+6$
- $\text{S}$：单质，化合价为 $0$

</details>

## 易错点

1. **Fe 与 S 反应只生成 $\text{FeS}$（$+2$ 价）**，不是 $\text{Fe}_2\text{S}_3$——硫的氧化性较弱，不能将 Fe 氧化到 $+3$ 价
2. **Cu 与 S 反应生成 $\text{Cu}_2\text{S}$（$+1$ 价）**，不是 $\text{CuS}$——同理，S 只能将 Cu 氧化到低价
3. **S 的氧化性弱于 $Cl_2$**，所以 S 只能把变价金属氧化到低价态，而 $Cl_2$ 能氧化到高价态
4. S 在空气中燃烧只能生成 $\text{SO}_2$，不能直接生成 $\text{SO}_3$
