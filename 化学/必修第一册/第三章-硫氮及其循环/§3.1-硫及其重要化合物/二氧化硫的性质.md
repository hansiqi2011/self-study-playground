# 二氧化硫的性质

## 定义

二氧化硫（$\text{SO}_2$）是硫的 $+4$ 价氧化物，属于**酸性氧化物**，具有漂白性，同时因为处于中间价态（$+4$），既能表现氧化性又能表现还原性。

## 核心内容

### 物理性质

| 性质 | 描述 |
|------|------|
| 颜色气味 | 无色、有**刺激性气味**的有毒气体 |
| 密度 | 密度大于空气（$M=64\text{ g/mol}$） |
| 溶解性 | 易溶于水（1 体积水溶解约 40 体积 $\text{SO}_2$） |

### 酸性氧化物通性

$\text{SO}_2$ 与水反应生成亚硫酸（弱酸、不稳定、**可逆反应**）：

$$\text{SO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{SO}_3$$

与碱反应：

$$\text{SO}_2 + 2\text{NaOH} \rightarrow \text{Na}_2\text{SO}_3 + \text{H}_2\text{O}$$

与碱性氧化物反应：

$$\text{SO}_2 + \text{Na}_2\text{O} \rightarrow \text{Na}_2\text{SO}_3$$

### 漂白性

$\text{SO}_2$ 能使**品红溶液褪色**，但加热后颜色恢复（**可逆漂白**）。

机理：$\text{SO}_2$ 与有色物质结合生成不稳定的无色物质，加热分解恢复原色。

> **对比 $\text{HClO}$ 漂白**：$\text{HClO}$ 将有色物质氧化分解，漂白**不可逆**，加热后不恢复。

### 还原性（$+4 \rightarrow +6$）

$\text{SO}_2$ 中 S 为 $+4$ 价，遇强氧化剂被氧化为 $+6$ 价：

$$2\text{SO}_2 + \text{O}_2 \underset{\Delta}{\overset{\text{催化剂}}{\rightleftharpoons}} 2\text{SO}_3$$

$$\text{SO}_2 + \text{Cl}_2 + 2\text{H}_2\text{O} \rightarrow \text{H}_2\text{SO}_4 + 2\text{HCl}$$

$$5\text{SO}_2 + 2\text{KMnO}_4 + 2\text{H}_2\text{O} \rightarrow 2\text{MnSO}_4 + \text{K}_2\text{SO}_4 + 2\text{H}_2\text{SO}_4$$

### 氧化性（$+4 \rightarrow -2$）

遇到更强的还原剂时，$\text{SO}_2$ 表现氧化性：

$$\text{SO}_2 + 2\text{H}_2\text{S} \rightarrow 3\text{S}\downarrow + 2\text{H}_2\text{O}$$

### 与指示剂的反应

$\text{SO}_2$ 通入石蕊试液：溶液**变红**（因为生成 $\text{H}_2\text{SO}_3$ 是酸），但**不褪色**。

### 检验方法

品红试液褪色 $\xrightarrow{\text{加热}}$ 恢复红色 → 确认为 $\text{SO}_2$

## 例题

<details>
<summary>例题 1：SO₂ 与 Cl₂ 混合后漂白性</summary>

**题目**：将等体积的 $\text{SO}_2$ 和 $\text{Cl}_2$ 同时通入品红溶液中，能否褪色？

**解答**：

不能褪色（或褪色效果大大减弱）。因为 $\text{SO}_2$ 和 $\text{Cl}_2$ 在水溶液中发生反应：

$$\text{SO}_2 + \text{Cl}_2 + 2\text{H}_2\text{O} \rightarrow \text{H}_2\text{SO}_4 + 2\text{HCl}$$

两者相互消耗，既失去了 $\text{SO}_2$ 的漂白性，也失去了 $\text{Cl}_2$（生成 $\text{HClO}$）的漂白性。

</details>

<details>
<summary>例题 2：鉴别 SO₂ 和 CO₂</summary>

**题目**：如何用化学方法鉴别 $\text{SO}_2$ 和 $\text{CO}_2$？

**解答**：

将气体分别通入**品红溶液**：
- 品红褪色 → 可能是 $\text{SO}_2$，再加热，若恢复红色 → 确认为 $\text{SO}_2$
- 品红不褪色 → $\text{CO}_2$

注意：不能用澄清石灰水鉴别，因为两者都能使石灰水变浑浊。

</details>

## 易错点

1. **$\text{SO}_2$ 漂白是可逆的**（加热恢复），$\text{HClO}$ 漂白是**不可逆的**——本质不同
2. **$\text{SO}_2$ 使石蕊变红但不褪色**——因为 $\text{H}_2\text{SO}_3$ 是酸性使指示剂变色，不是漂白
3. **$\text{SO}_2$ 既有氧化性又有还原性**——处于中间价态 $+4$，遇强氧化剂做还原剂，遇强还原剂做氧化剂
4. $\text{SO}_2$ 和 $\text{Cl}_2$ 混合后漂白能力**不是增强而是减弱**（相互反应消耗）
5. $\text{SO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{SO}_3$ 是**可逆反应**，$\text{H}_2\text{SO}_3$ 不稳定会分解
