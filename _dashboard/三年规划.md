# 高中三年学习规划

选科方向：**物理 / 化学 / 生物**
目标：**高一末覆盖完高二内容，高二起进入做题强化**

---

## 战略分层

| 层级 | 科目 | 策略 |
|---|---|---|
| 🔴 主攻 | 数学、物理、化学、生物 | 高一年内覆盖全部必修 + 部分选择性必修，高二做题强化 |
| 🟡 保底 | 地理 | 跟学校进度，高一下6月合格考过关即可 |
| 🟢 跟校 | 语文、英语、政治、历史 | 跟学校进度，不额外超前 |

---

## 考试时间线

```
高一下 2027年6月末 ─── 合格考：地理、生命科学（笔试+实验）、信息技术（上机）
高二下 2028年5月   ─── 等级考（小三门）：物理、化学、生物
高二下 2028年6月末 ─── 合格考：物理、化学、政治、历史
高三上 2029年1月   ─── 合格考：语数外 ｜ 春季高考
高三下 2029年6月   ─── 秋季高考（大三门）
```

## 第一阶段：高一（2026.9 — 2027.7）—— 知识覆盖

> 核心原则：新课推进 + 间隔复习并行，宁可新课慢一点也不丢复习节奏。

### 数学（沪教版 · 必修4册 + 选择性必修2册）

| 时段 | 目标 | 具体内容 |
|---|---|---|
| 9月 | 必修第一册收尾 | Ch4 幂函数/指数函数/对数函数 ✅ → Ch5 函数的概念性质及应用 ✅ → 全册综合测试 |
| 10—12月 | 必修第二册完成 | 三角比、三角函数、数列、平面向量 |
| 1—2月（寒假） | 必修第三册完成 | 矩阵行列式初步、算法初步、坐标平面上的直线 |
| 3—5月 | 必修第四册完成 | 圆锥曲线、复数、空间直线与平面 |
| 6—7月（暑假） | 选择性必修第一册 + 第二册 | 导数与微分、计数原理、概率统计、数学建模 |

### 物理（沪科教版 · 必修3册 + 选择性必修1册）

| 时段 | 目标 | 具体内容 |
|---|---|---|
| 9—11月 | 必修第一册完成 | 运动描述、匀变速直线运动、力与相互作用、牛顿运动定律 |
| 12—2月 | 必修第二册完成 | 功和机械能、抛体运动、圆周运动、万有引力与航天 |
| 3—5月 | 必修第三册完成 | 电场、电路、磁场、电磁感应 |
| 6—7月（暑假） | 选择性必修第一册 | 热学、机械振动与波、光学 |

### 化学（沪科技版 · 必修2册 + 选择性必修1册）

| 时段 | 目标 | 具体内容 |
|---|---|---|
| 9—12月 | 必修第一册完成 | 化学研究的天地、卤素、硫氮、原子结构与化学键 |
| 1—4月 | 必修第二册完成 | 化学反应与能量、有机化学初步 |
| 5—7月 | 选择性必修第一册 | 化学反应原理 |

> 选择性必修2（物质结构与性质）、3（有机化学基础）→ 高二上学期完成

### 生物（沪科技版 · 必修2册 + 选择性必修1册）

| 时段 | 目标 | 具体内容 |
|---|---|---|
| 9—11月 | 必修1完成 | 分子与细胞（Ch1-5） |
| 12—3月 | 必修2完成 | 遗传与进化 |
| 3—6月 | 选择性必修1 | 稳态与调节 |
| **6月末** | **合格考** | 必修1-2范围 |

> 选择性必修2（生物与环境）、3（生物技术与工程）→ 高二上学期完成

### 地理（中华地图版 · 只需合格考）

| 时段 | 目标 |
|---|---|
| 9—1月 | 必修第一册，跟学校走（当前已60%） |
| 2—5月 | 必修第二册，跟学校走（已录入） |
| 6月 | 考前集中复习 |
| **6月末** | **合格考** |

### 语文 / 英语 / 政治 / 历史

跟学校正常进度。不额外超前，时间全部让给主攻四科。

## 第二阶段：高二（2027.9 — 2028.5）—— 做题强化

> 前提：高一目标达成，知识覆盖完毕。此阶段用于做题、刷真题、查漏补缺。

### 高二上（2027.9 — 2028.1）

| 科目 | 任务 |
|---|---|
| 数学 | 必修+选择性必修全范围刷题，重点攻克圆锥曲线和导数大题 |
| 物理 | 选择性必修2-3完成 + 必修1-3刷题 |
| 化学 | 选择性必修2（物质结构）+ 选择性必修3（有机化学）完成 |
| 生物 | 选择性必修2（生物与环境）+ 选择性必修3（生物技术与工程）完成 |

### 高二下（2028.2 — 2028.5）

| 科目 | 任务 |
|---|---|
| 物化生 | **等级考冲刺**：系统刷题 + 真题模拟 + 查漏补缺 |
| 数学 | 继续刷题，重点突破薄弱模块 |
| **2028年5月** | **等级考：物理、化学、生物** |

### 2028年暑假

小三门考完，全力转向大三门（语数外）。

## 风险与缓冲

| 风险 | 影响 | 缓冲方案 |
|---|---|---|
| 物理进度落后 | 物理是欠账最多的主攻科目 | 选择性必修1可推迟到高二寒假 |
| 数学选择性必修来不及 | 概率统计与前面内容关联弱 | 可推迟到高二寒假集中学 |
| 化学选择性必修1来不及 | 化学反应原理是等级考核心 | 最迟高二上学期9-10月完成 |
| 学校考试/竞赛占用时间 | 打乱自学节奏 | 优先保数学和物理，其余弹性调整 |
| 间隔复习积压 | 新课太快导致复习队列爆炸 | 宁可暂停新课一周也要清复习债 |

---

## 核心纪律

1. **间隔复习 > 新课推进**。复习债不过夜。
2. **数学和物理每天都碰**。一天不练手生。
3. **里程碑未达标时复盘，不硬赶**。欠了就承认，调整计划，不自欺。
4. **不在跟校科目上投入额外时间**。语文英语政治历史跟着学校走就好。
5. **每月底对照里程碑自检一次**，更新本文档。
