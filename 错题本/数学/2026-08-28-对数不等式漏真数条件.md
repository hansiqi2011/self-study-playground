# 错题：对数不等式漏真数条件

## 原题

已知 $\log_a(x-1) > \log_a(3-2x)$，且 $0 < a < 1$，求 $x$ 的范围。

## 我的错误答案

$x < \frac{4}{3}$

只做了翻转不等号 + 解不等式，忘记加真数 > 0 的条件。

## 正确解法

1. $0 < a < 1$，递减，翻转：$x - 1 < 3 - 2x$，解得 $x < \frac{4}{3}$
2. **真数条件**：$x - 1 > 0 \Rightarrow x > 1$；$3 - 2x > 0 \Rightarrow x < \frac{3}{2}$
3. 取交集：$1 < x < \frac{4}{3}$

## 错因分析

对数不等式的第三步（真数 > 0）没有形成条件反射。只记得翻不等号，忘了对数的定义域限制。

## 防错策略

**对数不等式三步走（必须按顺序）：**

1. 看底：$a > 1$ 同向，$0 < a < 1$ 反向
2. 去对数，解不等式
3. **加真数 > 0 条件，取交集**（这步不能忘！）

口诀：**"翻号、解、加正、交"**
