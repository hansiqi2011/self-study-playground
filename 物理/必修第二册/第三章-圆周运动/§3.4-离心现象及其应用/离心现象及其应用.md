# 离心现象及其应用

## 定义

做圆周运动的物体，当提供的向心力**不足**（或突然消失）时，物体沿切线方向或某曲线**飞离圆周**的现象。

## 核心内容

### 产生条件

| 条件 | 物体运动 |
|---|---|
| $F = F_{向心}$ | 保持匀速圆周运动 |
| $F = 0$（突然消失） | 沿该点切线方向飞出（直线） |
| $F < F_{向心}$（不足） | 沿某曲线逐渐远离圆心 |
| $F > F_{向心}$（过大） | 向圆心方向靠近（做向心运动） |

### 关键理解

离心现象的本质：物体有**惯性**，倾向于沿切线飞出；向心力把它"拽"在圆周上。力不够 → 惯性占主导 → 远离圆心。

### 应用与危害

| 利用离心 | 防止离心 |
|---|---|
| 洗衣机脱水 | 汽车转弯限速 |
| 离心式水泵 | 砂轮/飞轮限转速 |
| 离心分离器 | 弯道内侧倾斜设计 |
| 制造水泥涵管 | 雨天转弯更需减速 |

### 公交车转弯问题

弯道半径越**小**、速度越**大** → 需要的向心力越大 → 离心现象越强烈。

（所以司机说"转小弯水泼得更多"是对的）

## 易错点

1. 离心运动不是"受到离心力"——没有离心力这个力，只是惯性的表现
2. 物体飞出方向是**切线方向**，不是径向向外
3. 转速越高 / 半径越小 → 需要的向心力越大 → 越容易发生离心
4. 洗衣机：水从小孔飞出是因为筒壁无法给水提供向心力
