# 圆周运动的案例分析

## 核心内容

### 案例一：竖直面圆周运动（过山车/绳系球）

#### 最高点分析

$$mg + F_N = \frac{mv^2}{R}$$

- 临界条件：$F_N = 0$ 时，$v_{\min} = \sqrt{gR}$
- $v > \sqrt{gR}$：轨道有向下压力（正常通过）
- $v < \sqrt{gR}$：**脱离轨道**（合力不够提供向心力）

#### 最低点分析

$$F_N - mg = \frac{mv^2}{R}$$

$$F_N = mg + \frac{mv^2}{R} > mg$$（超重状态）

#### 绳与杆的区别

| | 绳模型 | 杆（轨道）模型 |
|---|---|---|
| 最高点最小速度 | $v_{\min} = \sqrt{gR}$ | $v_{\min} = 0$ |
| 原因 | 绳只能拉不能推 | 杆可以拉也可以推 |

### 案例二：水平面转弯

自行车/摩托车转弯：向内倾斜角 $\theta$ 满足

$$\tan\theta = \frac{v^2}{gR}$$

汽车水平路面转弯：静摩擦力提供向心力

$$f = \frac{mv^2}{R}$$

速度过大 → $f$ 需求超过最大静摩擦力 → 侧滑（离心）

### 案例三：火车弯道

内低外高，倾斜角使重力和支持力的合力提供向心力，减少对摩擦力的依赖。

## 易错点

1. 最高点临界速度 $\sqrt{gR}$ 只适用于**绳/轨道外侧**模型，杆模型最小速度可以为 0
2. 最低点支持力一定**大于**重力（$F_N = mg + mv^2/R$）
3. 汽车转弯时摩擦力指向**圆心**（弯道内侧），不是沿运动方向
4. "向心力不够"不代表物体向圆心方向运动停止，而是**向外偏离**圆周
