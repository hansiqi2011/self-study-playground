# 向心加速度与向心力

## 定义

### 向心加速度
匀速圆周运动中，加速度方向**始终指向圆心**，只改变速度方向不改变速度大小。

### 向心力
产生向心加速度的合力，方向指向圆心。**不是一种新的力**，而是合力的效果。

## 核心内容

### 公式体系

$$a = \frac{v^2}{R} = \omega^2 R = \frac{4\pi^2}{T^2}R$$

$$F = ma = \frac{mv^2}{R} = m\omega^2 R = \frac{4\pi^2 m}{T^2}R$$

### 两个公式的"矛盾"辨析

| 公式 | 含义 | $a$ 与 $R$ 关系 |
|---|---|---|
| $a = v^2/R$ | $v$ 一定时 | $a$ 与 $R$ **成反比** |
| $a = \omega^2 R$ | $\omega$ 一定时 | $a$ 与 $R$ **成正比** |

> 不矛盾！前提条件不同。$v$ 和 $\omega$ 不能同时保持不变（因为 $v = \omega R$）。

### 向心力的来源（常见情况）

| 场景 | 向心力来源 |
|---|---|
| 水平面绳系球 | 绳的拉力 |
| 汽车水平转弯 | 地面静摩擦力 |
| 竖直面最高点（轨道外侧） | $mg + F_N$（均指向圆心） |
| 竖直面最低点 | $F_N - mg$（支持力向心减重力） |
| 卫星绕地球 | 万有引力 |

## 易错点

1. 向心力**不是一种新力**——它是已有力（重力、拉力、摩擦力等）的合力在指向圆心方向上的分量
2. 竖直面最高点：$F_N + mg = mv^2/R$；最低点：$F_N - mg = mv^2/R$
3. 受力分析中**绝对不能**画出一个叫"向心力"的力
4. $a = v^2/R$ 和 $a = \omega^2 R$ 适用条件不同，不能混用
