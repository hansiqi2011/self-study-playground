# 斜抛运动

## 定义

以初速度 $v_0$ 沿斜向（与水平成角 $\theta$）抛出，仅受重力作用的运动。

## 核心内容

### 分解

| | 水平方向（匀速） | 竖直方向（匀减速→匀加速） |
|---|---|---|
| 初速度 | $v_{0x} = v_0\cos\theta$ | $v_{0y} = v_0\sin\theta$ |
| 速度 | $v_x = v_0\cos\theta$ | $v_y = v_0\sin\theta - gt$ |
| 位移 | $x = v_0\cos\theta \cdot t$ | $y = v_0\sin\theta \cdot t - \frac{1}{2}gt^2$ |

### 关键结论

| 量 | 公式 |
|---|---|
| 到达最高点时间 | $t_{\text{顶}} = \frac{v_0\sin\theta}{g}$ |
| 最大高度 | $H = \frac{v_0^2\sin^2\theta}{2g}$ |
| 总飞行时间（同高度落回） | $T = \frac{2v_0\sin\theta}{g}$ |
| 水平射程（同高度） | $R = \frac{v_0^2\sin 2\theta}{g}$ |
| 射程最大时的角度 | $\theta = 45°$ |

### 对称性（同高度出发和落地时）

- 上升时间 = 下降时间
- 抛出速度 = 落地速度大小
- 轨迹关于最高点左右对称

## 易错点

1. 最高点时 $v_y = 0$ 但 $v_x \neq 0$，所以**最高点速度不为零**（= $v_0\cos\theta$）
2. 射程公式 $R = \frac{v_0^2\sin 2\theta}{g}$ 只适用于**落点与抛出点等高**的情况
3. $\theta = 45°$ 射程最大（因为 $\sin 2\theta$ 最大 = 1）
4. 互补角（如 $30°$ 和 $60°$）射程相等（$\sin 2\theta$ 相等）
