# 平抛运动的规律

## 定义

初速度 $v_0$ 水平，仅受重力的曲线运动。轨迹为抛物线。

## 核心内容

### 公式体系

| | 水平方向（匀速） | 竖直方向（自由落体） |
|---|---|---|
| 速度 | $v_x = v_0$ | $v_y = gt$ |
| 位移 | $x = v_0 t$ | $y = \frac{1}{2}gt^2$ |

### 合成量

| 量 | 公式 |
|---|---|
| 合速度大小 | $v = \sqrt{v_x^2 + v_y^2} = \sqrt{v_0^2 + g^2t^2}$ |
| 合速度方向 | $\tan\theta = \frac{v_y}{v_x} = \frac{gt}{v_0}$ |
| 合位移大小 | $s = \sqrt{x^2 + y^2}$ |
| 轨迹方程 | $y = \frac{g}{2v_0^2}x^2$（抛物线） |

### 解题关键

1. **时间是桥梁**：水平和竖直共用同一个 $t$
2. 落地时间：由高度 $h$ 决定，$t = \sqrt{\frac{2h}{g}}$
3. 水平射程：$x = v_0 \sqrt{\frac{2h}{g}}$

## 易错点

1. 落地时间**只取决于下落高度**，与 $v_0$ 无关
2. 落地速度方向不是竖直向下，而是与水平方向成角 $\theta$
3. 合位移方向 ≠ 合速度方向（位移连初末位置，速度是切线）
4. $v_y$ 在增大，所以合速度与水平方向的夹角在**不断增大**
