# 动能与动能定理

## 定义

### 动能
$$\boxed{E_k = \frac{1}{2}mv^2}$$

物体由于运动而具有的能量。标量，单位：J。

### 动能定理
$$\boxed{W_{\text{合}} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2}$$

外力对物体做的总功（合力做的功）= 物体动能的增量。

## 核心内容

### 动能定理的理解

| 要素 | 说明 |
|---|---|
| $W_{\text{合}}$ | 所有外力做功的代数和 = 合外力做的功 |
| $\Delta E_k$ | 末动能 - 初动能（可正可负） |
| 正功 | $W > 0$ → 动能增加 |
| 负功 | $W < 0$ → 动能减少 |

### 动能定理 vs 牛顿第二定律

| | 动能定理 | 牛二 + 运动学 |
|---|---|---|
| 关注 | 初末状态 + 做功 | 全过程（加速度、时间） |
| 优势 | 不需要知道加速度和时间；可处理变力 |  |
| 适用 | 直线/曲线运动，恒力/变力 | 恒力直线运动更方便 |

### 过程量与状态量

- **功**：过程量（与路径有关）
- **动能**：状态量（只与当前速度有关）

## 易错点

1. $W$ 是**合力做的功**（或所有外力做功的代数和），不是某一个力做的功
2. 动能只与速度大小有关，与方向无关（$v^2$ 没有方向）
3. 动能是标量，**永远 ≥ 0**
4. 动能定理适用于变力做功（牛顿定律不方便处理变力）
