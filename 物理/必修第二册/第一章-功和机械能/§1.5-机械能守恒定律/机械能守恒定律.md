# 机械能守恒定律

## 定义

在只有重力（或弹力）做功的情况下，物体的动能和势能可以相互转化，但机械能的总量保持不变。

$$\boxed{E_{k1} + E_{p1} = E_{k2} + E_{p2}}$$

或写为：

$$\boxed{\frac{1}{2}mv_1^2 + mgh_1 = \frac{1}{2}mv_2^2 + mgh_2}$$

## 核心内容

### 适用条件

**只有重力和弹簧弹力做功**（其他力不做功或合力做功为零）。

等价表述：没有摩擦力做功、没有外力做功、没有其他非保守力做功。

### 判断能否用机械能守恒的方法

1. 除重力/弹力外，物体**不受其他力** → ✅
2. 受其他力，但其他力**不做功**（如光滑面的支持力，垂直运动方向） → ✅
3. 有摩擦力或外力做功 → ❌ 不守恒

### 解题步骤

1. 判断是否满足机械能守恒条件
2. 选取参考平面（使计算简单）
3. 写出初态机械能 $E_1 = E_{k1} + E_{p1}$
4. 写出末态机械能 $E_2 = E_{k2} + E_{p2}$
5. 列方程 $E_1 = E_2$

### 典型模型

| 模型 | 机械能守恒？ | 说明 |
|---|---|---|
| 自由落体 | ✅ | 只有重力做功 |
| 光滑斜面下滑 | ✅ | 支持力不做功 |
| 单摆（不计阻力） | ✅ | 绳拉力不做功 |
| 粗糙斜面下滑 | ❌ | 摩擦力做负功 |
| 有外力拉动 | ❌ | 外力做功 |

## 易错点

1. ❌"速度不变就是机械能守恒"→ 匀速上升时动能不变但势能增加，机械能增大（外力做正功）
2. ❌"只要没有摩擦就守恒"→ 还要看是否有其他外力做功
3. 参考平面的选取不影响结果（$\Delta E_p$ 不变）
4. 机械能守恒 ≠ 动能守恒（动能可以变，只要动能减少的部分全转为势能）
