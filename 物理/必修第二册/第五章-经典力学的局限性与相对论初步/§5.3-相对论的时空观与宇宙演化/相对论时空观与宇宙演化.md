# 相对论时空观与宇宙演化

## 核心内容

### 三大相对论效应

| 效应 | 内容 | 公式 |
|---|---|---|
| **同时的相对性** | 在一个惯性系中同时的两个事件，在另一个惯性系中不一定同时 | — |
| **长度收缩（尺缩）** | 运动物体沿运动方向的长度变短 | $l = l_0\sqrt{1 - v^2/c^2}$ |
| **时间膨胀（钟慢）** | 运动时钟走得比静止时钟慢 | $\Delta t = \frac{\Delta t_0}{\sqrt{1 - v^2/c^2}}$ |

> $l_0$：物体在其静止参考系（固有参考系）中测量的长度
> $\Delta t_0$：事件在发生地参考系中的时间间隔（固有时间）

### 质能方程

$$E = mc^2$$

- 质量和能量**等价**
- 即使静止的物体也具有巨大的能量（静止能量）
- 核能释放的本质：质量亏损转化为能量

### 广义相对论（了解）

| 要点 | 内容 |
|---|---|
| 等效原理 | 引力效应等价于加速参考系的效应 |
| 时空弯曲 | 有质量的物体使周围时空弯曲 |
| 引力本质 | 物体沿弯曲时空的测地线运动 |
| 预言 | 光线弯曲（1919年日食证实）、引力波（2015年LIGO首次探测到） |

### 宇宙学（了解）

| 概念 | 内容 |
|---|---|
| 大爆炸假说 | 宇宙起源于约138亿年前的一次大爆炸 |
| 哈勃红移 | 远处星系光谱红移 → 星系远离我们 → 宇宙在膨胀 |
| 微波背景辐射 | 大爆炸的"余温"（约2.7 K），1965年发现 |
| 黑洞 | 引力极强，连光都无法逃脱的天体 |

## 易错点

1. 尺缩和钟慢是**相对效应**——双方互相认为对方的尺缩、钟慢
2. 尺缩只发生在**运动方向**上，垂直方向不收缩
3. $E = mc^2$ 中的 $m$ 是**静止质量**（现代物理学约定）
4. 钟慢效应已被实验证实（μ子寿命延长、铯原子钟飞行实验）
