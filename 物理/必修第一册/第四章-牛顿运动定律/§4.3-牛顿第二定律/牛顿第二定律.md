# 牛顿第二定律

## 定义

物体的加速度跟所受合力成正比，跟物体的质量成反比。加速度方向与合力方向相同。

$$\boxed{F_{\text{合}} = ma}$$

## 核心内容

### 公式的理解

| 要素 | 说明 |
|---|---|
| $F_{\text{合}}$ | 物体所受**所有外力的合力**，不是某一个力 |
| $m$ | 物体质量（kg） |
| $a$ | 加速度（m/s²），方向与 $F_{\text{合}}$ 相同 |

### 矢量性（分量形式）

$$F_{x\text{合}} = ma_x, \quad F_{y\text{合}} = ma_y$$

### 瞬时性

$F_{\text{合}}$ 与 $a$ 是**同时对应**的——力变则加速度立即变。

### 独立性

每个方向上的力独立决定该方向的加速度。

### 解题标准流程

1. 确定研究对象
2. 受力分析
3. 建坐标系
4. 正交分解
5. 列方程：$\sum F_x = ma_x$，$\sum F_y = ma_y$（或 $= 0$）
6. 解方程

### 两类基本问题

| 类型 | 已知 | 求 |
|---|---|---|
| 已知力求运动 | 力 → $a$ → $v$, $s$ | 运动学量 |
| 已知运动求力 | $v$, $s$ → $a$ → $F$ | 力 |

## 易错点

1. $F$ 是**合力**，不是某一个力
2. 加速度方向与**合力**方向相同，不一定与运动方向相同
3. 力减小 ≠ 减速！只要合力方向与运动方向相同，物体仍在加速（只是加速度减小了）
4. 单位必须统一为国际单位制（kg, m/s², N）
