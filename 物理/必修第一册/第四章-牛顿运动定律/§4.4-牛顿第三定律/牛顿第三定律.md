# 牛顿第三定律

## 定义

两个物体之间的作用力和反作用力总是大小相等、方向相反、作用在同一条直线上。

$$\boxed{F_{\text{甲对乙}} = -F_{\text{乙对甲}}}$$

## 核心内容

### 作用力与反作用力的特点

| 特点 | 说明 |
|---|---|
| 等大 | 始终大小相等 |
| 反向 | 方向相反 |
| 共线 | 在同一直线上 |
| 同时 | 同时产生、同时消失、同时变化 |
| 同性 | 性质相同（都是弹力/都是摩擦力/都是引力） |
| 异体 | 分别作用在两个不同物体上 |

### 作用力与反作用力 vs 一对平衡力

| | 作用力与反作用力 | 一对平衡力 |
|---|---|---|
| 作用对象 | **两个**不同物体 | **同一个**物体 |
| 是否共存 | 一定同时存在 | 可能有可能无 |
| 性质 | 一定相同 | 可以不同 |
| 能否抵消 | **不能**（不在同一物体上） | 能（合力为零） |

### 适用范围

- 静止和运动都适用
- 固体、液体、气体都适用
- 接触力和非接触力都适用

## 易错点

1. ❌"拔河赢了说明主动方拉力大"→ 双方拉力始终相等（赢是因为地面摩擦力大）
2. ❌"书压桌子的力和桌子对书的支持力是平衡力"→ 是作用力与反作用力（分别作用在桌子和书上）
3. ❌"作用力先产生，反作用力后产生"→ 同时产生
4. ❌"物体静止时才有反作用力"→ 任何时候都有
