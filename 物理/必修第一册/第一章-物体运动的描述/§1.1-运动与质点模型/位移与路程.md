# 位移与路程

## 定义

**位移（displacement）**：从初位置指向末位置的有向线段，是矢量，既有大小又有方向。

**路程（path length）**：物体运动轨迹的长度，是标量，只有大小没有方向。

## 核心内容

### 位移与路程的比较

| 比较 | 位移 | 路程 |
|------|------|------|
| 性质 | 矢量 | 标量 |
| 定义 | 初位置→末位置的有向线段 | 运动轨迹的总长度 |
| 方向 | 从初位置指向末位置 | 无方向 |
| 大小关系 | $\lvert\text{位移}\rvert \leq \text{路程}$ | 路程 $\geq$ 位移大小 |
| 等号成立 | 单向直线运动时相等 | — |

### 矢量与标量

- **矢量**：既有大小又有方向的物理量（如位移、速度、加速度）
- **标量**：只有大小没有方向的物理量（如路程、时间、速率）

### 坐标表示位置与位移

在一维坐标轴上：
- 位置用坐标 $x$ 表示
- 位移为坐标的变化量：

$$s = x - x_0$$

其中 $x_0$ 为初位置坐标，$x$ 为末位置坐标。

- $s > 0$：沿正方向运动
- $s < 0$：沿负方向运动

### 位移的图示

- 用从起点到终点的有向线段表示
- 线段长度表示位移大小
- 箭头指向表示位移方向

## 例题

<details>
<summary>例1：位移与路程的计算</summary>

**题目**：一个质点沿直线从 A 点出发，向东运动了 $3\text{ m}$ 到达 B 点，再向西运动了 $5\text{ m}$ 到达 C 点。求：
（1）质点的路程
（2）质点的位移

**解析**：
- 取向东为正方向，A 为原点
- B 点坐标：$x_B = +3\text{ m}$
- C 点坐标：$x_C = 3 - 5 = -2\text{ m}$

（1）路程 = 轨迹总长度 = $3 + 5 = 8\text{ m}$

（2）位移 $s = x_C - x_A = -2 - 0 = -2\text{ m}$

位移大小为 $2\text{ m}$，方向向西。

**答案**：路程为 $8\text{ m}$；位移大小为 $2\text{ m}$，方向向西。
</details>

<details>
<summary>例2：坐标与位移</summary>

**题目**：一质点在数轴上运动，$t = 0$ 时位于 $x_0 = -2\text{ m}$，$t = 3\text{ s}$ 时位于 $x = 4\text{ m}$。求这段时间内质点的位移。

**解析**：

$$s = x - x_0 = 4 - (-2) = 6\text{ m}$$

位移为 $+6\text{ m}$，方向沿 $x$ 轴正方向。

**答案**：位移为 $6\text{ m}$，方向沿 $x$ 轴正方向。
</details>

<details>
<summary>例3：位移与路程的关系</summary>

**题目**：一运动员沿 $400\text{ m}$ 跑道跑完一圈，用时 $50\text{ s}$。求运动员的位移和路程。

**解析**：
- 跑完一圈后回到起点，初位置 = 末位置
- 位移 = 末位置 - 初位置 = $0$
- 路程 = 轨迹长度 = $400\text{ m}$

**答案**：位移为 $0$；路程为 $400\text{ m}$。
</details>

## 易错点

1. **位移为零不代表没有运动**：物体回到出发点时位移为零，但路程不为零
2. **路程≠位移大小**：只有单方向直线运动时二者才相等
3. **位移方向不一定是运动方向**：位移方向由初末位置决定，与中间过程无关
4. **坐标的正负**：$s < 0$ 表示位移沿负方向，不能说"位移为负"就是没有位移
