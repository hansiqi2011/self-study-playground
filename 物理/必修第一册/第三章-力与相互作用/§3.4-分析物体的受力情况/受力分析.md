# 受力分析

## 定义

**受力分析**：确定研究对象所受的全部外力（大小、方向），并画出受力示意图。

---

## 核心内容

### 受力分析步骤

1. **明确研究对象**（隔离出来）
2. **画重力**（一定有）
3. **找接触力**：逐一检查研究对象与周围物体的接触面
   - 有接触 → 可能有弹力（是否有形变？）
   - 有接触 + 有相对运动或趋势 → 可能有摩擦力
4. **画受力示意图**

### 判断力是否存在的方法

| 力 | 产生条件 | 判断方法 |
|---|---|---|
| 重力 | 有质量 | 一定有 |
| 弹力 | 接触 + 形变 | "假设去掉接触面，物体会不会动？"会→有弹力 |
| 摩擦力 | 接触 + 相对运动或趋势 | "假设接触面光滑，物体会不会滑？"会→有摩擦力 |

### 隔离法

把某个物体从系统中**单独取出**进行分析的方法。

> 关键：只画**外力**（其他物体对研究对象的力），不画研究对象对别人的力。

### 经典案例：水平输送带

| 情况 | 受力 |
|---|---|
| 水平带 + 物体随带匀速 | 重力 + 支持力（无摩擦力！） |
| 倾斜带 + 物体随带匀速 | 重力 + 支持力 + 静摩擦力（沿带向上） |

---

## 易错点

1. **多画力**：凭空添加"下滑力""冲力""离心力"等不存在的力
2. **漏画力**：忘记检查某个接触面的摩擦力
3. **画了研究对象施加的力**（而非受到的力）
4. **水平输送带匀速运动时无摩擦力** → 无相对运动也无趋势
