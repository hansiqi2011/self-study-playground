# 力的合成

## 定义

**合力**：一个力如果能产生与几个力共同作用时相同的效果，这个力就是那几个力的合力。

**力的合成**：求几个力的合力。

核心方法：**平行四边形定则**

---

## 核心内容

### 平行四边形定则

以两个力 $F_1$、$F_2$ 为邻边构成平行四边形，**对角线**即为合力 $F$。

### 特殊情况

| 两力关系 | 合力大小 |
|---|---|
| 同向（$\theta = 0°$） | $F = F_1 + F_2$（最大） |
| 反向（$\theta = 180°$） | $F = |F_1 - F_2|$（最小） |
| 垂直（$\theta = 90°$） | $F = \sqrt{F_1^2 + F_2^2}$ |
| 任意角度 $\theta$ | $F = \sqrt{F_1^2 + F_2^2 + 2F_1 F_2 \cos\theta}$ |

### 合力范围

$$|F_1 - F_2| \leq F \leq F_1 + F_2$$

> 💡 合力不一定比分力大！当两力夹角 > 120° 且大小相等时，合力 < 任一分力。

### 矢量与标量

| | 矢量 | 标量 |
|---|---|---|
| 特点 | 有大小、有方向 | 只有大小 |
| 合成法则 | 平行四边形定则 | 算术加减 |
| 举例 | 力、位移、速度、加速度 | 质量、温度、时间、路程 |

## 例题

<details>
<summary>例题：斜拉桥钢索合力</summary>

**题目**：两根对称钢索与竖直方向夹角均为 30°，每根拉力 $F_1 = F_2 = 3 \times 10^4$ N。求合力。

**解答**：

对称 → 合力竖直向下。利用菱形对角线性质：

$$F = 2F_1 \cos 30° = 2 \times 3 \times 10^4 \times \frac{\sqrt{3}}{2} \approx 5.2 \times 10^4 \text{ N}$$

方向：竖直向下。
</details>

---

## 易错点

1. **合力不一定比分力大** → 只有当两力同向时合力最大；夹角大时合力可能比任一分力都小
2. **作图时比例要一致** → 图解法中力的线段长度必须严格按比例
3. **角度是两力之间的夹角** → 不是某一力与合力的夹角
4. **共点力要求** → 平行四边形定则只适用于共点力（作用在同一点或延长线交于同一点）
