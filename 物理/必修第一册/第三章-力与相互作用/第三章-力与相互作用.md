## 核心公式汇总

| 公式 | 表达式 | 适用条件 |
|---|---|---|
| 重力 | $G = mg$ | 任何有质量的物体 |
| 胡克定律 | $F = kx$ | 弹性限度内 |
| 滑动摩擦力 | $f = \mu N$ | 有相对滑动时 |
| 合力范围 | $|F_1 - F_2| \leq F \leq F_1 + F_2$ | 两个共点力 |
| 斜面分解 | $F_\parallel = mg\sin\theta$，$F_\perp = mg\cos\theta$ | 斜面上的重力 |
| 平衡条件 | $F_{\text{合}} = 0$ | 静止或匀速 |
