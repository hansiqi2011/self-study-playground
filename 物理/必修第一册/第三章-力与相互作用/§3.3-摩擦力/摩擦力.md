# 摩擦力

## 定义

两个相互接触的物体，当它们之间发生**相对运动**或**有相对运动趋势**时，在接触面上产生阻碍相对运动（或趋势）的力。

---

## 核心内容

### 滑动摩擦力

$$\boxed{f = \mu N}$$

- $f$：滑动摩擦力
- $\mu$：动摩擦因数（无单位），取决于材料和表面状况
- $N$：**法向压力**（不一定等于重力！）

方向：与**相对运动方向**相反

特点：
- 与接触面积**无关**
- 与相对运动速度大小**无关**

### 静摩擦力

物体间有相对运动**趋势**（但未实际滑动）时的摩擦力。

特点：
- 大小**可变**：$0 < f_{\text{静}} \leq f_{\max}$
- 方向：与**相对运动趋势**方向相反
- $f_{\max}$（最大静摩擦力）≈ 略大于滑动摩擦力（高中常近似相等）

### 两类摩擦力对比

| | 滑动摩擦力 | 静摩擦力 |
|---|---|---|
| 条件 | 有相对运动 | 有相对运动趋势 |
| 大小 | $f = \mu N$（固定值） | $0 < f \leq f_{\max}$（变力） |
| 方向 | 与相对运动方向相反 | 与相对运动趋势方向相反 |
| 能否用公式直接算 | 能 | 不能（需由平衡条件确定） |

## 例题

<details>
<summary>例题：叠放木块的摩擦力</summary>

**题目**：$G_A = 20$ N 的木块 A 放在桌面上，$\mu_A = 0.4$。
(1) 匀速拉动 A 的水平力多大？
(2) 在 A 上放 $G_B = 10$ N 的木块 B，A、B 一起匀速运动的水平力多大？

**解答**：
(1) $f = \mu_A N = 0.4 \times 20 = 8$ N → $F = 8$ N
(2) $N' = G_A + G_B = 30$ N，$f' = \mu_A N' = 0.4 \times 30 = 12$ N → $F' = 12$ N
</details>

---

## 易错点

1. **$N$ 不一定等于 $mg$** → 斜面上 $N = mg\cos\theta$；有竖直外力时 $N \neq mg$
2. **静摩擦力大小不能用 $\mu N$ 算** → 静摩擦力由平衡条件决定，$\mu N$ 只算滑动摩擦力
3. **摩擦力方向 ≠ 运动方向的反方向** → 是与"相对运动"方向相反。人走路时，脚相对地面向后滑 → 摩擦力向前（驱动力）
4. **$\mu$ 不是"摩擦力与压力的比"** → $\mu$ 是材料属性常数，不随 $f$ 或 $N$ 变化
