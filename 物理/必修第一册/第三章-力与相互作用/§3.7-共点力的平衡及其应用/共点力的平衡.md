# 共点力的平衡

## 定义

**平衡状态**：物体保持静止或做匀速直线运动。

**共点力平衡条件**：物体所受所有力的**合力为零**。

$$\boxed{F_{\text{合}} = 0}$$

即：$\sum F_x = 0$ 且 $\sum F_y = 0$（正交分解后各方向合力为零）

---

## 核心内容

### 二力平衡

两个力等大、反向、共线。

### 三力平衡

三力中任意两力的合力与第三力等大反向。

等价表述：三力首尾相连构成**封闭三角形**。

### 多力平衡的解题方法

**正交分解法**：
1. 受力分析
2. 建立坐标系（通常沿运动方向或沿接触面）
3. 将不在轴上的力分解
4. 列方程：$\sum F_x = 0$，$\sum F_y = 0$

---

## 例题

<details>
<summary>例题：斜面上物体的平衡</summary>

**题目**：物体重 $G = 20$ N，放在 $\theta = 30°$ 的粗糙斜面上静止。求支持力和摩擦力。

**解答**：

建立沿斜面和垂直斜面的坐标系：

垂直斜面方向：$N - G\cos 30° = 0 \Rightarrow N = 20 \times \frac{\sqrt{3}}{2} \approx 17.3$ N

沿斜面方向：$f - G\sin 30° = 0 \Rightarrow f = 20 \times 0.5 = 10$ N（方向沿斜面向上）
</details>

---

## 易错点

1. **平衡 ≠ 静止** → 匀速直线运动也是平衡状态
2. **"合力为零"不等于"没有力"** → 是所有力的矢量和为零
3. **三力平衡时第三力的方向** → 必须在另外两力合力的反方向上
4. **正交分解时坐标轴选取不当** → 导致多个力都需要分解，计算复杂化
