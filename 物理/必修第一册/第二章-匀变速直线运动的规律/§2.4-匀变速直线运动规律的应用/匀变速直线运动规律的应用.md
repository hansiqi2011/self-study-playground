# 匀变速直线运动规律的应用

## 核心方法

### 解题通用步骤

1. **分析运动过程**：明确是几段运动（匀速→匀减速？匀加速→匀速？）
2. **画运动示意图**：标出各段的 $v_0$、$v_t$、$a$、$s$、$t$
3. **选公式**：知三求二，选最直接的公式
4. **注意正负号和物理约束**：减速到零后是否继续？

---

## 核心内容

### 典型问题类型

#### 1. 刹车问题（含反应时间）

总停车距离 = 反应距离 + 制动距离

$$s_{\text{总}} = \underbrace{v_0 t_1}_{\text{反应时间内匀速}} + \underbrace{\frac{v_0^2}{2|a|}}_{\text{制动匀减速}}$$

> 💡 反应时间内汽车仍以原速匀速运动！

#### 2. 追及问题

两物体追及的条件：位移关系 + 速度关系

- 追上条件：$s_{\text{后}} = s_{\text{前}} + \Delta s_0$（$\Delta s_0$ 为初始间距）
- 恰好追上（临界条件）：追上时两者速度相等 $v_{\text{后}} = v_{\text{前}}$

#### 3. $v$-$t$ 图像辅助解题

$v$-$t$ 图像下方面积 = 位移

- 三角形面积：$s = \frac{1}{2}v_0 t$（从 $v_0$ 减速到 0）
- 梯形面积：$s = \frac{(v_0 + v_t)}{2} \cdot t$

### 公式选择策略

| 已知量 | 求什么 | 最优公式 |
|---|---|---|
| $v_0, a, t$ | $v_t$ 或 $s$ | $v_t = v_0 + at$ 和 $s = v_0t + \frac{1}{2}at^2$ |
| $v_0, v_t, s$ | $a$ 或 $t$ | $v_t^2 - v_0^2 = 2as$ |
| $v_0, v_t, t$ | $s$ | $s = \frac{(v_0 + v_t)}{2} \cdot t$ |

## 例题

<details>
<summary>例题1：高速公路安全车距</summary>

**题目**：汽车以 $v_0 = 120$ km/h = $33.3$ m/s 行驶，制动加速度 $a = -5$ m/s²，反应时间 $t_1 = 0.7$ s。求安全车距。

**解答**：

反应距离：$s_1 = v_0 t_1 = 33.3 \times 0.7 = 23.3$ m

制动时间：$t_2 = \frac{0 - 33.3}{-5} = 6.7$ s

制动距离：$s_2 = v_0 t_2 + \frac{1}{2}at_2^2 = 33.3 \times 6.7 + \frac{1}{2}(-5)(6.7)^2 = 110.9$ m

或更简洁：$s_2 = \frac{v_0^2}{2|a|} = \frac{33.3^2}{10} = 110.9$ m

安全车距：$s = s_1 + s_2 = 23.3 + 110.9 = 134.2$ m
</details>

<details>
<summary>例题2：判断是否超速</summary>

**题目**：限速 40 km/h 的路段，汽车急刹留下 9 m 车痕，滑行 1.5 s 后停止。判断是否超速。

**解答**：

匀减速从 $v_0$ 到 $0$，平均速度 $\bar{v} = \frac{s}{t} = \frac{9}{1.5} = 6$ m/s

由 $\bar{v} = \frac{v_0 + 0}{2}$ 得 $v_0 = 12$ m/s $= 43.2$ km/h $> 40$ km/h

**超速。**
</details>

## 易错点

1. **忘记反应时间** → 刹车总距离必须包含反应时间内的匀速位移
2. **追及问题不画图** → 容易搞混位移关系，务必画出两个物体的位置示意图
3. **"恰好追上"的临界条件理解错误** → 不是距离最小时追上，而是位移差 = 初始间距时追上
4. **多段运动各段衔接** → 前一段的末速度 = 后一段的初速度
