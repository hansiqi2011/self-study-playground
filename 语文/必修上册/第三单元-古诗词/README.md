# 第三单元 · 古诗词

## 单元主题

感受古代诗词的永恒魅力，体会不同时代诗人的情感世界。

## 学习目标

- 理解古诗词中的意象和意境
- 掌握用典、借景抒情等表达技巧
- 了解不同词牌/诗体的特点
- 能够赏析古诗词的思想内容和艺术特色

## 核心考点

1. **曹操**：求贤若渴，用典（周公吐哺/青青子衿/呦呦鹿鸣）
2. **陶渊明**：田园诗，"久在樊笼里，复得返自然"
3. **李白**：浪漫主义，梦境层递，"安能摧眉折腰事权贵"
4. **杜甫**："古今七律第一"，对仗工整，情景交融
5. **白居易**：音乐描写（大弦嘈嘈/小弦切切），"同是天涯沦落人"
6. **苏轼**：豪放词，怀古伤今，"人生如梦"
7. **辛弃疾**：用典最密（孙权/刘裕/刘义隆/佛狸祠/廉颇），壮志难酬
8. **李清照**：叠字开头14字，意象群（淡酒/晚风/过雁/黄花/梧桐/细雨）
9. **默写**：全部8首均需背诵
