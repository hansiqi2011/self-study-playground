# 永遇乐·京口北固亭怀古

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 辛弃疾（1140—1207），字幼安，号稼轩 |
| 时代 | 南宋 |
| 词牌 | 永遇乐 |
| 背景 | 1205年，66岁的辛弃疾任镇江知府，登北固亭有感而发 |

## 原文

千古江山，英雄无觅孙仲谋处。舞榜歌台，风流总被雨打风吹去。斜阳草树，寻常巷陌，人道寔奔曾住。想当年，金戈铁马，气吞万里如虎。

元嘉草草封狼居胥，赢得仓皇北顾。四十三年，望中犹记，烽火扬州路。可堪回首，佛狸祠下，一片神鸦社鼓。凭谁问：廉颇老矣，尚能饭否？

## 核心考点

### 主题
壮志难酬、忧国伤时、反对草率北伐。

### 用典详解（本词最重要考点）

| 典故 | 原事 | 词中用意 |
|---|---|---|
| **孙权** | 三国东吴大帝，曾在京口建都 | 怀念英雄，感叹英雄不再 |
| **寔奔处** | 南朝宋武帝刘裕的祖居 | 刘裕以京口为基地北伐成功，赞美其气魄 |
| **元嘉草草** | 宋文帝元嘉年间刘义隆草率北伐 | 警告草率出兵的恶果 |
| **佛狸祠** | 北魏太武帝拓跋焘的小名 | 汉族百姓忘记国耻，在敌人祠庙前赛神 | 
| **廉颇** | 战国赵国老将，怒而思战 | 自比廉颇，壮志未已但恐无人问津 |

### 结构
| 部分 | 内容 | 情感 |
|---|---|---|
| 上阕 | 孙权+刘裕（赞英雄） | 向往、敬仰 |
| 下阕前 | 刘义隆+佛狸祠（警戒+悲哀） | 警告、悲愤 |
| 下阕末 | 廉颇（自比） | 悲壮、无奈 |

## 重点字词

| 字词 | 含义 |
|---|---|
| 无觅 | 无处寻觅 |
| 舞榜歌台 | 歌舞升平的楼台 |
| 寔奔 | 刘裕小名 |
| 封狼居胥 | 封侯拜相（指北伐胜利后获封） |
| 仓皇 | 慈惶、惊慌 |
| 烽火 | 战火 |
| 可堪 | 不堀、哪堪 |
| 神鸦社鼓 | 祖庙前神鸦绕飞、社鼓喊嘻 |

## 易错点

- 本词用典最密，每个典故的指向必须记清：哪个是正面（孙权、刘裕），哪个是反面（刘义隆）
- “四十三年”是当年辛弃疾南下的时间，不是写这首词时的年龄
- “廉颇老矣，尚能饭否”是辛弃疾自比廉颇，担心无人起用自己
- “佛狸祠”写的是北方汉族百姓忘却国耻，不是写南方
