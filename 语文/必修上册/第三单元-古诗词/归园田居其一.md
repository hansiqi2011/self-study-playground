# 归园田居（其一）

## 作品信息

- **作者**：陶渊明（字元亮，号五柳先生，私谥靖节）
- **时代**：东晋
- **体裁**：五言古诗
- **出处**：《陶渊明集》
- **背景**：义熙元年（405年），陶渊明辞去彭泽县令，归隐田园，此组诗为归田初期所作

## 原文

> 少无适俗韵，性本爱丘山。
> 误落尘网中，一去三十年。
> 羁鸟恋旧林，池鱼思故渊。
> 开荒南野际，守拙归园田。
>
> 方宅十余亩，草屋八九间。
> 榆柳荫后檐，桃李罗堂前。
> 暧暧远人村，依依墟里烟。
> 狗吠深巷中，鸡鸣桑树颠。
>
> 户庭无尘杂，虚室有余闲。
> 久在樊笼里，复得返自然。

## 核心考点

### 主题思想

- **厌恶官场**：以"尘网""樊笼"比喻官场束缚
- **回归自然**：表达对田园生活的热爱与归隐的喜悦
- **守拙全真**：不愿为五斗米折腰，保持本真

### 结构层次

| 层次 | 内容 | 情感 |
|------|------|------|
| 第1-8句 | 回顾仕途，说明归田原因 | 悔恨、庆幸 |
| 第9-16句 | 描绘田园风光 | 宁静、喜悦 |
| 第17-20句 | 抒发归田感受 | 自由、释然 |

### 艺术手法

| 手法 | 示例 | 分析 |
|------|------|------|
| 比喻 | "误落尘网中" | 以"尘网"喻官场 |
| 比喻 | "羁鸟恋旧林，池鱼思故渊" | 以笼中鸟、池中鱼自比，表达对自由的渴望 |
| 白描 | "方宅十余亩，草屋八九间" | 朴素写实，不事雕琢 |
| 动静结合 | "狗吠深巷中，鸡鸣桑树颠" | 以动衬静，突出田园宁静 |
| 远近结合 | 近处方宅草屋→远处暧暧村落 | 层次分明的田园全景 |
| 对比 | 尘网/樊笼 vs 园田/自然 | 官场与田园的对立 |

### 默写重点句

1. "羁鸟恋旧林，池鱼思故渊。"——比喻渴望自由
2. "暧暧远人村，依依墟里烟。"——远景白描
3. "久在樊笼里，复得返自然。"——全诗主旨句

## 重点字词

| 词语 | 释义 |
|------|------|
| 适俗韵 | 迎合世俗的气质（适：迎合） |
| 尘网 | 比喻官场（尘：尘世） |
| 三十年 | 一说"十三年"（从出仕到辞官） |
| 羁鸟 | 被关在笼中的鸟（羁：束缚） |
| 守拙 | 守住自己的愚拙本性（不善逢迎） |
| 荫 | 遮蔽（yìn，名词作动词） |
| 罗 | 排列（名词作动词） |
| 暧暧 | 昏暗朦胧的样子 |
| 依依 | 轻柔飘动的样子 |
| 墟里 | 村落（墟：同"墟"，集市/村落） |
| 颠 | 顶端，树梢 |
| 尘杂 | 尘俗杂事 |
| 虚室 | 空旷的居室 |
| 樊笼 | 关鸟兽的笼子，比喻官场 |

## 易错点

1. **"暧暧"** 易误写为"暖暖"——暧（ài）是昏暗朦胧之义
2. **"依依墟里烟"** "墟"易误写为"虚"——墟是村落之意
3. **"鸡鸣桑树颠"** "颠"非"巅"——颠即顶端，通用
4. **"一去三十年"** 版本异文：有版本作"十三年"，需按课本为准
5. **主旨理解**：不可简单理解为消极避世，应理解为对人格独立和精神自由的追求
