# 短歌行

## 作品信息

- **作者**：曹操（字孟德）
- **时代**：东汉末
- **体裁**：乐府诗（四言）
- **出处**：《曹操集》
- **背景**：建安十三年（208年）赤壁之战前后，曹操大宴群臣，横槊赋诗，抒发求贤之志

## 原文

> 对酒当歌，人生几何！
> 譬如朝露，去日苦多。
> 慨当以慷，忧思难忘。
> 何以解忧？唯有杜康。
>
> 青青子衿，悠悠我心。
> 但为君故，沉吟至今。
> 呦呦鹿鸣，食野之苹。
> 我有嘉宾，鼓瑟吹笙。
>
> 明明如月，何时可掇？
> 忧从中来，不可断绝。
> 越陌度阡，枉用相存。
> 契阔谈讌，心念旧恩。
>
> 月明星稀，乌鹊南飞。
> 绕树三匝，何枝可依？
> 山不厌高，海不厌深。
> 周公吐哺，天下归心。

## 核心考点

### 主题思想

- **求贤若渴**：渴望天下贤才归附
- **统一天下的壮志**：以周公自比，表达收揽人才、建功立业的雄心
- **时光短暂的忧思**：人生苦短与功业未成的焦虑

### 艺术手法

| 手法 | 示例 | 分析 |
|------|------|------|
| 用典 | "青青子衿，悠悠我心" | 化用《诗经·郑风·子衿》，表达对贤才的思念 |
| 用典 | "呦呦鹿鸣，食野之苹" | 化用《诗经·小雅·鹿鸣》，表达礼遇贤才之意 |
| 用典 | "周公吐哺，天下归心" | 化用周公"一沐三握发，一饭三吐哺"典故，表达求贤之诚 |
| 比兴 | "明明如月，何时可掇" | 以明月比贤才，可望不可即 |
| 比兴 | "月明星稀，乌鹊南飞" | 以乌鹊择枝比贤才择主 |
| 比喻 | "譬如朝露" | 以朝露喻人生短暂 |

### 默写重点句

1. "对酒当歌，人生几何！譬如朝露，去日苦多。"——感叹时光易逝
2. "青青子衿，悠悠我心。但为君故，沉吟至今。"——求贤若渴
3. "山不厌高，海不厌深。周公吐哺，天下归心。"——篇末抒志

## 重点字词

| 词语 | 释义 |
|------|------|
| 当歌 | 应当高歌（当：应当） |
| 杜康 | 相传酿酒始祖，借代酒 |
| 子衿 | 你的衣领，代指贤才 |
| 沉吟 | 沉思吟味 |
| 掇 | 拾取，摘取 |
| 越陌度阡 | 穿过田间小路（陌：南北小路；阡：东西小路） |
| 枉用相存 | 屈驾来访问我（枉：屈就；存：问候） |
| 契阔 | 聚散，偏指久别 |
| 谈讌 | 同"谈宴"，设宴交谈 |
| 匝 | 周，圈 |
| 厌 | 同"餍"，满足 |
| 吐哺 | 吐出嘴里的食物，形容求贤心切 |

## 易错点

1. **"慨当以慷"** 易误写为"慷慨"——此处是乐府诗音节需要的倒装
2. **"何时可掇"** "掇"易误写为"辍"或"缀"——掇（duō）是摘取之意
3. **"枉用相存"** "存"的含义是"问候"而非"存在"
4. **"契阔谈讌"** "讌"通"宴"，非"燕"
5. **用典出处混淆**："青青子衿"出自《诗经·郑风》，"呦呦鹿鸣"出自《诗经·小雅》
