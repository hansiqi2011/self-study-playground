# 琵琶行并序

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 白居易（772—846），字乐天，号香山居士 |
| 时代 | 唐代 |
| 写作时间 | 元和十一年（816）秋 |
| 体裁 | 七言古诗（长篇叙事诗） |
| 背景 | 谪居浔阳期间，浔阳江头送客 |

## 核心考点

### 主题
“同是天涯沦落人，相逢何必曾相识”——借琵琶女的不幸身世抒发自己被谪的苦闷。

### 结构
| 部分 | 内容 | 作用 |
|---|---|---|
| 序 | 交代写作缘由 | 背景铺垫 |
| 第一段 | 江头送客闻琵琶 | 引出人物 |
| 第二段 | 琵琶女演奏 | 音乐描写高潮 |
| 第三段 | 琵琶女自述身世 | 对比发展 |
| 第四段 | 诗人感慨，再奠琵琶 | 主题升华 |

### 音乐描写（最重要考点）

| 比喻 | 原句 | 音乐特点 |
|---|---|---|
| 急雨 | 大弦嘈嘈如急雨 | 粗重急促 |
| 私语 | 小弦切切如私语 | 细腥轻柔 |
| 珠落玉盘 | 大珠小珠落玉盘 | 清脆圆润 |
| 鸟语花底 | 间关莺语花底滑 | 婉转流畅 |
| 冰泉冷涩 | 幽咽泉流冰下难 | 低沉停止 |
| 银瓶乍破 | 银瓶乍破水浆迸 | 突然爆发 |
| 刀枪鸣 | 铁骑突出刀枪鸣 | 激烈雄壮 |

### 关键默写句

1. “千呼万唤始出来，犹抱琵琶半遮面”
2. “大弦嘈嘈如急雨，小弦切切如私语”
3. “嘈嘈切切错杂弹，大珠小珠落玉盘”
4. “别有幽愁暗恨生，此时无声胜有声”
5. “同是天涯沦落人，相逢何必曾相识”

## 重点字词

| 字词 | 含义 |
|---|---|
| 浔浂(pén pǔ) | 地名，今江西九江 |
| 转徒 | 转任江州司马 |
| 捷 | 效率高，敏捷 |
| 钿(bò) | 用手指或工具拨弦 |
| 唛(yǎ) | 压，这里指借助按弦的技法 |
| 吼 | 动物口中含着和鸣的声音 |
| 却坐促弦 | 退回坐下重新弹奏 |
| 整顿衣裳起敦容 | 整理衣服端正容貌 |

## 易错点

- “嘈嘈”“切切”是拟声词，不要写成“嘲嘲”“切切”
- “此时无声胜有声”——无声是音乐的休止，不是真的没有声音
- “序”中的信息与正文对应关系要清楚
- “江州司马”不是大官，是谪官——理解诗人的失落感
