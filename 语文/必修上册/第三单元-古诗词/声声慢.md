# 声声慢（寻寻觅觅）

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 李清照（1084—1155），号易安居士 |
| 时代 | 南宋 |
| 词牌 | 声声慢 |
| 背景 | 南渡后晚年之作，国破家亡夫死 |

## 原文

寻寻觅觅，冷冷清清，凄凄惨惨戚戚。乍暖还寒时候，最难将息。三杯两盏淡酒，怎敌他、晚来风急！雁过也，正伤心，却是旧时相识。

满地黄花堆积，憔悴损，如今有谁堪摘？守着窗儿，独自怎生得黑！梧桐更兼细雨，到黄昏、点点滴滴。这次第，怎一个愁字了得！

## 核心考点

### 主题
国破家亡后的极度愁苦和孤寂。

### 词的结构与情感层次
| 层次 | 内容 | 情感 |
|---|---|---|
| 开篇14叠字 | 寻寻觅觅冷冷清清凄凄惨惨戚戚 | 定调：孤寂凄凉 |
| 淡酒/晚风 | 三杯两盏淡酒敌不过晚风 | 无法消愁 |
| 过雁 | 旧时相识（双关：往年传书雁） | 物是人非 |
| 黄花 | 憔悴损无人摘 | 自伤老去 |
| 梧桐/细雨 | 点点滴滴到黄昏 | 愁绝少 |
| 结尾 | 怎一个愁字了得 | 愁之深溢于言表 |

### 艺术特色
1. **叠字**：开头14个叠字，音乐性极强，层层递进（动作→环境→感受）
2. **意象群**：淡酒→晚风→过雁→黄花→梧桐→细雨，全是愁的载体
3. **直接抒情+借景抒情**结合

## 重点字词

| 字词 | 含义 |
|---|---|
| 戚戚 | 忧愁的样子 |
| 乍暖还寒 | 刚刚暖和又转冷（亦指心境） |
| 将息 | 休息、调养 |
| 憔悴损 | 憔悴得满身憐悟 |
| 堪 | 能够、可以 |
| 次第 | 光景、情形 |
| 了得 | 完结、概括 |

## 易错点

- 14个叠字的层次分法：寻寻觅觅(动作——寻找无果) → 冷冷清清(环境——寒冷凄清) → 凄凄惨惨戚戚(心境——极度悲苦)
- “雁过也，正伤心，却是旧时相识”——双关意：雁是当年传书的雁，也是“云中谁寄锦书来”的雁
- “满地黄花堆积”的黄花=菊花，不是任何黄色的花
- “怎一个愁字了得”不是“不愁”，而是“愁已不足以表达”
