# 登高

## 作品信息

- **作者**：杜甫（字子美，自号少陵野老）
- **时代**：唐
- **体裁**：七言律诗
- **出处**：《杜工部集》
- **背景**：大历二年（767年）秋，杜甫流寓夔州（今重庆奉节），重阳登高所作。时年56岁，身患多病，国事艰难
- **评价**：被明代胡应麟誉为"古今七律第一"

## 原文

> 风急天高猿啸哀，渚清沙白鸟飞回。
> 无边落木萧萧下，不尽长江滚滚来。
> 万里悲秋常作客，百年多病独登台。
> 艰难苦恨繁霜鬓，潦倒新停浊酒杯。

## 核心考点

### 主题思想

- **悲秋伤怀**：借重阳登高写秋景之萧瑟
- **漂泊之苦**：长年客居异乡的孤独悲凉
- **忧国忧民**：个人命运与国家命运交织（"艰难"双关）

### 结构分析

| 部分 | 内容 | 手法 |
|------|------|------|
| 首联 | 近景：风、天、猿、渚、沙、鸟 | 工笔细描，六意象一句 |
| 颔联 | 远景：落木、长江 | 宏大壮阔，以景衬情 |
| 颈联 | 抒情：万里漂泊、多病登台 | 直抒胸臆 |
| 尾联 | 收束：国难身衰、停酒添愁 | 含蓄蕴藉 |

**前四句写景（秋天长江峡口），后四句抒情（漂泊多病）**

### 艺术手法

| 手法 | 示例 | 分析 |
|------|------|------|
| 对仗工整 | 全诗八句皆对（四联全对，极为罕见） | 首联"风急"对"渚清"，颔联"无边"对"不尽" |
| 情景交融 | "无边落木萧萧下" | 秋景之萧瑟即心境之悲凉 |
| 借景抒情 | 首联、颔联 | 萧瑟秋景烘托悲凉心境 |
| 夸张 | "万里""百年" | 极言漂泊之远、人生之短 |

### 颈联"八悲"（宋人罗大经析）

万里——地之远；悲秋——时之惨；作客——羁旅；常——久旅不归；百年——暮齿；多病——衰疾；登台——高处生悲；独——无亲朋

### 默写重点句

1. "无边落木萧萧下，不尽长江滚滚来。"——壮阔秋景
2. "万里悲秋常作客，百年多病独登台。"——集中抒悲
3. "艰难苦恨繁霜鬓，潦倒新停浊酒杯。"——以酒衬愁

## 重点字词

| 词语 | 释义 |
|------|------|
| 渚 | 水中小洲 |
| 回 | 回旋盘桓 |
| 落木 | 落叶（"木"比"叶"更显枯黄质感） |
| 萧萧 | 风吹落叶声 |
| 万里 | 远离故乡万里（夔州距长安极远） |
| 百年 | 一生，此指暮年 |
| 作客 | 客居他乡（非"做客"） |
| 艰难 | 双关：国事艰难+个人境遇困难 |
| 苦恨 | 极恨，深为遗憾 |
| 繁霜鬓 | 白发增多如霜（繁：使动，使增多） |
| 潦倒 | 衰颓失意 |
| 新停 | 刚刚停止（因病不能饮酒） |

## 易错点

1. **"渚清沙白鸟飞回"** "回"非"徊"——回指盘旋飞回
2. **"作客"与"做客"** 作客=客居异乡（漂泊）≠做客（访友）
3. **"艰难"的双重含义** 既指国事艰难（安史之乱后），又指个人生活潦倒
4. **"新停浊酒杯"** 是因病新近被迫戒酒，非自愿戒酒——添一层愁苦
5. **四联全对** 律诗通常只要求颔联颈联对仗，此诗四联皆工对，是格律的极致
