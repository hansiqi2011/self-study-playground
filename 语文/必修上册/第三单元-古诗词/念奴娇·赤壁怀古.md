# 念奴娇·赤壁怀古

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 苏轼（1037—1101），字子瞻，号东坡居士 |
| 时代 | 北宋 |
| 写作时间 | 1082年（谪居黄州期间） |
| 词牌 | 念奴娇 |
| 风格 | 豪放词代表作 |

## 原文

大江东去，浪淊尽，千古风流人物。故垒西边，人道是，三国周郎赤壁。乱石穿空，惊涛拍岸，卷起千堆雪。江山如画，一时多少豪杰。

遥想公礹当年，小乔初嫁了，雄姿英发。羽扇纶巾，谈笑间，樯橹灰飞烟灭。故国神游，多情应笑我，早生华发。人生如梦，一尊还酬江月。

## 核心考点

### 主题
怀古伤今，借周瑙英雄业绩反衬自己壮志难酬，最终归于旷达。

### 结构
| 部分 | 内容 | 手法 |
|---|---|---|
| 上阕 | 赤壁壮景 + 英雄感慰 | 写景拓开 |
| 下阕前半 | 周瑙雄姿英发 | 写人对比 |
| 下阕后半 | 感叹早生华发→人生如梦 | 抒情旷达 |

### 重点意象
- 大江东去——历史流逝
- 乱石/惊涛/千堆雪——壮观景象
- 羽扇纶巾——儒雅从容
- 江月——永恒自然

## 重点字词

| 字词 | 含义 |
|---|---|
| 浪淊 | 浪花冲刷 |
| 故垒 | 旧时兵营的围墙 |
| 纶巾 | 丝帻做的头巾 |
| 樯橹(qiáng lǔ) | 船桨和船桩 |
| 尊(zūn) | 同“樽”，酒杯 |
| 酬 | 敷衔，这里指以酒浇地 |
| 华(huā)发 | 白发 |
| 公琹 | 周瑙，字公琹 |

## 易错点

- “故垒”不是“坡”，是土山/塔堡
- “尊”的古今异义：古=酒器，今=尊重
- “多情应笑我”断句争议：“多情应笑，我早生华发” or “多情应笑我早生华发”
- “人生如梦”不是消极厥世，而是旷达超脱
