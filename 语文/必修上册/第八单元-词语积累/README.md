# 第八单元 · 词语积累与词语解释

## 单元主题

学习词语知识，丰富语言积累，提高词语运用能力。

## 活动内容

1. **丰富词语积累** —— 多渠道积累词语、辨析近义词
2. **把握古今词义的联系与区别** —— 古今异义、词义演变
3. **词义的辨析和词语的使用** —— 语境义、感情色彩、搭配

## 核心知识

| 知识点 | 内容 |
|---|---|
| 古今异义 | 妻子/交通/卑鄙/虽然 等 |
| 一词多义 | 根据语境判断词义 |
| 近义词辨析 | 词义轻重/范围大小/感情色彩/搭配习惯 |
| 词义演变 | 扩大/缩小/转移/感情色彩变化 |
| 语境义 | 结合上下文理解临时含义 |
