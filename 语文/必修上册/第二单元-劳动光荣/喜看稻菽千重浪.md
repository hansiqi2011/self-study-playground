# 喜看稻菽千重浪——记首届国家最高科技奖获得者袁隆平

## 作品信息

| 项目 | 内容 |
|------|------|
| 作者 | 沈英甲 |
| 体裁 | 人物通讯 |
| 来源 | 《科技日报》2001年2月22日 |
| 背景 | 2001年袁隆平获得首届国家最高科学技术奖，本文为获奖报道 |

## 原文（关键段落）

> 标题化用毛泽东《七律·到韶山》诗句"喜看稻菽千重浪，遍地英雄下夕烟"

开头：2001年2月19日，中共中央、国务院隆重举行国家科学技术奖励大会，授予湖南杂交水稻研究中心研究员、中国工程院院士袁隆平2000年度国家最高科学技术奖。

（全文以"曾记否，到中流击水""创新是科学家的灵魂和本质""事实是科学家的空气""饥饿的威胁在退却"四个小标题组织材料）

## 核心考点

### 1. 文章结构与写法
- **小标题结构**：四个小标题各选取典型事例，多角度展现袁隆平的精神品质
- **核心手法**：用具体事例表现人物品质（以事写人）
- **倒叙开头**：以颁奖大会开头，设置悬念，引出人物

### 2. 人物形象分析
| 品质 | 对应事例 |
|------|----------|
| 创新精神 | 敢于挑战权威，提出杂交水稻理论 |
| 实事求是 | 坚持田间实验，用事实说话 |
| 坚韧不拔 | 文革期间坚持研究，历经挫折不放弃 |
| 心系天下 | 致力解决全人类的粮食问题 |

### 3. 人物通讯的特点
- 真实性：以真实人物和事件为基础
- 典型性：选择最能表现人物精神的事例
- 文学性：运用描写、叙议结合等手法增强感染力
- 新闻性：有明确的时效性和社会价值

### 4. 标题赏析
- "喜看"：表达喜悦、赞美之情
- "稻菽千重浪"：化用诗句，形象写出丰收景象，暗扣袁隆平的功绩
- 副标题点明新闻由头

## 重点字词

| 词语 | 释义 |
|------|------|
| 稻菽 | 稻子和豆类，泛指粮食作物 |
| 刻骨铭心 | 比喻记忆深刻，难以忘记 |
| 义无反顾 | 从道义上只有勇往直前，不能犹豫回顾 |
| 矢志不移 | 立下志愿绝不改变 |
| 淡泊名利 | 对名利看得很淡，不追求 |

## 易错点

1. 体裁判断：本文是**人物通讯**（新闻体裁），不是人物传记（文学体裁）
2. 通讯与消息的区别：通讯篇幅长、细节多、时效性相对弱、文学性强
3. 标题出处："喜看稻菽千重浪"出自毛泽东《七律·到韶山》，不是袁隆平的话
4. 小标题的作用：不仅是结构划分，也是对人物精神品质的高度概括
