# 心有一团火，温暖众人心

## 作品信息

| 项目 | 内容 |
|------|------|
| 作者 | 林为民 |
| 体裁 | 人物通讯 |
| 来源 | 《人民日报》 |
| 人物 | 张秉贵（北京百货大楼糖果柜台售货员） |
| 背景 | 张秉贵以"一团火"精神服务顾客三十余年，被授予全国劳动模范称号 |

## 原文（关键段落）

开头：张秉贵是北京百货大楼糖果柜台的售货员。他凭着"一团火"的服务精神，在平凡的岗位上做出了不平凡的业绩。

关键细节：
- "一抓准"——一把抓糖，份量准确
- "一口清"——算账又快又准
- 主动为顾客排忧解难，以热情化解矛盾

## 核心考点

### 1. 人物形象
| 品质 | 具体表现 |
|------|----------|
| 热情服务 | 对每位顾客都像对待亲人，"一团火"精神 |
| 精益求精 | 练就"一抓准""一口清"的过硬本领 |
| 无私奉献 | 在平凡岗位上数十年如一日 |
| 细心体贴 | 能察觉顾客的情绪和需求 |

### 2. 写作技巧
- **以小见大**：通过日常售货的细节展现人物精神
- **正面描写与侧面描写结合**：既有张秉贵的言行，也有顾客的反馈
- **典型事例选取**：选择最能体现"一团火"精神的场景
- **细节描写**：动作描写精细传神

### 3. 标题特点
- "一团火"是核心意象/比喻：喻指张秉贵的服务热情
- "心有"→"温暖"：内在品质到外在效果的因果关系
- 标题即文眼，统摄全文

### 4. 与《喜看稻菽千重浪》的比较
| 比较项 | 本文 | 《喜看稻菽千重浪》 |
|--------|------|---------------------|
| 人物领域 | 普通劳动者 | 科学家 |
| 组织方式 | 时间线+典型场景 | 小标题分节 |
| 侧重点 | 服务精神与细节 | 科学精神与成就 |
| 共同点 | 都以具体事例表现品质 | 同 |

## 重点字词

| 词语 | 释义 |
|------|------|
| 和颜悦色 | 脸色和蔼喜悦，形容态度温和亲切 |
| 体贴入微 | 照顾或关心非常细致周到 |
| 全神贯注 | 精力高度集中 |
| 炉火纯青 | 比喻功夫达到了纯熟完美的境界 |

## 易错点

1. 这是**自读课文**，考试直接出题概率低，但人物通讯的写法分析可能与精读课文对比考查
2. "一团火"不仅是比喻，更是贯穿全文的线索
3. 不要将本文简单归为"好人好事"报道——它体现的是对平凡劳动的尊重与赞美
