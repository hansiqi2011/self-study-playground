# 芣苢

## 作品信息

| 项目 | 内容 |
|------|------|
| 出处 | 《诗经·周南》 |
| 时代 | 先秦（西周至春秋） |
| 体裁 | 四言诗 |
| 内容 | 描写妇女采摘车前草（芣苢）的劳动场景 |
| 地位 | 高中必背篇目 |

## 原文

采采芣苢，薄言采之。
采采芣苢，薄言有之。

采采芣苢，薄言掇之。
采采芣苢，薄言捋之。

采采芣苢，薄言袺之。
采采芣苢，薄言襭之。

## 核心考点

### 1. 重章叠句手法（全诗核心）
- **结构**：三章六句，每章仅换一个动词
- **效果**：
  - 形成回环往复的节奏美和音乐美
  - 表现劳动过程的推进（动作递进）
  - 渲染劳动的欢快气氛
  - 强化情感表达

### 2. 六个关键动词（必考）

| 动词 | 读音 | 含义 | 动作阶段 |
|------|------|------|----------|
| 采 | cǎi | 采摘 | 开始采摘 |
| 有 | yǒu | 取得、获取 | 已经采到 |
| 掇 | duō | 拾取、摘取 | 一片片摘取 |
| 捋 | luō | 用手成把地捋取 | 成把地捋 |
| 袺 | jié | 提起衣襟兜住 | 用衣襟兜 |
| 襭 | xié | 把衣襟掖在腰带上兜住 | 把衣襟掖好兜满 |

**递进关系**：从零星采摘 → 逐渐增多 → 满载而归

### 3. 艺术手法
| 手法 | 分析 |
|------|------|
| 赋 | 直接铺陈叙述采摘过程（诗经"赋"的典型） |
| 重章叠句 | 全诗反复咏唱，仅更换动词 |
| 动作描写 | 六个动词精准呈现劳动全过程 |

### 4. 默写重点句
- 全文六句均为常考默写范围
- 高频考法：给出某动词，要求补全上下句

### 5. 重要注释

| 词语 | 释义 |
|------|------|
| 芣苢（fú yǐ） | 车前草，可食用、可入药 |
| 采采 | 茂盛的样子（一说"采了又采"） |
| 薄言 | 助词，无实义（发语词，凑足音节） |
| 袺（jié） | 提起衣襟兜东西 |
| 襭（xié） | 把衣襟掖在腰带上兜东西 |

## 重点字词

| 字词 | 注音 | 释义 |
|------|------|------|
| 芣苢 | fú yǐ | 车前草 |
| 薄言 | bó yán | 语助词，无实义 |
| 掇 | duō | 拾取 |
| 捋 | luō | 成把地取 |
| 袺 | jié | 提起衣襟兜住 |
| 襭 | xié | 把衣襟掖在带间兜住 |

## 易错点

1. **字音**：芣苢（fú yǐ）不读"bù yǐ"；掇（duō）不读"chuò"；捋（luō）不读"lǚ"；袺（jié）不读"jí"；襭（xié）不读"qì"
2. **"薄言"理解**：是助词/语气词，无实义，不能翻译为"说"
3. **"采采"释义**：主流解释为"茂盛的样子"（形容芣苢），而非"采了又采"（动作）
4. **手法判断**：本诗用的是"赋"（铺陈直叙），不是"比"也不是"兴"
5. **六个动词的顺序**：采→有→掇→捋→袺→襭，体现动作递进，不可打乱
6. **默写易混**：袺和襭字形相近，注意区分——袺是"提起衣襟"，襭是"掖在腰带上"
