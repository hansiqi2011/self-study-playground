# 插秧歌

## 作品信息

| 项目 | 内容 |
|------|------|
| 作者 | 杨万里 |
| 朝代 | 南宋 |
| 体裁 | 七言古诗 |
| 风格 | "诚斋体"——活泼自然、语言口语化 |
| 地位 | 高中必背篇目 |

## 原文

田夫抛秧田妇接，小儿拔秧大儿插。
笠是兜鍪蓑是甲，雨从头上湿到胛。
唤渠朝餐歇半霎，低头折腰只不答。
秧根未牢莳未匝，照管鹅儿与雏鸭。

## 核心考点

### 1. 诗歌内容逐联分析

| 联 | 内容 | 描写角度 |
|----|------|----------|
| 首联 | 全家协作插秧（抛、接、拔、插） | 劳动场面·分工 |
| 颔联 | 雨中劳作，笠如兜鍪蓑如甲 | 劳动环境·比喻 |
| 颈联 | 家人唤吃饭，农夫不答 | 劳动态度·侧面 |
| 尾联 | 嘱咐看好鹅鸭别吃秧苗 | 劳动心态·口语 |

### 2. 主题思想
- 表现农家插秧劳动的**紧张忙碌**
- 体现劳动者的**勤劳专注**
- 洋溢着劳动的**生活气息和乐趣**
- 全家齐上阵的**协作精神**

### 3. 艺术手法

| 手法 | 具体分析 |
|------|----------|
| 白描 | 直接描绘插秧场景，不加雕饰 |
| 比喻 | "笠是兜鍪蓑是甲"——把劳动比作战斗，表现紧张 |
| 口语化 | "唤渠""歇半霎""照管"等方言口语入诗 |
| 对偶 | "田夫抛秧田妇接，小儿拔秧大儿插" |
| 侧面描写 | 通过"不答"表现劳动的专注 |

### 4. "笠是兜鍪蓑是甲"赏析（高频考点）
- **兜鍪**：古代头盔；**甲**：铠甲
- 把斗笠比作头盔，蓑衣比作铠甲
- 将插秧比拟为一场与天气、与时间的"战斗"
- 表现劳动的紧张艰苦，也有农人乐观的幽默感

### 5. 默写重点句
- "笠是兜鍪蓑是甲，雨从头上湿到胛"——写雨中劳作的艰辛
- "秧根未牢莳未匝，照管鹅儿与雏鸭"——写劳动者的专注与细心

## 重点字词

| 字词 | 注音 | 释义 |
|------|------|------|
| 兜鍪 | dōu móu | 古代战士的头盔 |
| 胛 | jiǎ | 肩胛，肩背部 |
| 渠 | qú | 他（方言代词） |
| 半霎 | bàn shà | 很短的时间 |
| 莳 | shì | 移栽，种植 |
| 匝 | zā | 满、遍 |
| 照管 | zhào guǎn | 照看、看管 |

## 易错点

1. **体裁判断**：这是**七言古诗**（古体诗），不是律诗——不严格要求平仄对仗
2. **"兜鍪"的写法**：鍪（móu）不要写成"鉾"或"矛"
3. **"渠"的理解**：此处是方言代词"他"，不是"水渠"
4. **"莳未匝"**：莳=移栽种植，匝=满/遍；意思是"秧苗还没栽满（田地）"
5. **诗歌风格**：杨万里"诚斋体"特点是活泼自然、善用口语，不同于同时期陆游的沉郁
6. **尾联理解**："照管鹅儿与雏鸭"是农夫对唤他吃饭之人的回答——意思是"别来烦我，去看好鹅鸭别让它们糟蹋秧苗"，不是在描述另一件事
