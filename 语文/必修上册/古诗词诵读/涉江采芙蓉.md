# 涉江采芙蓉

## 作品信息

- **出处**：《古诗十九首》（第六首）
- **时代**：东汉末年
- **作者**：无名氏（文人五言诗）
- **收录**：萧统《文选》
- **体裁**：五言古诗
- **地位**：《古诗十九首》代表作，全文背诵篇目

---

## 原文

涉江采芙蓉，兰泽多芳草。
采之欲遗谁？所思在远道。
还顾望旧乡，长路漫浩浩。
同心而离居，忧伤以终老。

---

## 核心考点

### 主题思想

表现游子思乡、夫妻离别之苦。诗歌以采芙蓉起兴，写游子漂泊在外，思念故乡妻子（或妻子思念远行丈夫），最终以"同心而离居"的悲叹作结，深沉感人。

### 艺术手法

| 手法 | 分析 |
|------|------|
| 悬想（对写法） | 从对方角度写相思——"还顾望旧乡"可理解为诗人想象对方也在远望自己，虚实交融 |
| 意象营造 | 芙蓉（荷花）、兰泽、芳草——以美好事物反衬离别之苦，乐景写哀 |
| 起兴 | 以采芙蓉起兴，引出思念远人的主题 |
| 直抒胸臆 | "同心而离居，忧伤以终老"直接倾诉离愁 |
| 以乐写哀 | 芙蓉兰草的美景与离别痛苦形成对比 |

### 名句默写重点

- "涉江采芙蓉，兰泽多芳草"（起句写景）
- "采之欲遗谁？所思在远道"（一问一答，点出思念）
- "还顾望旧乡，长路漫浩浩"（空间距离写心理距离）
- **"同心而离居，忧伤以终老"**（全诗情感高潮，最常考）

### 意象分析

| 意象 | 含义 |
|------|------|
| 芙蓉 | 荷花，象征高洁美好，也是爱情信物（"芙蓉"谐音"夫容"） |
| 兰泽 | 长满兰草的水泽，象征美好环境 |
| 芳草 | 美好事物，亦有思念的象征意味 |
| 长路 | 阻隔两人的空间距离，象征无法逾越的分离 |
| 旧乡 | 故乡，牵挂之所在 |

## 重点字词

| 字词 | 释义 |
|------|------|
| 涉 | 趟水，渡过 |
| 芙蓉 | 荷花（此处指水中莲花） |
| 兰泽 | 长满兰草的沼泽 |
| 遗（wèi） | 赠送（读去声） |
| 所思 | 所思念的人 |
| 远道 | 远方的道路（指远方） |
| 还顾 | 回头望 |
| 旧乡 | 故乡 |
| 漫浩浩 | 形容路途无边无际 |
| 同心 | 感情深厚，心意相同 |
| 离居 | 分居两地 |
| 终老 | 度过余生直到老死 |

---

## 易错点

1. **"遗"的读音**：此处读 wèi（赠送），不读 yí（遗留）
2. **抒情主人公争议**：一说是游子思乡，一说是思妇怀人，高考通常接受"悬想"（对写法）的解读
3. **"还顾望旧乡"的视角转换**：从采芙蓉的水乡场景突然切换到回望旧乡的陆路场景，体现悬想手法
4. **"同心而离居"的"而"**：表转折（心在一起却身在两地），不是并列
5. **"忧伤以终老"的"以"**：相当于"而"，表修饰或伴随
