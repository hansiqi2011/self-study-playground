# 鹊桥仙

## 作品信息

- **作者**：秦观（1049—1100），字少游，号淮海居士
- **时代**：北宋
- **流派**：婉约派（"苏门四学士"之一）
- **体裁**：词（鹊桥仙调）
- **题材**：七夕（牛郎织女）
- **地位**：咏七夕词的千古绝唱，全文背诵篇目

---

## 原文

纤云弄巧，飞星传恨，银汉迢迢暗度。
金风玉露一相逢，便胜却人间无数。

柔情似水，佳期如梦，忍顾鹊桥归路。
两情若是久长时，又岂在朝朝暮暮。

---

## 核心考点

### 主题思想

歌颂真挚、坚贞的爱情。一反传统七夕词的悲悯哀伤，词人认为牛郎织女的爱情虽不能朝夕相守，但其忠贞不渝的精神超越了凡俗的厮守，提出"两情若是久长时，又岂在朝朝暮暮"的爱情观——翻新立意，化悲为豪。

### 艺术手法

| 手法 | 分析 |
|------|------|
| 以议论入词 | "金风玉露一相逢，便胜却人间无数"与"两情若是久长时，又岂在朝朝暮暮"以议论总结，升华情感 |
| 翻新立意 | 打破七夕词的悲情传统，不写离别之悲，反写精神之贵 |
| 比喻 | "柔情似水"以水喻情；"佳期如梦"以梦喻短暂美好 |
| 意象对偶 | "纤云弄巧，飞星传恨"——纤云/飞星，弄巧/传恨，工整精美 |
| 化用典故 | 银汉（天河）、鹊桥、金风玉露（秋天）——七夕意象体系 |

### 名句默写重点

- "纤云弄巧，飞星传恨，银汉迢迢暗度"（渲染七夕氛围）
- "金风玉露一相逢，便胜却人间无数"（以议论升华，短暂相逢胜过平凡厮守）
- "柔情似水，佳期如梦，忍顾鹊桥归路"（离别之际的不舍）
- **"两情若是久长时，又岂在朝朝暮暮"**（千古名句，全词点睛）

### 结构分析

| 部分 | 内容 | 手法 |
|------|------|------|
| 上片前三句 | 写景：七夕夜景与牛女相会 | 铺叙渲染 |
| 上片后两句 | 议论：一次相逢胜过平常 | 议论升华 |
| 下片前三句 | 抒情：相逢短暂的柔情与不舍 | 比喻抒情 |
| 下片后两句 | 议论：爱情贵在真挚长久 | 翻案点题 |

## 重点字词

| 字词 | 释义 |
|------|------|
| 纤云 | 轻盈纤细的云彩 |
| 弄巧 | 变幻出美妙的花样（暗合"乞巧"节） |
| 飞星 | 流星（一说指牛郎星、织女星） |
| 传恨 | 传递离别的愁恨 |
| 银汉 | 银河（天河） |
| 迢迢 | 遥远的样子 |
| 暗度 | 悄悄渡过（织女渡银河） |
| 金风 | 秋风（五行中秋属金） |
| 玉露 | 秋天洁白的露水 |
| 柔情似水 | 温柔的情感如水般绵长 |
| 佳期如梦 | 美好的相会时光如梦般短暂 |
| 忍顾 | 怎忍心回头看（忍：怎忍） |
| 朝朝暮暮 | 每日每夜，指日常厮守 |

---

## 易错点

1. **"金风玉露"不是春天**：金风=秋风（七夕在农历七月初七，秋天），玉露=秋露
2. **"忍顾"的"忍"**：是"怎忍"（反问/岂忍），不是"忍耐着看"
3. **词的情感基调**：不是悲伤哀怨，而是在柔情中透出豁达——与传统七夕悲情不同
4. **"又岂在朝朝暮暮"**：不是否定相守，而是强调精神契合比形式厮守更可贵
5. **上下片结构**：两处议论（上片结句+下片结句）是本词最大特色，答题时必须提及"以议论入词"
