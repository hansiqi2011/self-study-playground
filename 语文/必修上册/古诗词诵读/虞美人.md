# 虞美人

## 作品信息

- **作者**：李煜（937—978），字重光，号钟隐、莲峰居士
- **身份**：南唐后主（末代君主）
- **时代**：五代十国
- **体裁**：词（小令，虞美人调）
- **背景**：亡国被俘后所作，相传为其绝命词。宋太宗闻此词大怒，赐牵机药将其毒死
- **地位**：千古词帝代表作，全文背诵篇目

---

## 原文

春花秋月何时了？往事知多少。
小楼昨夜又东风，故国不堪回首月明中。

雕栏玉砌应犹在，只是朱颜改。
问君能有几多愁？恰似一江春水向东流。

---

## 核心考点

### 主题思想

抒发亡国之痛与故国之思。词人以春花秋月引发对往事的追忆，由自然的永恒对比人事的变迁，将无限愁绪化为滔滔江水的比喻，表达了深沉的亡国哀思。

### 艺术手法

| 手法 | 分析 |
|------|------|
| 比喻 | "恰似一江春水向东流"——以春水喻愁，化抽象为形象，写出愁之深广、绵长、无尽 |
| 对比 | 春花秋月（永恒）vs 往事（消逝）；雕栏玉砌（犹在）vs 朱颜（已改）——以不变衬有变 |
| 虚实结合 | 实写：小楼东风、月明之夜；虚写：故国宫殿、昔日容颜 |
| 设问 | "春花秋月何时了？""问君能有几多愁？"——以问句领起，加强情感力度 |
| 以乐写哀 | 春花秋月本为美景，词人却嫌其"何时了"，反衬内心痛苦之深 |

### 名句默写重点

- "春花秋月何时了？往事知多少"（以问起篇）
- "小楼昨夜又东风，故国不堪回首月明中"（"又"字写时光流逝之无情）
- "雕栏玉砌应犹在，只是朱颜改"（物是人非）
- **"问君能有几多愁？恰似一江春水向东流"**（千古名句，以水喻愁的经典）

### 关键字词赏析

| 词语 | 赏析 |
|------|------|
| 何时了 | 厌倦之情——乐景衬哀情，春花秋月越美，越反衬囚徒之苦 |
| 又 | "又东风"一个"又"字，写出年复一年的煎熬 |
| 应犹在 | "应"字含推测——身不能至，只能想象故国模样 |
| 只是 | 转折叹惋，物在人非的沉痛 |
| 一江春水 | 以水喻愁，兼有：量大（一江）、不断（流水）、无法阻止（向东流） |

## 重点字词

| 字词 | 释义 |
|------|------|
| 了 | 完结，终了 |
| 往事 | 指南唐故国的繁华岁月 |
| 故国 | 已灭亡的南唐 |
| 不堪 | 不忍，承受不住 |
| 雕栏玉砌 | 雕花栏杆和玉石台阶，代指故国宫殿 |
| 朱颜 | 红润的容颜，代指往昔（也暗含宫中人事） |
| 改 | 变化——容颜衰老，也指国破家亡后的沧桑巨变 |
| 君 | 你（自问自答，实际是自己） |
| 几多 | 多少 |

---

## 易错点

1. **"春花秋月何时了"**：不是赞美自然，而是厌倦——囚禁之人不愿看到时光流逝的标志
2. **"朱颜改"的理解**：不仅是容颜衰老，更是故国人事全非的象征
3. **"雕栏玉砌应犹在"**：是虚写（想象中的故国），不是实写眼前场景
4. **词的格律**：虞美人为两仄韵两平韵交替，注意"了/少""风/中""在/改""愁/流"的韵脚变化
5. **"绝命词"背景**：答题时应联系写作背景（亡国囚居），避免泛泛而谈"伤春悲秋"
