# 古诗词诵读

## 说明

课本末尾附录四首古诗词，均需背诵默写。

## 篇目

| 篇目 | 作者 | 体裁 | 主题 |
|---|---|---|---|
| [[静女]] | 《诗经·邶风》 | 诗经 | 青年男女约会 |
| [[涉江采芙蓉]] | 《古诗十九首》 | 五言古诗 | 游子思乡/离别 |
| [[虞美人]] | 李煜 | 词 | 亡国之痛 |
| [[鹊桥仙]] | 秦观 | 词 | 爱情/七夕 |

## 共同特点

- 均为必背篇目
- 主题涉及爱情与离别
- 从先秦到宋代的时间跨度
- 体裁从四言→五言→词的演变
