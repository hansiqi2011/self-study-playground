# 师说

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 韩愈（768—824），字退之，唐代文学家，古文运动倡导者 |
| 时代 | 唐代 |
| 体裁 | 议论文（“说”为古代议论文体裁） |
| 写作背景 | 针对当时社会“耻学于师”的不良风气 |

## 原文

古之学者必有师。师者，所以传道受业解惑也。人非生而知之者，孰能无惑？惑而不从师，其为惑也，终不解矣。生乎吾前，其闻道也固先乎吾，吾从而师之；生乎吾后，其闻道也亦先乎吾，吾从而师之。吾师道也，夫幸知其年之先后生于吾乎？是故无贵无贱，无长无少，道之所存，师之所存也。

嗟乎！师道之不传也久矣！欲人之无惑也难矣！古之圣人，其出人也远矣，犹且从师而问焉；今之众人，其下圣人也亦远矣，而耻学于师。是故圣益圣，愚益愚。圣人之所以为圣，愚人之所以为愚，其皆出于此乎？爱其子，择师而教之；于其身也，则耻师焉，惑矣。彼童子之师，授之书而习其句读者，非吾所谓传其道解其惑者也。句读之不知，惑之不解，或师焉，或不焉，小学而大遗，吾未见其明也。

巫医乐师百工之人，不耻相师。士大夫之族，曰师曰弟子云者，则群聚而笑之。问之，则曰：“彼与彼年相若也，道相似也。”位卑则足羞，官盛则近谀。呜呼！师道之不复可知矣。巫医乐师百工之人，君子不齿，今其智乃反不能及，其可怪也欤！

圣人无常师。孔子师郯子、苌弘、师襄、老聒。郯子之徒，其贤不及孔子。孔子曰：三人行，则必有我师。是故弟子不必不如师，师不必贤于弟子，闻道有先后，术业有专攻，如是而已。

李氏子螢，年十七，好古文，六艺经传皆通习之，不拘于时，学于余。余嘉其能行古道，作师说以贻之。

## 核心考点

### 论证结构
1. 第一段：正面立论——师的作用和从师的标准
2. 第二段：反面论证——三组对比批判“耻学于师”
3. 第三段：举例论证——孔子从师
4. 第四段：交代写作缘由

### 三组对比（第二段）
| 对比 | 内容 | 论证效果 |
|---|---|---|
| 古vs今 | 古之圣人从师 vs 今之众人耻师 | 纵向对比 |
| 对子vs对己 | 爱其子择师 vs 于其身耻师 | 自相矛盾 |
| 工匠vs士人 | 巫医乐师不耻相师 vs 士大夫群聚而笑 | 反训 |

## 重点字词

| 字词 | 读音/含义 |
|---|---|
| 师者，所以传道受业解惑也 | 受=授（通假）；所以=用来…的（人） |
| 孰能无惑 | 孰=谁 |
| 是故 | 因此 |
| 无贵无贱 | 无论…无论… |
| 圣益圣，愚益愚 | 益=更加 |
| 句读之不知 | 宾语前置，“之”=句读 |
| 小学而大遗 | 小=小的方面，意动 |
| 不耻相师 | 师=以…为师，意动 |
| 位卑则足羞 | 足=值得 |
| 官盛则近谀 | 近=接近，谀=谄媚 |
| 不拘于时 | 不被时俗拘束 |
| 作师说以贻之 | 贻=赠送 |
| 晶乎与 | 晶=唘(欟) |

## 文言知识

### 通假字
- 受 → 授（传授）
- 不(fǒu) → 否（不拘于时）

### 词类活用
- **师**：名词→意动用法，“以…为师”（吾从而师之/不耻相师）
- **小/大**：形容词→意动用法，“以…为小/大”（小学而大遗）
- **耻**：形容词→意动用法，“以…为耻”（耻学于师）
- **惑**：形容词→名词，“疑惑的问题”

### 特殊句式
- **判断句**：“师者，所以传道受业解惑也”（…者，…也）
- **宾语前置**：“句读之不知”（不知句读）
- **被动**：“不拘于时”（不被时俗拘束）
- **介宾结构**：“学于余”（向我学习）

## 易错点

- “师”字在文中多次出现，作为名词“老师”和动词“以…为师”要区分清楚
- “所以”古义“用来…的” vs 今义“因此”——这里是古义
- “小学而大遗”不是“小学生”的意思，而是“小的方面学习了，大的方面却遗漏了”
- “圣益圣，愚益愚”的“益”是副词“更加”，不是“有益”
