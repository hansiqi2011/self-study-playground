# 第六单元 · 学习之道

## 单元主题

探讨学习的意义、态度和方法。文言文与现代文结合，中外视角互补。

## 学习目标

- 理解议论文的论证方法（比喻论证、举例论证、对比论证）
- 掌握文言文重点实词、虚词和特殊句式
- 体会不同文体议论风格的异同
- 学习写作议论文

## 核心考点

1. **劝学**：比喻论证(青出于蓝/冰寒于水/金石可镂)、通假字、词类活用
2. **师说**：论证结构(立论→论证→举例→交代缘由)、"师者所以传道受业解惑也"
3. **拿来主义**：比喻论证(大宅子/鱼翅/鸦片/烟枪烟灯/姨太太)、先破后立
4. **默写篇目**：劝学（节选）、师说（全文）
