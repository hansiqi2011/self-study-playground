# 劝学

## 作品信息

| 项目 | 内容 |
|------|------|
| 作者 | 荀子（约前313—前238） |
| 时代 | 战国 |
| 出处 | 《荀子·劝学》 |
| 体裁 | 议论文（说理散文） |
| 地位 | 先秦儒家代表作，荀子开篇第一章 |

## 原文

> 君子曰：学不可以已。
>
> 青，取之于蓝，而青于蓝；冰，水为之，而寒于水。木直中绳，輮以为轮，其曲中规。虽有槁暴，不复挺者，輮使之然也。故木受绳则直，金就砺则利，君子博学而日参省乎己，则知明而行无过矣。
>
> 吾尝终日而思矣，不如须臾之所学也；吾尝跂而望矣，不如登高之博见也。登高而招，臂非加长也，而见者远；顺风而呼，声非加疾也，而闻者彰。假舆马者，非利足也，而致千里；假舟楫者，非能水也，而绝江河。君子生非异也，善假于物也。
>
> 积土成山，风雨兴焉；积水成渊，蛟龙生焉；积善成德，而神明自得，圣心备焉。故不积跬步，无以至千里；不积小流，无以成江海。骐骥一跃，不能十步；驽马十驾，功在不舍。锲而舍之，朽木不折；锲而不舍，金石可镂。蚓无爪牙之利，筋骨之强，上食埃土，下饮黄泉，用心一也。蟹六跪而二螯，非蛇鳝之穴无可寄托者，用心躁也。

## 核心考点

### 中心论点
**学不可以已**——学习不可以停止。

### 论证层次

| 段落 | 论点 | 论证方法 |
|------|------|----------|
| 第一段 | 学习的意义：提高/改变自己 | 比喻论证（青/蓝、冰/水、木/轮） |
| 第二段 | 学习的作用：善假于物 | 比喻论证（登高、顺风、舆马、舟楫） |
| 第三段 | 学习的方法和态度：积累、专一 | 正反对比（骐骥/驽马、锲而舍之/锲而不舍、蚓/蟹） |

### 核心论据
1. **学习能提高自己** — 青出于蓝而胜于蓝
2. **善假于物** — 君子生非异也，善假于物也
3. **贵在积累** — 不积跬步，无以至千里
4. **贵在专一** — 锲而不舍，金石可镂；用心一也

### 必背默写重点句

| 句子 | 常考角度 |
|------|----------|
| 青，取之于蓝，而青于蓝 | 学习超越（成语"青出于蓝"出处） |
| 故木受绳则直，金就砺则利 | 学习改造自我 |
| 君子博学而日参省乎己，则知明而行无过矣 | 学习+反省 |
| 吾尝终日而思矣，不如须臾之所学也 | 学与思的关系 |
| 君子生非异也，善假于物也 | 善于借助外力 |
| 故不积跬步，无以至千里；不积小流，无以成江海 | 积累的重要性 |
| 锲而舍之，朽木不折；锲而不舍，金石可镂 | 坚持不懈 |

| 例句 | 活用类型 | 释义 |

#### 特殊句式

| 句式 | 例句 | 说明 |
|------|------|------|
| 定语后置 | 蚓无爪牙**之利**，筋骨**之强** | "利""强"为后置定语 |
| 状语后置 | 青，取之**于蓝**，而青**于蓝** | 介宾短语后置 |
| 固定句式 | 无以至千里 | "无以"=没有用来……的办法 |

#### 一词多义

| 词 | 义项 |
|----|------|
| **而** | ①转折（而青于蓝）②递进（则知明而行无过矣）③修饰（终日而思）④并列（蟹六跪而二螯） |
| **于** | ①从（取之于蓝）②比（而青于蓝）③对（善假于物） |
| **之** | ①代词（取之于蓝）②助词（不如须臾之所学也）③定语后置标志（爪牙之利） |

## 易错点

1. **"輮以为轮"** — 易写错"輮"字，注意是"车"字旁
2. **"虽有槁暴"** — "暴"读pù，通"曝"，非bào
3. **"参省"** — "参"读cān非shēn，"省"读xǐng非shěng
4. **"跂而望"** — "跂"读qì，踮脚，非qí
5. **"君子生非异也"** — "生"通"性"读xìng，非shēng
6. **"金石可镂"** — "镂"易写成"漏"
7. **"不积跬步"** — "跬"字易忘或写错
8. **混淆比喻论证层次** — 第一段论学习意义（青蓝/冰水），第二段论善假于物（登高/舟车），第三段论积累专一
