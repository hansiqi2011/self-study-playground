# 第四单元 · 家乡文化生活

## 单元主题

了解家乡文化，参与文化建设，增强文化自信。

## 活动内容

1. **记录家乡的人和物** —— 口述历史/人物访谈/田野调查
2. **家乡文化生活现状调查** —— 设计问卷/数据分析/撰写报告
3. **参与家乡文化建设** —— 提出方案/付诸实践

## 学习目标

- 学会观察和记录生活中的文化现象
- 掌握基本的调查研究方法
- 学会撰写调查报告
- 培养文化自觉和参与意识
