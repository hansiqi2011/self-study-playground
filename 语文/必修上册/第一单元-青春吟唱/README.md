# 第一单元 · 青春吟唱

## 单元主题

青春是花样年华。本单元五首诗歌和两篇小说创作于不同历史时期，都是对青春的吟唱。

## 学习目标

- 理解诗歌运用意象抒发感情的手法
- 把握小说叙事和抒情的特点
- 从语言、形象、情感等不同角度欣赏作品
- 尝试写作诗歌

## 核心考点

1. **意象分析**：万山红遍/层林尽染/鹰击长空/鱼翔浅底（沁园春）；红烛=奉献精神；蜘蛛=谦卑生命力；云雀=欢乐精灵
2. **表达技巧**：借景抒情、象征、比喻、排比、重章叠句
3. **小说三要素**：环境（战争/山村）、人物（通讯员/新媳妇/香雪）、情节
4. **默写篇目**：沁园春·长沙（全文）
