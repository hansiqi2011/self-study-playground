# 沁园春·长沙

## 作品信息

- **作者**：毛泽东（1893—1976）
- **时代**：现代
- **写作时间**：1925年秋
- **体裁**：词（沁园春，双调114字）
- **背景**：1925年秋，毛泽东离开故乡韶山赴广州主持农民运动讲习所，途经长沙，重游橘子洲，感慨万千而作此词。时值国共合作的大革命高潮前夕。

## 原文

独立寒秋，湘江北去，橘子洲头。
看万山红遍，层林尽染；漫江碧透，百舸争流。
鹰击长空，鱼翔浅底，万类霜天竞自由。
怅寥廓，问苍茫大地，谁主沉浮？

携来百侣曾游，忆往昔峥嵘岁月稠。
恰同学少年，风华正茂；书生意气，挥斥方遒。
指点江山，激扬文字，粪土当年万户侯。
曾记否，到中流击水，浪遏飞舟？

## 核心考点

### 主题思想
- 以天下为己任的壮志豪情
- 对国家命运的关切与担当（"谁主沉浮"）
- 革命青年改造旧世界的凌云壮志

### 艺术手法

| 手法 | 具体表现 |
|------|---------|
| 写景层次 | 远近结合（万山—漫江）、俯仰结合（鹰击长空—鱼翔浅底）、动静结合（层林尽染—百舸争流） |
| 结构特点 | 上阕写景抒情（景→问），下阕忆事言志（忆→答） |
| 色彩对比 | "红遍""碧透"色彩鲜明，营造壮美意境 |
| 以问作结 | "谁主沉浮"承上启下，"浪遏飞舟"豪迈作答 |

### 默写重点句
1. "看万山红遍，层林尽染；漫江碧透，百舸争流。"（写景名句）
2. "鹰击长空，鱼翔浅底，万类霜天竞自由。"（动词精妙）
3. "恰同学少年，风华正茂；书生意气，挥斥方遒。"（忆少年）
4. "曾记否，到中流击水，浪遏飞舟？"（豪迈结尾）

### 关键意象
- **万山红遍/层林尽染**：壮美秋景，暗喻革命形势蓬勃发展
- **鹰击长空/鱼翔浅底**：万物竞自由，象征对自由的追求
- **中流击水/浪遏飞舟**：革命者的豪情与力量

## 易错点

1. **"沁园春"是词牌名**，"长沙"才是标题——注意区分
2. "层林尽染"的"染"易误写为"燃"
3. "漫江碧透"的"漫"意为"满"，不是"漫无边际"
4. "鱼翔浅底"用"翔"而非"游"——以鸟喻鱼，写鱼游之自在
5. "挥斥方遒"的"遒"易误写为"逑"或"虬"
6. "浪遏飞舟"的"遏"易与"竭"混淆
