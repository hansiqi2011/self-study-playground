# 哦，香雪

## 作品信息

- **作者**：铁凝（1957— ），河北赵县人，当代女作家，中国作协主席
- **时代**：当代
- **发表时间**：1982年
- **体裁**：短篇小说
- **获奖**：1982年全国优秀短篇小说奖
- **背景**：改革开放初期，火车开进偏远山村，象征现代文明进入封闭乡村。小说以诗化的笔调展现山村少女对知识和文明的渴望。

## 原文（关键段落）

### 火车进村

> 哦，五彩缤纷的一分钟啊！……这短暂的一分钟，搅乱了台儿沟以往的宁静。

### 香雪换铅笔盒

> 她终于站在火车上了。……当她在下一站走下火车时，她手里紧紧攥着那只铅笔盒。

### 结尾——独自走夜路回村

> 她站了起来，忽然感到心里很满意，风也柔合了许多。……大山原来是这样的！月亮原来是这样的！……台儿沟一定会是"这样的"……

## 核心考点

### 主题思想
- 山村少女对知识和现代文明的热切渴望
- 封闭乡村与外部世界初次碰撞的诗意表达
- 追求进步、追求尊严的纯真愿望
- 时代变革中淳朴人性的美好

### 人物形象

| 人物 | 形象特征 | 关键表现 |
|------|---------|---------|
| 香雪 | 纯真执着、渴望知识、自尊心强 | 为换铅笔盒独自坐火车到下一站，独自走夜路返回 |
| 凤娇 | 活泼大胆、虚荣但不失纯真 | 关注旅客的发卡和手表，喜欢"北京话" |

### 核心象征

| 象征物 | 象征意义 |
|--------|---------|
| 铅笔盒（自动的） | 对知识、文明、尊严的渴望 |
| 火车 | 现代文明的载体/外部世界 |
| 台儿沟 | 封闭、贫穷但纯朴的乡村 |
| 一分钟停靠 | 乡村与现代文明的短暂接触 |

### 艺术手法

| 手法 | 具体表现 |
|------|---------|
| 诗化小说 | 语言优美抒情、淡化情节、意境清新如散文诗 |
| 心理描写 | 香雪走夜路的内心活动——恐惧→坚定→喜悦 |
| 对比 | 香雪（求知）vs 凤娇（慕物）——衬托香雪的精神追求 |
| 象征 | 铅笔盒/火车/夜路的多层象征意义 |
| 环境烘托 | 月色、大山、风——映衬香雪的成长与觉醒 |

### 情节脉络
1. 火车每天停靠一分钟——台儿沟姑娘们的兴奋
2. 香雪渴望自动铅笔盒（被同学嘲笑木头铅笔盒）
3. 香雪用鸡蛋换铅笔盒，被带到下一站
4. 独自走三十里夜路返回——完成精神成长
5. 同伴们迎接——"哦，香雪！香雪！"

## 重点字词

| 字词 | 释义 |
|------|------|
| 台儿沟 | 小说中虚构的偏远山村 |
| 攥 (zuàn) | 紧紧握住 |
| 五彩缤纷 | 色彩繁多，形容火车带来的新奇世界 |
| 皱巴巴 | 形容不平整，此处形容旧铅笔盒 |
| 柔和 | 温和，不猛烈（风也柔合了→实为"柔和"之意） |

## 易错点

1. **铅笔盒是"自动"铅笔盒**（按钮弹开式），不是普通铅笔盒——代表"先进"
2. 香雪用**鸡蛋**换铅笔盒，不是用钱买——突出物质匮乏
3. 火车在台儿沟只停**一分钟**——这个时间限制是关键叙事动力
4. "哦，香雪"的"哦"是感叹/呼唤语气——标题本身就有诗意
5. 铁凝是**当代**作家（非现代），且此文发表于**1982年**（改革开放初期）
6. 这是**诗化小说**，不要按常规小说的强情节思路去分析
