# 百合花

## 作品信息

- **作者**：茹志鹃（1925—1998），上海人，当代女作家
- **时代**：当代
- **写作时间**：1958年
- **体裁**：短篇小说
- **背景**：以1946年中秋前后解放战争中的一次战斗为背景。写于"十七年文学"时期，却以战争中细腻的人情美独树一帜，突破了当时战争文学的宏大叙事模式。

## 原文（关键段落）

### 开头——"我"与通讯员相遇

> 一个通讯员送我到前沿包扎所去。……他背着枪，枪筒里稀奇地插了一枝野菊花。

### 高潮——新媳妇献百合花被

> 在卫生员揭开棉被查看伤势时，新媳妇一针一针地缝着那个破洞。……她低着头，正一针一针地在缝他衣肩上那个破洞。

### 结尾——盖上百合花被

> 新媳妇却像什么也没看见，什么也没听到，依然拿着针，细细地、密密地缝着那个破洞。……她自己动手把半条被子平展展地铺在棺材底，半条盖在他身上。

## 核心考点

### 主题思想
- 战争中的人性美与人情美
- 军民之间纯洁真挚的感情
- 普通人在战争中展现的崇高品质
- 对青春生命逝去的哀悼与礼赞

### 人物形象

| 人物 | 形象特征 | 关键细节 |
|------|---------|---------|
| 通讯员 | 腼腆、憨厚、质朴、舍己为人 | 枪筒里的野菊花/衣服被门钩挂破/馒头 |
| 新媳妇 | 善良、美丽、重情义 | 起初不愿借被/后来一针一针缝补/盖被送行 |
| "我"（女文工团员） | 观察者/叙事者、细腻敏感 | 第一人称有限视角 |

### 艺术手法

| 手法 | 具体表现 |
|------|---------|
| 细节描写 | ①衣服上的破洞（前后呼应）②枪筒里的野菊花（质朴天真）③两个馒头（最后的关怀）④百合花被子（纯洁感情） |
| 伏笔与照应 | 衣肩的破洞——开头被门钩挂破，结尾新媳妇缝补 |
| 象征 | 百合花被子 = 纯洁的情感与美好的生命 |
| 以小见大 | 以一个小通讯员的牺牲，写出战争中的人性光辉 |
| 第一人称叙事 | 有限视角，增强真实感和亲切感 |

### 关键细节梳理

| 细节 | 出现位置 | 作用 |
|------|---------|------|
| 枪筒里的野菊花 | 相遇时 | 表现通讯员的天真质朴、热爱生活 |
| 衣肩上的破洞 | 借被时挂破→结尾缝补 | 贯穿全文的伏笔/照应，串联人物情感 |
| 两个馒头 | 通讯员临走留下 | 对"我"的质朴关心；牺牲后成为遗物 |
| 百合花被子 | 新媳妇的嫁妆→盖棺 | 从舍不得到主动奉献——情感升华 |

## 重点字词

| 字词 | 释义 |
|------|------|
| 包扎所 | 战地临时救护站 |
| 通讯员 | 部队中负责传递消息的士兵 |
| 虔诚 | 恭敬而有诚意 |
| 颤抖 | 发抖，此处表现内心激动 |
| 新媳妇 | 刚结婚不久的年轻女子 |

## 易错点

1. **叙事视角**是第一人称有限视角（"我"是女文工团员），不是全知视角
2. 小说标题"百合花"指的是**被子上的百合花图案**，不是真实的百合花
3. 新媳妇**起初不愿借被**并非自私——是新婚嫁妆的珍贵/害羞，后来主动盖棺才见真情
4. 通讯员的牺牲是为**救护担架员**，不是直接战斗牺牲
5. 此文写于1958年，背景设在**1946年**——注意写作时间与故事时间的区分
6. 茹志鹃是**女作家**，其女为作家王安忆
