# 致云雀

## 作品信息

- **作者**：珀西·比希·雪莱（Percy Bysshe Shelley，1792—1822），英国浪漫主义诗人
- **译者**：江枫
- **时代**：19世纪英国浪漫主义
- **写作时间**：1820年
- **体裁**：抒情诗（全诗21节，每节5行）
- **背景**：雪莱与妻子玛丽在意大利莱杭散步时，听到云雀鸣唱，有感而作。雪莱是英国浪漫主义"第二代"代表诗人，与拜伦、济慈齐名。

## 原文（关键节选）

**第1节**
你好啊，欢乐的精灵！
你似乎从不是飞禽，
从天堂或天堂的邻近，
以酣畅淋漓的乐音，
不事雕琢的艺术，倾吐你的衷心。

**第8节**（比喻诗人）
像一位诗人，隐身
在思想的明辉之中，
吟诵着即兴的诗韵，
直到普天下的同情
都被未曾留意过的希望和忧虑唤醒；

**第9节**（比喻少女）
像一位高贵的少女，
居住在深宫的楼台，
在寂寞难言的时刻，
排遣她为爱所苦的情怀，
甜美如爱的歌曲溢出闺阁之外；

**第21节（末节）**
教给我一半，你的心
必然熟知的那种欢欣，
和谐的热狂就会流出我的双唇，
全世界就会像此刻的我——侧耳倾听。

## 核心考点

### 主题思想
- 云雀 = **欢乐的精灵**，象征理想境界中自由纯粹的欢乐
- 表达诗人对理想境界的热切向往
- 以云雀的"不知悲伤"反衬人间的苦闷与局限
- 渴望获得云雀般的纯粹欢乐与感召力量

### 艺术手法

| 手法 | 具体表现 |
|------|---------|
| 比喻（博喻） | 将云雀比作：诗人、少女、萤火虫、玫瑰——多角度展现云雀特质 |
| 象征 | 云雀象征不受尘世束缚的理想精神 |
| 对比 | 云雀的纯粹欢乐 vs 人间总有悲伤相随 |
| 设问/直接呼告 | "你好啊，欢乐的精灵！"直接与云雀对话 |

### 四个核心比喻

| 比喻对象 | 云雀的相应特质 |
|----------|---------------|
| 诗人 | 隐身于思想光辉中，以歌声唤醒世人 |
| 少女 | 感情溢出，甜美不可抑制 |
| 萤火虫 | 身处高处不可见，光芒却四散 |
| 玫瑰 | 隐于绿叶，芬芳远播 |

## 重点字词

| 字词 | 释义 |
|------|------|
| 云雀 | skylark，善高飞边飞边鸣的小型鸟 |
| 酣畅淋漓 | 尽情畅快 |
| 不事雕琢 | 不刻意修饰，自然天成 |
| 衷心 | 内心深处真诚的感情 |
| 霓裳 | 虹霓做的衣裳，形容美丽轻盈 |
| 犀利 | 锋利、透彻 |

## 易错点

1. **全诗21节**（105行），每节5行——注意整体把握
2. "致云雀"的"致"= 向……表达（敬意/感情），不是"导致"
3. 云雀的象征义是"纯粹的欢乐精灵"，不仅仅是自由——区分于一般"鸟=自由"的套路
4. 雪莱（Shelley）不是雪莱（Charlotte Brontë的笔名），注意英国浪漫主义诗人身份
5. 末节"教给我一半"——表明诗人自知无法完全达到云雀境界，只求"一半"
