# 红烛

## 作品信息

- **作者**：闻一多（1899—1946），湖北浠水人，诗人、学者、民主斗士
- **时代**：现代
- **出处**：诗集《红烛》（1923年）同名序诗
- **体裁**：现代抒情诗
- **背景**：1922年闻一多赴美留学，深感民族屈辱，创作此诗表达以身许国的赤诚之心。诗集以"红烛"命名，以唐代李商隐"蜡炬成灰泪始干"为引。

## 原文（关键节选）

> 引："蜡炬成灰泪始干"——李商隐

**第一节**
红烛啊！
这样红的烛！
诗人啊！
吐出你的心来比比，
可是一般颜色？

**第四节**
红烛啊！
既制了，便烧着！
烧吧！烧吧！
烧破世人的梦，
烧沸世人的血——
也救出他们的灵魂，
也捣破他们的监狱！

**第八节**
红烛啊！
"莫问收获，但问耕耘。"

（全诗共9节，以"红烛啊！"起始形成回环结构）

## 核心考点

### 主题思想
- **核心象征**：红烛 = 奉献精神 / 诗人自我牺牲的理想人格
- 红烛的"红"= 赤诚之心、爱国热情
- 燃烧自我，照亮他人——歌颂无私奉献
- 探索人生价值：以生命之火照亮黑暗社会

### 艺术手法

| 手法 | 具体表现 |
|------|---------|
| 象征 | 红烛象征诗人理想人格与奉献精神 |
| 与物对话 | 全诗以"红烛啊！"呼唤红烛，形成对话体 |
| 感叹词回环 | 每节以"红烛啊！"起始，层层推进情感 |
| 托物言志 | 借红烛表达自己以身许国的志向 |

### 诗歌情感脉络（9节）
1. 赞叹红烛之红（赤诚）
2. 追问红烛为何燃烧（人生价值）
3. 明确燃烧的意义——"莫问收获，但问耕耘"
4. 呼唤红烛烧破世人的梦/烧沸世人的血
5-7. 对红烛流泪的理解——同情世人的悲伤
8. 最终精神升华——不问收获的奉献境界
9. 赞美红烛"莫问收获，但问耕耘"

### 默写重点句
- "莫问收获，但问耕耘。"（结尾名句）
- "吐出你的心来比比，可是一般颜色？"
- "烧破世人的梦，烧沸世人的血"

## 重点字词

| 字词 | 释义 |
|------|------|
| 蜡炬成灰泪始干 | 李商隐《无题》，引为全诗总纲 |
| 莫问收获，但问耕耘 | 不求回报，只管付出（全诗核心精神） |
| 监狱 | 此处比喻束缚人灵魂的黑暗社会 |
| 灵魂 | 指世人觉醒的意识 |

## 易错点

1. 全诗**9节**，非8节——注意节数
2. "莫问收获，但问耕耘"出现在**最后一节**，是全诗主旨升华
3. 红烛的"泪"不仅是蜡泪，更象征诗人对社会黑暗的悲愤
4. 引用李商隐"蜡炬成灰泪始干"是化用而非照搬原意——原诗写爱情，此处转为爱国
5. 闻一多属**新月派**，注重诗歌的"三美"（音乐美、绘画美、建筑美）
