## 原文（开头与关键段）

> 秋天，无论在什么地方的秋天，总是好的；可是啊，北国的秋，却特别地来得清，来得静，来得悲凉。

> 南国之秋，当然是也有它的特异的地方的，比如廿四桥的明月，钱塘江的秋潮，普陀山的凉雾，荔枝湾的残荷等等，可是色彩不浓，回味不永。比起北国的秋来，正像是黄酒之与白干，稀饭之与馍馍，鲈鱼之与大蟹，黄犬之与骆驼。

> 秋天，这北国的秋天，若留得住的话，我愿把寿命的三分之二折去，换得一个三分之一的零头。

## 文章结构

### 总—分—总结构

```
总起：北国的秋——清、静、悲凉（文眼）
  │
  ├─ 分写：五幅秋景图
  │    ├─ 1. 秋院清晨（破屋/碧天/驯鸽/牵牛花/秋草）
  │    ├─ 2. 秋槐落蕊（细腻/清闲/落寞）
  │    ├─ 3. 秋蝉残鸣（衰弱/残声/啼唱）
  │    ├─ 4. 秋雨话凉（都市闲人/"一层秋雨一层凉"）
  │    └─ 5. 秋果奇景（枣树/淡绿微黄）
  │
  └─ 总结：南国之秋vs北国之秋 → 眷恋之情
```

## 核心考点

### 1. 主题思想

对北平秋天的深沉眷恋与赞美。表面写秋景，实则寄寓了作者对故都的深厚感情，以及知识分子在特定时代的落寞与忧郁。"故都"一词兼含怀旧与眷恋。

### 2. 艺术手法

| 手法 | 具体表现 |
|------|----------|
| 情景交融 | 以"清、静、悲凉"为情感基调选择景物，景中含情 |
| 对比 | 南国之秋vs北国之秋——突出北国秋味的"浓""深" |
| 比喻 | "黄酒之与白干"等四组比喻，以味觉写视觉感受 |
| 以小见大 | 不写名胜古迹，专写平民生活中的秋味 |
| 色彩点染 | 青天、蓝朵、灰土、淡绿微黄——冷色调为主 |

### 3. 关键语句赏析

- **"北国的秋，却特别地来得清，来得静，来得悲凉"**——全文文眼，三个特征统领全篇
- **"我愿把寿命的三分之二折去，换得一个三分之一的零头"**——以生命为代价的深情眷恋
- **"像花而又不是花的那一种落蕊"**——极写细腻感受，静中取动

### 4. 默写重点句

- 秋天，无论在什么地方的秋天，总是好的；可是啊，北国的秋，却特别地来得清，来得静，来得悲凉。
- 比起北国的秋来，正像是黄酒之与白干，稀饭之与馍馍，鲈鱼之与大蟹，黄犬之与骆驼。

## 易错点

- "故都"≠ 颓败之都。"故"是"旧、从前"的意思，含深情怀念
- "悲凉"不是消极——是审美意义上的况味，体现中国文人"悲秋"传统
- 五幅秋景图的顺序有讲究：从清晨到白天到雨后，从视觉到听觉到综合
- 对比手法的目的是"衬托"非"贬低"南国之秋
