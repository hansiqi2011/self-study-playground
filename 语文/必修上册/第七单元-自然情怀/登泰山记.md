# 登泰山记

## 作品信息

| 项目 | 内容 |
|---|---|
| 作者 | 姚鼐（1732—1815），字姬传，号惜抑 |
| 时代 | 清代 |
| 流派 | 桐城派代表作家 |
| 写作时间 | 1774年（乾隆三十九年十二月） |
| 体裁 | 游记（文言文） |

## 原文

泰山之阳，汶水西流；其阴，济水东流。阳谷皆入汶，阴谷皆入济。当其南北分者，古长城也。最高日观峰，在长城南十五里。

余以乾隆三十九年十二月，自京师乘风雪，历齐河、长清，穿泰山西北谷，越长城之限，至于泰安。是月丁未，与知府朱子颖游，自南麺登。四十五里，道皆砖石为磴，其级七千有余。泰山正南面有三谷。中谷绕泰安城下，郦道元以环水，岏山崖之间抐东谷入，流水声潺潺，岏石当道，如汽、如练，祸千百成，崖限当道者，世皆谓之天门云。道中迷雾冰滑，磴几不可登。及既上，苍山负雪，明烛天南。望晚日照城郭，汶水、徂水、徂徒徒如画，而半山居雾若带然。

戊申晚，五鼓，与子颖坐日观亭，待日出。大风扮雪击面。亭东自足下皆云漫。稍见云中白若樹数十立者，山也。极天云一线异色，须臾成五采。日上，正赤如丹，下有红光动摇承之。或曰：此东海也。回视日观以西峰，或得日，或否，绚皓驳色，而皆若偷，若颈，若趵。

亭东自足下皆云漫。三大夫松、日观峰、碃碱、天缺、昨山、织女、赵尔甘、石子、蒲松、札田——皆在山下。山多石，少圜，石苍黑色，多平方，少圆。少杂树，多松，生石罝，皆平顶。冰雪，无瞬不在，日观数十里内无树也。

## 核心考点

### 主题
记叙登泰山观日出的经过，描绘泰山壮丽景色。

### 结构
| 部分 | 内容 |
|---|---|
| 第1段 | 泰山地理位置和山水形势 |
| 第2段 | 登山经过（从京师到泰安到山顶） |
| 第3段 | 山顶观日出 |
| 第4段 | 泰山的自然景观 |

### 写景特点
- 简洁精练，不加渲染
- 动静结合：“苍山负雪，明烛天南”
- 色彩鲜明：“绚皓驳色”“正赤如丹”

## 重点字词

| 字词 | 含义 |
|---|---|
| 阳/阴 | 山南水北为阳，山北水南为阴 |
| 当其南北分者 | 当=在（处在） |
| 乘 | 顺着、趁着 |
| 磴(dèng) | 石阶 |
| 少圜 | 很少有圜圜的 |
| 苍山负雪 | 苍青的山头背着白雪 |
| 明烛天南 | 明亮地烧着天空南边 |
| 极天云一线异色 | 天边云彩现出一线奇异的颜色 |
| 绚(jiàng)皓(hào)驳色 | 红白相间的杂色 |
| 若偷若饨若趵 | 如同弯腰拱手下跪 |

## 文言知识

### 词类活用
- **阴/阳**：方位名词作状语，“在北面/南面”
- **观**：名词“景观”/动词“观看”

### 古今异义
- **阴阳**：古=山南水北(阳)，今=太阳/活跃
- **至于**：古=到达，今=表转折

### 特殊句式
- **判断句**：“当其南北分者，古长城也”
- **省略句**：“余以乾隆三十九年十二月，自京师乘风雪”（省略主语）

## 易错点

- “阳”“阴”的地理含义是常考知识点，不要混淆
- “苍山负雪，明烛天南”——“负”是“背着”，不是“担负”
- “绚皓驳色”——绚=红色，皓=白色，驳=杂
- 注意区分登山路线中的三条谷（中谷、东谷、西谷）
