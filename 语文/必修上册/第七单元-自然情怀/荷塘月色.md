# 荷塘月色

| 项目 | 内容 |
|------|------|

| 时代 | 现代 |
| 写作时间 | 1927年7月 |
| 体裁 | 写景抒情散文 |
| 背景 | 写于清华园，大革命失败后，作者内心苦闷彷徨 |
| 地位 | 现代散文经典，写景散文的典范之作 |

---

## 原文（关键段落）

> 这几天心里颇不宁静。今晚在院子里坐着乘凉，忽然想起日日走过的荷塘，在这满月的光里，总该另有一番样子吧。

> 曲曲折折的荷塘上面，弥望的是田田的叶子。叶子出水很高，像亭亭的舞女的裙。层层的叶子中间，零星地点缀着些白花，有袅娜地开着的，有羞涩地打着朵儿的；正如一粒粒的明珠，又如碧天里的星星，又如刚出浴的美人。微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的。

> 月光如流水一般，静静地泻在这一片叶子和花上。薄薄的青雾浮起在荷塘里。叶子和花仿佛在牛乳中洗过一样；又像笼着轻纱的梦。

## 文章结构

### 圆形结构（出发—漫步—回归）

```
出门（心里颇不宁静）
  │
  ├─ 小煤屑路（幽僻/寂寞/自由）
  │
  ├─ 荷塘月色（核心）
  │    ├─ 月下荷塘：荷叶→荷花→荷香→荷波→流水
  │    └─ 荷塘月色：月光→青雾→树影→光与影
  │
  ├─ 荷塘四周（远山/树色/蝉声蛙声）
  │
  ├─ 联想（采莲赋/西洲曲→江南往事）
  │
  └─ 回家（推门进去，妻已睡熟）
```

情感线索：不宁静 → 暂得宁静（淡淡的喜悦）→ 无法摆脱现实 → 回归不宁静

## 核心考点

### 1. 主题思想

表达作者在特定时代背景下寻求宁静与超脱的心境。荷塘月色是理想化的"另一世界"，是暂时逃离现实苦闷的精神避难所。最终的回归暗示这种超脱只是暂时的。

### 2. 艺术手法

| 手法 | 具体表现 |
|------|----------|
| **通感** | "微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的"（嗅觉→听觉）；"光与影有着和谐的旋律，如梵婀玲上奏着的名曲"（视觉→听觉） |
| **叠字** | 曲曲折折、田田、亭亭、层层、缕缕、薄薄、静静——增强音韵美和画面感 |
| **比喻（博喻）** | 荷花：明珠、星星、美人（三个喻体，多角度） |
| **拟人** | "袅娜地开着""羞涩地打着朵儿" |
| **动静结合** | 静态的月光与动态的微风、流水相映 |

### 3. 名句赏析

- **"微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的"**
  - 通感手法的经典：将嗅觉（清香）转化为听觉（歌声）
  - "缕缕"写香气之细，"渺茫"写若有若无——两种感觉的共同特征是"淡而飘忽"
  - 这是高考常考的修辞手法辨析例句

- **"这几天心里颇不宁静"**——全文感情基调的奠定

- **"像亭亭的舞女的裙"**——写荷叶的形态，"亭亭"兼有身姿与高度

### 4. 默写重点

- 微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的。
- 月光如流水一般，静静地泻在这一片叶子和花上。

## 易错点

- 通感≠比喻。通感是感官转移（甲感觉→乙感觉），比喻是本体→喻体。"清香像歌声"是通感兼比喻
- "颇不宁静"的原因不宜简单归结为政治——应理解为一种复杂的内心苦闷
- 叠字不全是形容词，也有动态感：如"静静地泻"中"静静"修饰动词
- 圆形结构的关键：结尾回家并非情感的解决，而是"无法逃离"的暗示
