# 第七单元 · 自然情怀

## 单元主题

感受人与自然的深层对话，体会作者笔下自然景物中寄寓的思想感情。

## 学习目标

- 把握写景散文的情景关系
- 理解文言散文的语言和章法
- 体会不同作者面对自然时的不同情怀
- 学习写景抒情的方法

## 核心考点

1. **故都的秋**：总分总结构、五幅秋景图、"清/静/悲凉"三字概括
2. **荷塘月色**：通感/叠字/比喻、圆形结构、"淡淡的喜悦和淡淡的哀愁"
3. **我与地坛**：地坛=精神家园、生命哲学、母爱主题
4. **赤壁赋**：主客问答结构、由悲转乐、"物与我皆无尽"、骈散结合
5. **登泰山记**：桐城派、阴阳/磴/绛皓驳色等文言词汇
6. **默写篇目**：赤壁赋（全文）、登泰山记（全文）
