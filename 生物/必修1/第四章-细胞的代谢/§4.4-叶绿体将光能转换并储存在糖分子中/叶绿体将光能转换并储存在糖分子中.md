# 叶绿体将光能转换并储存在糖分子中

## 一、叶绿体是光合作用的场所

### 叶绿体结构

| 结构 | 特点 | 功能 |
|---|---|---|
| **外膜** | 平滑，透性较大 | 物质进出 |
| **内膜** | 控制物质进出 | 选择透过 |
| **类囊体** | 单层膜扁平囊状结构，堆叠成基粒 | 光反应场所 |
| **基质** | 类囊体间的液态环境 | 碳反应场所 |

> 1g 菠菜叶片中叶绿体的类囊体总面积可达约 60 m²——极大化光能吸收面积。

### 光合色素

| 色素类别 | 具体名称 | 颜色 | 主要吸收光 |
|---|---|---|---|
| **叶绿素** | 叶绿素 a | 蓝绿色 | 红橙光、蓝紫光 |
|  | 叶绿素 b | 黄绿色 | 红橙光、蓝紫光 |
| **类胡萝卜素** | 胡萝卜素 | 橙黄色 | 蓝紫光 |
|  | 叶黄素 | 黄色 | 蓝紫光 |

**关键点：**
- 叶绿素含量约为类胡萝卜素的 **3 倍**
- 叶绿素主要吸收**红橙光和蓝紫光**，几乎不吸收绿光 → 叶片呈绿色
- 秋天叶片变黄：叶绿素分解，类胡萝卜素（黄/橙）显现

### 色素提取与分离实验

- **提取**：用 95% 乙醇（有机溶剂）溶解色素
- **分离**：层析法——不同色素在有机溶剂中溶解度不同 → 扩散速率不同
- 层析结果（从上到下）：胡萝卜素 → 叶黄素 → 叶绿素 a → 叶绿素 b
  - 记忆：**"胡叶（黄）a b"**（溶解度从大到小）

## 二、光合作用总反应式

$$CO_2 + H_2O \xrightarrow{光能,\,叶绿体} (CH_2O) + O_2$$

展开写（配平）：

$$6CO_2 + 12H_2O \xrightarrow{光能,\,叶绿体} C_6H_{12}O_6 + 6H_2O + 6O_2$$

**注意：**
- 产物中有 **6H₂O**（光反应中水参与反应生成的新水）
- **O₂ 全部来自 H₂O**（不是来自 CO₂）——同位素标记实验证明

## 三、光反应（类囊体薄膜上）

### 过程三步走

```
1. 光能捕获与转换
   色素吸收光能 → 传递到特定叶绿素a → 释放高能电子

2. 水的光解
   失去电子的叶绿素a氧化性极强
   → 从H₂O中夺取电子 → H₂O裂解为 H⁺ + O₂
   （O₂释放到细胞外）

3. 高能化合物形成
   高能电子 + NADP⁺ + H⁺ → NADPH（还原型辅酶Ⅱ）
   电子传递泵H⁺入类囊体腔 → H⁺顺浓度梯度过ATP合酶 → ATP
```

### 光反应总结

| 项目 | 内容 |
|---|---|
| **场所** | 类囊体薄膜 |
| **条件** | 光、色素、酶 |
| **原料** | H₂O、ADP+Pi、NADP⁺ |
| **产物** | O₂、ATP、NADPH |
| **能量变化** | 光能 → ATP 和 NADPH 中活跃的化学能 |

---

## 四、碳反应 / 卡尔文循环（叶绿体基质）

### 过程三步走

```
① CO₂固定
   CO₂ + 五碳糖(C₅) ──酶──→ 2个三碳化合物(C₃)

② C₃还原
   C₃ + ATP + NADPH ──→ 三碳糖(G3P)
   （活跃化学能 → 稳定化学能）

③ 五碳糖再生
   部分三碳糖 → 五碳糖（循环继续）
   另一部分三碳糖 → 蔗糖/淀粉等糖类
```

### 碳反应总结

| 项目 | 内容 |
|---|---|
| **场所** | 叶绿体基质 |
| **条件** | 酶（不直接需要光，但需光反应提供 ATP 和 NADPH） |
| **原料** | CO₂、ATP、NADPH |
| **产物** | 三碳糖(G3P)、ADP+Pi、NADP⁺ |
| **能量变化** | ATP/NADPH 中活跃化学能 → 糖中稳定化学能 |

---

## 五、光反应与碳反应的关系

```
              光反应                    碳反应
              (类囊体薄膜)              (叶绿体基质)
    
    H₂O ──→ O₂ + H⁺           CO₂ + C₅ → C₃
    光能 → ATP ─────────────→ 驱动C₃还原
    光能 → NADPH ──────────→ 提供H和电子
              ←────────────── ADP+Pi, NADP⁺ 返回
```

### 相互促进与制约

| 情境 | 光反应 | 碳反应 |
|---|---|---|
| 光照减弱 | ATP/NADPH 减少 → | CO₂ 固定减慢 |
| CO₂ 供应不足 | ADP/NADP⁺ 回收慢 ← | C₃ 还原减慢 |
| 中午气孔关闭 | 光反应也受制约 ← | CO₂ 进不来 |

## 六、影响光合作用的环境因素

| 因素 | 影响机制 | 实践应用 |
|---|---|---|
| **光照强度** | 光反应速率；有光饱和点 | 合理密植，补光 |
| **CO₂ 浓度** | 碳反应原料；有 CO₂ 饱和点 | 温室增施 CO₂ |
| **温度** | 影响酶活性 | 不同气候带植物最适温度不同 |
| **水分** | 光合原料；缺水→气孔关闭→CO₂ 进入减少 | 合理灌溉 |

### 光补偿点与光饱和点

- **光补偿点**：光合速率 = 呼吸速率 → 净光合 = 0
- **光饱和点**：再增大光照强度，光合速率不再增加
- 阳生植物光饱和点高于阴生植物

## 七、光合作用研究史（经典实验）

| 时间 | 科学家 | 实验/贡献 | 结论 |
|---|---|---|---|
| 1642 | 赫尔蒙特 | 柳树+水实验 | 植物增重主要来自水 |
| 1771 | 普里斯特利 | 密闭钟罩+植物+蜡烛/小鼠 | 植物能净化空气 |
| 1779 | 英格豪斯 | 500+ 次重复实验 | 光照是必要条件 |
| 1864 | 萨克斯 | 半遮光+碘液 | 光下制造淀粉 |
| 1941 | 鲁宾&卡门 | ¹⁸O 标记 H₂O 和 CO₂ | O₂ 来自 H₂O |
| 1954 | 卡尔文 | ¹⁴C 标记 + 纸层析 | CO₂ → 糖的途径（卡尔文循环） |

## 八、光合作用与细胞呼吸的对比

| | 光合作用 | 细胞呼吸 |
|---|---|---|
| **场所** | 叶绿体 | 细胞质基质 + 线粒体 |
| **条件** | 光、色素、酶 | 酶（有氧/无氧） |
| **原料** | CO₂ + H₂O | C₆H₁₂O₆ + O₂ |
| **产物** | C₆H₁₂O₆ + O₂ | CO₂ + H₂O |
| **能量变化** | 光能→化学能（储存） | 化学能→ATP（释放） |
| **实质** | 合成有机物，储能 | 分解有机物，释能 |

---

## 易错点

1. **O₂ 来自 H₂O 的光解，不是来自 CO₂**——鲁宾&卡门同位素标记实验直接证明
2. **碳反应不等于"暗反应就不需要光"**——碳反应本身不直接用光，但需要光反应提供的 ATP 和 NADPH。没有光→光反应停→碳反应也停
3. **C₃ 和 C₅ 的含量变化**：
   - 突然停光 → ATP/NADPH 减少 → C₃ 积累升高，C₅ 减少
   - 突然降低 CO₂ → C₃ 减少，C₅ 积累升高
4. **净光合 vs 真正（总）光合**：实验测的是净光合 = 总光合 - 呼吸。弱光下净光合为负 ≠ 不进行光合作用
5. **光合色素层析顺序**：从快到慢（从上到下）是胡萝卜素→叶黄素→叶绿素a→叶绿素b——溶解度越大扩散越快
6. **恩格曼实验**：用需氧细菌在水绵周围的聚集位置判断有效光——巧妙利用"间接指标"
