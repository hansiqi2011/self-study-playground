# 细胞通过分解有机分子获取能量

## 一、ATP——生命活动的直接能源物质

### 结构

- 全称：腺苷三磷酸（adenosine triphosphate）
- 组成：1个腺苷（腺嘌呤 + 核糖）+ 3个磷酸基团
- 结构简式：A—P～P～P（～表示高能磷酸键）

### ATP 与 ADP 的相互转换

```
        细胞呼吸/光合作用
ADP + Pi ─────────────────→ ATP（合成，储能）
        ←─────────────────
         水解释放能量（供能）
```

- ATP 水解 → ADP + Pi + 能量（~30 kJ/mol）
- 人体 ATP 总量仅够维持约 15 秒生命活动，但通过快速循环再生不会耗尽

### ATP 的用途

- 肌肉收缩
- 主动运输
- 生物合成
- 神经冲动传导
- 发光（如萤火虫）

## 二、有氧呼吸

### 总反应式

$$C_6H_{12}O_6 + 6O_2 + 6H_2O \xrightarrow{酶} 6CO_2 + 12H_2O + 能量$$

（注意：左边有 6H₂O 参与反应）

### 两大阶段

#### 第一阶段：糖酵解（细胞质基质）

$$C_6H_{12}O_6 \xrightarrow{酶} 2C_3H_4O_3（丙酮酸）+ 少量ATP + NADH$$

- 场所：**细胞质基质**
- 产物：2分子丙酮酸 + 少量ATP（2个）+ NADH
- 不需要O₂

#### 第二阶段：三羧酸循环 + 氧化磷酸化（线粒体）

- 丙酮酸进入线粒体 → 脱CO₂ → 乙酰辅酶A → 进入三羧酸循环
- 三羧酸循环（线粒体基质）：彻底氧化为CO₂，产生NADH和少量ATP
- 氧化磷酸化（线粒体内膜）：NADH上的电子经电子传递链 → 驱动ATP大量合成
- O₂在此阶段作为最终电子受体，生成H₂O

### 产能统计

1 分子葡萄糖彻底氧化分解 → 约 **30 个 ATP**

能量转换效率：1161 kJ / 2870 kJ ≈ **40%**，其余以热能形式释放

## 三、无氧呼吸

### 条件：缺氧环境

糖酵解仍然进行（产生丙酮酸），但丙酮酸不进入线粒体。

### 两种类型

| 类型 | 产物 | 实例 |
|---|---|---|
| **乳酸发酵** | 乳酸 | 人体肌肉剧烈运动时、乳酸菌 |
| **酒精发酵** | 乙醇 + CO₂ | 酵母菌、果实无氧环境 |

### 反应式

乳酸发酵：
$$C_6H_{12}O_6 \xrightarrow{酶} 2C_3H_6O_3（乳酸）+ 少量能量$$

酒精发酵：
$$C_6H_{12}O_6 \xrightarrow{酶} 2C_2H_5OH + 2CO_2 + 少量能量$$

### 产能

1 分子葡萄糖 → 仅 **2 个 ATP**（全部来自糖酵解阶段）

## 四、有氧呼吸 vs 无氧呼吸

| 比较项 | 有氧呼吸 | 无氧呼吸 |
|---|---|---|
| 是否需要O₂ | 需要 | 不需要 |
| 分解程度 | 彻底（→ CO₂ + H₂O） | 不彻底（→ 乳酸 或 乙醇+CO₂） |
| 场所 | 细胞质基质 + 线粒体 | 仅细胞质基质 |
| 产ATP量 | ~30个 | 2个 |
| 共同阶段 | 糖酵解 | 糖酵解 |

---

## 五、其他有机分子的氧化分解

| 有机物 | 分解途径 |
|---|---|
| 脂肪 | 水解为甘油+脂肪酸 → 甘油→丙酮酸；脂肪酸→乙酰辅酶A → 三羧酸循环 |
| 蛋白质 | 水解为氨基酸 → 脱氨基 → 碳链进入呼吸途径；氨基→尿素排出 |

注意：脂肪酸的彻底氧化**必须有氧**（需进入三羧酸循环）

---

## 易错点

1. **有氧呼吸也需要水参与反应**：总反应式左边有 6H₂O
2. **糖酵解不需要O₂**：有氧和无氧呼吸都经历糖酵解，区别在糖酵解之后
3. **无氧呼吸产物中的能量并未释放**：乳酸/乙醇中仍含有大量化学能（所以酒精能燃烧）
4. **CO₂产生的场所**：有氧呼吸的CO₂在线粒体基质产生；无氧呼吸（酒精发酵）的CO₂在细胞质基质产生
5. **O₂消耗的场所**：线粒体内膜（电子传递链末端）
6. **ATP ≠ 能量**：ATP是能量的载体/货币，不是能量本身
