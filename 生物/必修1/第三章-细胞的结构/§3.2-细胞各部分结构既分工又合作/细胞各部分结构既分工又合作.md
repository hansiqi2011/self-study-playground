# 细胞各部分结构既分工又合作

## 一、细胞器概览

细胞质基质中分布着许多相对独立、具有特定功能的结构——**细胞器**（organelle）。

### 动植物细胞结构比较

| 结构 | 动物细胞 | 植物细胞 | 功能 |
|---|---|---|---|
| 线粒体 | ✓ | ✓ | 有氧呼吸主要场所，"动力车间" |
| 核糖体 | ✓ | ✓ | 蛋白质合成场所 |
| 内质网 | ✓ | ✓ | 蛋白质和脂质合成、加工，"生产车间" |
| 高尔基体 | ✓ | ✓ | 蛋白质加工、分类、包装，"加工包装车间" |
| 溶酶体 | ✓ | ✓ | 含水解酶，细胞内消化 |
| 中心体 | ✓ | ✗（高等植物） | 与细胞分裂有关 |
| 叶绿体 | ✗ | ✓ | 光合作用场所 |
| 液泡 | ✗（通常） | ✓ | 调节渗透压，储存物质 |
| 细胞壁 | ✗ | ✓ | 支持和保护（主要成分：纤维素） |

### 八种细胞器详解

#### 1. 线粒体
- **膜结构**：双层膜（外膜平滑，内膜向内折叠形成**嵴**，增大表面积）
- **内含物**：基质中含有少量 DNA、RNA 和核糖体（半自主性细胞器）
- **功能**：有氧呼吸第二、三阶段的场所（三羧酸循环在基质，氧化磷酸化在内膜）；为细胞供应 ATP
- **分布特点**：代谢旺盛的细胞中数量多（如肌肉细胞、腺细胞）

#### 2. 叶绿体
- **膜结构**：双层膜；内部有**类囊体**（基粒由类囊体堆叠而成）
- **内含物**：类囊体薄膜上含有光合色素（叶绿素、类胡萝卜素）；基质中含少量 DNA、RNA 和核糖体
- **功能**：光合作用的场所（光反应在类囊体薄膜，暗反应在基质）
- **分布**：植物绿色部位的细胞（叶肉细胞为主）

#### 3. 核糖体
- **膜结构**：无膜（由 rRNA + 蛋白质组成的颗粒状结构）
- **组成**：大亚基 + 小亚基
- **功能**：蛋白质合成（翻译 mRNA → 多肽链）的场所
- **分布**：游离于细胞质基质中，或附着在内质网上（粗面内质网）
- **特点**：原核细胞和真核细胞都有；是细胞中数量最多的细胞器

#### 4. 内质网
- **膜结构**：单层膜，呈网状管道系统
- **分类**：
  - **粗面内质网**：表面附有核糖体 → 合成分泌蛋白和膜蛋白
  - **滑面内质网**：无核糖体 → 合成脂质、糖原代谢、解毒
- **功能**：蛋白质折叠和初步加工、脂质合成、Ca²⁺ 储存
- **特点**：占细胞体积 10% 以上；外膜与核膜外层相连

#### 5. 高尔基体
- **膜结构**：单层膜，多个扁平膜囊堆叠
- **功能**：
  - 对蛋白质进一步修饰加工（如加糖链）
  - 分类、包装成不同囊泡发往不同目的地
  - 植物细胞中参与**细胞壁**的形成
- **特点**：介于内质网和质膜之间的"中转站"

#### 6. 溶酶体
- **膜结构**：单层膜囊泡
- **内含物**：60 多种水解酶（蛋白酶、核酸酶、脂肪酶等），内部 pH≈5（酸性）
- **功能**：
  - 消化胞吞进来的物质（病原体、异物）
  - 分解衰老损坏的细胞器（自噬）
  - 细胞凋亡时释放酶促进自溶
- **来源**：由高尔基体出芽形成

#### 7. 液泡
- **膜结构**：单层膜（称为液泡膜/tonoplast）
- **内含物**：细胞液（含有机酸、糖类、色素、无机盐等）
- **功能**：
  - 维持细胞渗透压（调节吸水/失水）
  - 储存营养物质和代谢废物
  - 花瓣/果实颜色（液泡中的花青素等色素）
- **分布**：成熟植物细胞有大液泡（可占细胞体积 90%）；动物细胞通常无明显液泡

#### 8. 中心体
- **膜结构**：无膜
- **结构**：由两个互相垂直的**中心粒**组成（每个中心粒由 9 组三联微管排成圆筒）
- **功能**：细胞分裂时形成纺锤体，牵引染色体移动
- **分布**：动物细胞和低等植物细胞有；高等植物细胞无

### 按膜结构分类

| 类型 | 细胞器 |
|---|---|
| **双层膜** | 线粒体、叶绿体 |
| **单层膜** | 内质网、高尔基体、溶酶体、液泡 |
| **无膜** | 核糖体、中心体 |

## 二、内膜系统

内质网、高尔基体、溶酶体等构成**内膜系统**，将细胞质分隔成许多功能化区域。

作用：
- 区域化提高反应效率
- 为多种酶提供附着位点
- 使各种代谢反应有序进行

### 内质网

- 呈网状排列，通常占细胞体积 10% 以上
- 分为**粗面内质网**（附有核糖体）和**滑面内质网**
- 功能：蛋白质和脂质的合成、加工

### 高尔基体

- 多个扁平膜囊堆叠而成
- 功能：蛋白质的进一步加工、分类、包装
- 在植物细胞中还与细胞壁的形成有关

### 溶酶体

- 单层膜囊泡，内含多种水解酶
- 功能：细胞内消化（分解衰老的细胞器、入侵的病原体等）

---

## 三、细胞骨架

- 由蛋白质纤维（微管、微丝等）构成的网络状框架结构
- 功能：
  - 支撑细胞形态
  - 维持细胞内部空间格局
  - 物质运输的"轨道"（细胞器和囊泡可沿骨架移动）

---

## 四、细胞核

- 通常为球形，体积占细胞的 5%~10%
- 一般一个细胞一个核（骨骼肌细胞含几十到几百个核；哺乳动物成熟红细胞和植物筛管细胞无核）

### 结构

| 结构 | 特点 |
|---|---|
| **核膜** | 双层膜，有核孔 |
| **核孔** | 物质（如 mRNA）进出的通道 |
| **核仁** | 与核糖体的形成有关 |
| **染色质** | 主要由 DNA 和蛋白质组成；可被碱性染料（苏木精、洋红）染成深色 |

**核心功能**：遗传信息的储存和传递

- mRNA 携带 DNA 的遗传信息 → 从核孔进入细胞质 → 在核糖体上指导蛋白质合成

## 五、分泌蛋白的合成与分泌（各结构协作的经典案例）

以胰腺细胞合成和分泌消化酶为例：

```
核糖体（合成肽链）
    ↓
内质网（加工为较成熟的蛋白质）
    ↓ 出芽形成囊泡
高尔基体（进一步修饰加工）
    ↓ 形成运输囊泡
沿细胞骨架移动 → 囊泡与质膜融合 → 蛋白质分泌到细胞外
```

**能量供应**：整个过程需要的能量主要由**线粒体**提供。

### 同位素标记实验证据

用 ³H 标记氨基酸注入豚鼠胰腺泡细胞：
- 3 min → 出现在内质网（附有核糖体）
- 17 min → 出现在高尔基体
- 117 min → 出现在质膜内侧囊泡和细胞外分泌物中

### 膜面积的变化

分泌蛋白分泌过程中：
- 内质网膜面积**减少**（出芽形成囊泡）
- 高尔基体膜面积**基本不变**（一边融合一边出芽）
- 质膜面积**增大**（囊泡与之融合）

## 易错点

1. **核糖体无膜结构**：但它是蛋白质合成的场所，所有细胞都有
2. **高等植物无中心体**：但低等植物（如衣藻）有中心体
3. **线粒体和叶绿体含有少量 DNA**：能自主复制，具有半自主性
4. **分泌蛋白 ≠ 所有蛋白质都经过内质网和高尔基体**：只有分泌蛋白和膜蛋白走这条路；细胞质基质中的蛋白质由游离核糖体直接合成
5. **染色质和染色体是同一物质的不同形态**：分裂期高度螺旋 → 染色体；间期松散 → 染色质
