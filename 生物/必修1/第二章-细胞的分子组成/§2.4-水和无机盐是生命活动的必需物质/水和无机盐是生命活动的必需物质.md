# 水和无机盐是生命活动的必需物质

## 核心概念

- **水**是细胞中含量最多的化合物（约占总质量 70%），构成细胞内外环境
- **无机盐**含量虽少，但以离子形式参与重要生命活动

---

## 一、水

### 1. 水在生物体中的分布

- 水生生物含水量 > 陆生生物
- 代谢活动高的器官含水量高（如脑 84%、血液 83%）
- 代谢活动低的含水量低（如骨骼 22%、牙齿 10%）
- 休眠种子含水量 <10%

### 2. 水分子的特点——极性分子

- O 端带弱负电荷，H 端带弱正电荷
- 极性特点使水成为**良好溶剂**——极性物质（无机盐、大部分有机分子）易溶于水
- 水的比热容大 → 维持细胞温度相对稳定

### 3. 水的存在形式

| 形式 | 特点 | 占比 | 功能 |
|---|---|---|---|
| **自由水** | 游离态，可自由流动 | 绝大部分（~95.5%） | 物质运输、化学反应介质、代谢参与 |
| **结合水** | 与其他分子结合，不能自由流动 | 约 4.5% | 维持其他分子的结构和活性 |

### 4. 水与生命活动的关系

- 缺水 10% → 生理活动紊乱
- 缺水 20% → 生命活动终止
- 种子晒干（去除自由水）→ 代谢降低，便于保存
- 种子过度干燥（失去结合水）→ 无法萌发

> **自由水/结合水比值**越大 → 代谢越旺盛

---

## 二、无机盐

### 1. 存在形式

大多以**离子**状态存在：
- 阳离子：K⁺、Na⁺、Ca²⁺、Mg²⁺、Zn²⁺、Mn²⁺、Fe²⁺、Fe³⁺
- 阴离子：Cl⁻、SO₄²⁻、HCO₃⁻、PO₄³⁻

### 2. 无机盐的功能

| 功能类型 | 举例 |
|---|---|
| **组成化合物** | Fe → 血红蛋白；Mg → 叶绿素 |
| **参与代谢** | 金属离子作为酶的辅助因子 |
| **调节渗透压** | Na⁺、K⁺、Cl⁻ 等维持内环境稳定 |
| **调节酸碱平衡** | HCO₃⁻、HPO₄²⁻、H₂PO₄⁻（缓冲对） |
| **维持正常生理功能** | Ca²⁺（45~55 mg/L）→ 低于此值引发肌肉抽搐 |

### 3. 具体实例

| 离子 | 缺乏时表现 |
|---|---|
| Fe | 缺铁性贫血 |
| Mg²⁺ | 植物叶脉间缺绿，叶片变黄 |
| Ca²⁺ | 血钙过低 → 肌肉抽搐 |
| I⁻ | 地方性甲状腺肿 |
| Zn²⁺、Mn²⁺ | 植物叶片不同程度缺绿症 |

---

## 易错点

- **水是含量最多的化合物**，但如果问"含量最多的元素"答案是 O（因为水中 O 质量大）
- 自由水参与代谢反应（如光合作用原料、水解反应），结合水不直接参与代谢
- 无机盐以**离子**形式存在而非分子形式——不能说"细胞中有 NaCl 分子"
- 运动后补充的是**淡盐水**而非纯水——因为出汗丢失了无机盐离子
