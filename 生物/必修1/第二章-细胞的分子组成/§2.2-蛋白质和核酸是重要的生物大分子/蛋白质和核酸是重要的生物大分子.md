# 蛋白质和核酸是重要的生物大分子

## 核心概念

- **蛋白质**由氨基酸组成，是生命活动的主要承担者，功能取决于氨基酸序列及空间结构
- **核酸**由核苷酸聚合而成，是储存与传递遗传信息的生物大分子

---

## 一、蛋白质

### 1. 蛋白质是生命活动的主要承担者

| 功能类型 | 举例 |
|---|---|
| 结构蛋白 | 胶原蛋白（结缔组织，支持保护） |
| 转运蛋白 | 血红蛋白（运输 O₂）、膜转运蛋白 |
| 催化（酶） | 绝大多数酶是蛋白质 |
| 信息传递 | 受体蛋白、激素（如胰岛素） |
| 免疫防御 | 免疫球蛋白（抗体） |

### 2. 氨基酸——蛋白质的基本单位

**结构通式**：中心碳原子连接：
- 一个氨基（—NH₂）
- 一个羧基（—COOH）
- 一个氢原子（—H）
- 一个侧链（**R 基**）——不同氨基酸的区别在于 R 基不同

常见氨基酸有 **20 种**，分为极性（亲水）和非极性（亲脂）两大类。

**人体必需氨基酸**（8 种，不能自身合成）：苏氨酸、色氨酸、赖氨酸、缬氨酸、苯丙氨酸、亮氨酸、异亮氨酸、甲硫氨酸。

### 3. 脱水缩合形成肽键

$$\text{—NH}_2 + \text{HOOC—} \longrightarrow \text{—CO—NH—} + \text{H}_2\text{O}$$

- 肽键结构：**—CO—NH—**
- 两个氨基酸 → 二肽（1 个肽键，脱 1 分子水）
- n 个氨基酸 → 形成 **(n-1) 个肽键**，脱去 **(n-1) 分子水**（一条链时）

### 4. 蛋白质的结构层次

```
氨基酸 → 肽链（氨基酸序列） → 空间结构（折叠） → 蛋白质
```

- **氨基酸序列**决定空间结构
- **空间结构**决定功能
- 一个蛋白质可由一条或多条肽链构成（如血红蛋白由 4 条肽链）

### 5. 结构与功能的关系

- 氨基酸序列中**关键位点**改变 → 功能巨大变化（如镰状细胞贫血：一个氨基酸替换 → 红细胞变形）
- 高温、强酸、强碱等 → 蛋白质空间结构改变（变性）→ 功能丧失

### 蛋白质多样性的基础

20 种氨基酸的不同**种类、数量、排列顺序** → 蛋白质种类极其丰富（理论上 50 个氨基酸的肽链可有 $20^{50}$ 种序列）

## 二、核酸

### 1. 核酸的分类

| 比较项 | DNA（脱氧核糖核酸） | RNA（核糖核酸） |
|---|---|---|
| 五碳糖 | 脱氧核糖 | 核糖 |
| 碱基 | A、T、G、C | A、U、G、C |
| 结构 | 通常双链 | 通常单链 |
| 分布 | 主要在细胞核（线粒体、叶绿体少量） | 主要在细胞质 |
| 功能 | 储存遗传信息 | 参与遗传信息传递与表达 |

**碱基种类和其简称的对应**
A：==腺嘌呤==
T：==胸腺嘧啶==
U：==尿嘧啶==
G：==鸟嘌呤==
C：==胞嘧啶==

### 2. 核苷酸——核酸的基本单位

核苷酸 = **五碳糖 + 碱基 + 磷酸基团**

- 脱氧核苷酸（4 种）→ 组成 DNA
- 核糖核苷酸（4 种）→ 组成 RNA

### 3. 核酸的结构

- 核苷酸之间通过"**磷酸–糖–磷酸–糖**"脱水缩合形成链状结构
- 碱基位于链的一侧
- DNA 双链中碱基互补配对：**A-T，G-C**

### 4. DNA 储存遗传信息

- 脱氧核苷酸只有 4 种，但数量众多、排列顺序多样
- 遗传信息储存在脱氧核苷酸的排列顺序中
- RNA 病毒的遗传信息储存在 RNA 中（如 HIV、SARS-CoV-2）

## 蛋白质降解（拓展）

- **泛素-蛋白酶体途径**：细胞准确降解多余蛋白质的机制
- 三种酶协作：E1（泛素活化酶）、E2（泛素偶连酶）、E3（泛素-蛋白连接酶）
- E3 的专一性决定哪个蛋白质被标记降解
- 2004 年诺贝尔化学奖

---

## 易错点

- **肽键形成**时参与的只能是中心碳原子上的氨基和羧基（不是 R 基上的）
- DNA 中有 T 无 U，RNA 中有 U 无 T——判断核酸类型的关键
- 蛋白质变性是**空间结构**被破坏，肽键未断裂
- 核酸的"碱基序列"≠ "核苷酸序列"但实际上一一对应（因为糖和磷酸相同）
- n 个氨基酸形成 m 条肽链 → 肽键数 = n - m，脱水数 = n - m
