# 子集与推出关系

## 核心思想

本节揭示了**集合的包含关系**（$A \subseteq B$）与**命题的推出关系**（$\alpha \Rightarrow \beta$）之间的等价性，是连接集合论和命题逻辑的桥梁。

> [!definition] 子集与推出关系的等价定理
> 设 $A$、$B$ 是非空集合，$A = \{a \mid a \text{ 具有性质 } \alpha\}$，$B = \{b \mid b \text{ 具有性质 } \beta\}$，则：
> $$A \subseteq B \iff \alpha \Rightarrow \beta$$

## 定理证明

> [!important] 等价性证明
> **充分性**（$A \subseteq B \Rightarrow \alpha \Rightarrow \beta$）：
> 如果 $a_1$ 具有性质 $\alpha$，那么 $a_1 \in A$，而 $A \subseteq B$，所以 $a_1 \in B$。因此 $a_1$ 具有性质 $\beta$，即 $\alpha \Rightarrow \beta$。
>
> **必要性**（$\alpha \Rightarrow \beta \Rightarrow A \subseteq B$）：
> 如果 $a_1 \in A$，那么 $a_1$ 具有性质 $\alpha$，由 $\alpha \Rightarrow \beta$，可推得 $a_1$ 具有性质 $\beta$，所以 $a_1 \in B$，因此 $A \subseteq B$。
>
> 综上所述，$A \subseteq B$ 与 $\alpha \Rightarrow \beta$ 等价。

## 核心转化关系

| 集合关系 | 推出关系 | 条件关系 |
|---------|---------|---------|
| $A \subseteq B$ | $\alpha \Rightarrow \beta$ | $\alpha$ 是 $\beta$ 的充分条件 |
| $B \subseteq A$ | $\beta \Rightarrow \alpha$ | $\alpha$ 是 $\beta$ 的必要条件 |
| $A = B$ | $\alpha \Leftrightarrow \beta$ | $\alpha$ 是 $\beta$ 的充要条件 |
| $A \subsetneq B$ | $\alpha \Rightarrow \beta$ 且 $\beta \not\Rightarrow \alpha$ | $\alpha$ 是 $\beta$ 的充分非必要条件 |
| $B \subsetneq A$ | $\beta \Rightarrow \alpha$ 且 $\alpha \not\Rightarrow \beta$ | $\alpha$ 是 $\beta$ 的必要非充分条件 |

> [!warning] 方法论
> 判断条件关系时，可以将命题条件 $\alpha$、$\beta$ 构造为集合 $A$、$B$，然后通过比较集合的包含关系来确定充分/必要条件关系。这将逻辑问题**转化为集合问题**，往往更直观。

## 引入动机

以 $x > 5$ 与 $x > 3$ 为例：
- 我们知道 $x > 5$ 是 $x > 3$ 的充分条件
- 记集合 $A = \{x \mid x > 5\}$，$B = \{x \mid x > 3\}$
- 因为集合 $A$ 的元素性质"$x > 5$"可推出集合 $B$ 的元素性质"$x > 3$"
- 即如果 $x \in A$，则 $x > 5$，可推得 $x > 3$，那么 $x \in B$
- 所以 $A \subseteq B$，反之亦然

## 例题

### 例1

试用子集与推出关系来说明 $\alpha$ 是 $\beta$ 的什么条件。

**(1)** $\alpha$：$x = 1$；$\beta$：$x^2 = 1$

> [!hint]- 解答
> 设 $A = \{x \mid x = 1\}$，$B = \{x \mid x^2 = 1\}$。
>
> 因为 $A = \{1\}$，$B = \{x \mid x^2 = 1\} = \{-1, 1\}$，
>
> 所以 $A \subsetneq B$。
>
> 由此得到：$x = 1$ 是 $x^2 = 1$ 的**充分非必要条件**。

**(2)** $\alpha$：正整数 $n$ 被 $5$ 整除；$\beta$：正整数 $n$ 的个位数是 $5$

> [!hint]- 解答
> $A = \{n \mid n = 5k, k \in \mathbb{N}^*\}$，$B = \{n \mid n \text{ 的个位数是 } 5\}$。
>
> 因为 $A = \{n \mid n \text{ 的个位数是 } 5\} \cup \{n \mid n \text{ 的个位数是 } 0\}$，
>
> 所以 $B \subsetneq A$。
>
> 因此"正整数 $n$ 的个位数是 $5$"是"正整数 $n$ 被 $5$ 整除"的充分非必要条件，即"正整数 $n$ 被 $5$ 整除"是"正整数 $n$ 的个位数是 $5$"的**必要非充分条件**。

### 例2

设 $\alpha$：$1 \leqslant x \leqslant 3$，$\beta$：$m + 1 \leqslant x \leqslant 2m + 4$，$m \in \mathbf{R}$，$\alpha$ 是 $\beta$ 的充分条件，求 $m$ 的取值范围。

> [!hint]- 解答
> 设 $A = \{x \mid 1 \leqslant x \leqslant 3\}$，$B = \{x \mid m + 1 \leqslant x \leqslant 2m + 4\}$。
>
> 因为 $\alpha$ 是 $\beta$ 的充分条件，所以 $A \subseteq B$。
>
> ![[图1-6-数轴示意图.png]]
>
> 由图 1-6，可得：
> $$\begin{cases} m + 1 \leqslant 1, \\ 3 \leqslant 2m + 4. \end{cases}$$
>
> 解得 $-\dfrac{1}{2} \leqslant m \leqslant 0$。
>
> 所以 $m$ 的取值范围是 $-\dfrac{1}{2} \leqslant m \leqslant 0$。

## 练习 1.6

**1.** 试用子集与推出关系来说明 $\alpha$ 是 $\beta$ 的什么条件。

(1) $\alpha$：$x = 1$ 且 $y = 2$，$\beta$：$x + y = 3$

> [!hint]- 解答
> 设 $A = \{(x,y) \mid x = 1 \text{ 且 } y = 2\} = \{(1, 2)\}$，
> $B = \{(x,y) \mid x + y = 3\}$。
>
> 显然 $(1, 2) \in B$（因为 $1 + 2 = 3$），所以 $A \subsetneq B$。
>
> 因此 $\alpha$ 是 $\beta$ 的**充分非必要条件**。

(2) $\alpha$：$a + b > 0$，$\beta$：$a > 0, b > 0$

> [!hint]- 解答
> 设 $A = \{(a,b) \mid a + b > 0\}$，$B = \{(a,b) \mid a > 0 \text{ 且 } b > 0\}$。
>
> 若 $a > 0$ 且 $b > 0$，则 $a + b > 0$，所以 $B \subseteq A$。
> 但 $a = 3, b = -1$ 时 $a + b > 0$ 但 $b < 0$，所以 $A \not\subseteq B$。
>
> 即 $B \subsetneq A$，因此 $\alpha$ 是 $\beta$ 的**必要非充分条件**。

(3) $\alpha$：$xy > 0$，$\beta$：$|x + y| = |x| + |y|$

> [!hint]- 解答
> 设 $A = \{(x,y) \mid xy > 0\}$，$B = \{(x,y) \mid |x+y| = |x| + |y|\}$。
>
> $|x+y| = |x| + |y|$ 成立当且仅当 $xy \geqslant 0$（即 $x, y$ 同号或至少有一个为零）。
>
> 而 $xy > 0$ 要求 $x, y$ 同号且均不为零，所以 $A \subsetneq B$。
>
> 因此 $\alpha$ 是 $\beta$ 的**充分非必要条件**。

(4) $\alpha$：某数是整数的 $\dfrac{1}{3}$，$\beta$：某数与整数相差 $\dfrac{1}{3}$

> [!hint]- 解答
> 设 $A = \left\{\dfrac{n}{3} \mid n \in \mathbb{Z}\right\}$，$B = \left\{n \pm \dfrac{1}{3} \mid n \in \mathbb{Z}\right\}$。
>
> 整数的 $\dfrac{1}{3}$ 形如 $\dfrac{n}{3}$，分三类：
> - $n = 3k$：得整数 $k$
> - $n = 3k + 1$：得 $k + \dfrac{1}{3}$（与整数相差 $\dfrac{1}{3}$）
> - $n = 3k + 2$：得 $k + \dfrac{2}{3}$（与整数相差 $\dfrac{1}{3}$，因为距 $k+1$ 差 $\dfrac{1}{3}$）
>
> 而与整数相差 $\dfrac{1}{3}$ 的数形如 $n + \dfrac{1}{3}$ 或 $n - \dfrac{1}{3}$（即 $n + \dfrac{2}{3}$ 的另一种写法不对，应为 $(n+1) - \dfrac{1}{3}$）。
>
> 所以 $B \subsetneq A$（整数本身在 $A$ 中但不在 $B$ 中）。
>
> 因此 $\alpha$ 是 $\beta$ 的**必要非充分条件**。

**2.** 设 $\alpha$：$1 \leqslant x < 4$，$\beta$：$x < m$，$\alpha$ 是 $\beta$ 的充分条件，求实数 $m$ 的取值范围。

> [!hint]- 解答
> 设 $A = \{x \mid 1 \leqslant x < 4\}$，$B = \{x \mid x < m\}$。
>
> 因为 $\alpha$ 是 $\beta$ 的充分条件，所以 $A \subseteq B$。
>
> 即对所有 $1 \leqslant x < 4$，都有 $x < m$。
>
> 因此需要 $m \geqslant 4$。
>
> 所以实数 $m$ 的取值范围是 $m \geqslant 4$。

## 易错点

> [!warning] 常见错误
> 1. **忘记验证集合非空**：定理要求 $A$、$B$ 为非空集合。当参数使集合为空集时需单独讨论。
> 2. **子集方向搞反**：$\alpha$ 是 $\beta$ 的充分条件 $\Leftrightarrow$ $\alpha \Rightarrow \beta$ $\Leftrightarrow$ $A \subseteq B$（$\alpha$ 对应的集合是**小集合**）。
> 3. **参数问题中忽略端点**：如例2中需注意不等号是否取等，边界条件必须逐一检验。
> 4. **混淆"$\alpha$ 是 $\beta$ 的充分条件"与"$\beta$ 是 $\alpha$ 的充分条件"**：前者是 $A \subseteq B$，后者是 $B \subseteq A$。

## 解题方法总结

> [!important] 用集合法判断条件关系的步骤
> 1. 将条件 $\alpha$ 和 $\beta$ 分别构造为集合 $A$ 和 $B$
> 2. 判断 $A$ 和 $B$ 的包含关系
> 3. 由包含关系得出条件关系：
>    - $A \subseteq B$ → $\alpha$ 是 $\beta$ 的充分条件
>    - $B \subseteq A$ → $\alpha$ 是 $\beta$ 的必要条件
>    - $A = B$ → 充要条件
>    - $A \not\subseteq B$ 且 $B \not\subseteq A$ → 既不充分也不必要
