# 并集

## 定义

> [!definition]
> 由所有属于集合 $A$ **或者**属于集合 $B$ 的元素组成的集合叫做集合 $A$、$B$ 的**并集**（union），记作 $A \cup B$，读作"$A$ 并 $B$"。即
> $$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$$

## 核心内容

### Venn 图表示

![[图1-3-并集的三种情况.png]]

集合 $A \cup B$ 的图示法表示如图 1-3 中的阴影部分：
1. $A$、$B$ 部分相交 —— 并集为两个圆覆盖的所有区域
2. $A \subseteq B$ —— 并集为 $B$
3. $A$、$B$ 不相交 —— 并集为两个圆的全部区域

### 重要性质

> [!important]
> - $A \cup B = B \cup A$（交换律）
> - $A \cup A = A$（幂等律）
> - $A \cup \varnothing = A$（空集是并集的单位元）
> - 若 $A \subseteq B$，则 $A \cup B = B$
> - $A \subseteq A \cup B$，$B \subseteq A \cup B$（两集合都是并集的子集）
> - $A \cap B \subseteq A \subseteq A \cup B$（交集 ⊆ 原集合 ⊆ 并集）

## 例题

### 例2

已知集合 $A = \{a, b, c, d\}$，$B = \{b, d, e, f\}$，求 $A \cap B$，$A \cup B$。

> [!hint]- 解答
> **解：**
> $$A \cap B = \{b, d\}$$
> $$A \cup B = \{a, b, c, d, e, f\}$$

### 例3

已知集合 $A = \{x \mid -2 < x < 2\}$，$B = \{x \mid x > 1 \text{ 或 } x < -1\}$，求 $A \cup B$。

> [!hint]- 解答
> **解：**
>
> $A$ 覆盖 $(-2, 2)$，$B$ 覆盖 $(-\infty, -1) \cup (1, +\infty)$。
>
> 两者的并集覆盖了整个实数轴上的所有点，故
> $$A \cup B = \mathbf{R}$$

### 例4

已知 $A = \{x \mid x = 2k,\, k \in \mathbf{Z}\}$，$B = \{x \mid x = 2k - 1,\, k \in \mathbf{Z}\}$，求 $A \cup B$。

> [!hint]- 解答
> **解：**
> $$A \cup B = \{x \mid x = 2k \text{ 或 } 2k - 1,\, k \in \mathbf{Z}\} = \{x \mid x = k,\, k \in \mathbf{Z}\}$$
>
> 即 $A \cup B = \mathbf{Z}$。
>
> **理解：** $A$ 是全体偶数集，$B$ 是全体奇数集，二者的并集当然是全体整数集。

## 练习

### 练习 1.3(2)

**1.** 已知 $\mathbf{Q}, \mathbf{N}, \mathbf{R}, \mathbf{Z}$ 分别表示有理数集、自然数集、实数集和整数集，求 $\mathbf{Q} \cup \mathbf{N}$，$\mathbf{R} \cap \mathbf{Z}$。

> [!hint]- 答案
> - $\mathbf{Q} \cup \mathbf{N} = \mathbf{Q}$（因为 $\mathbf{N} \subseteq \mathbf{Q}$）
> - $\mathbf{R} \cap \mathbf{Z} = \mathbf{Z}$（因为 $\mathbf{Z} \subseteq \mathbf{R}$）

**2.** 用 $A, B, \in, \subseteq, \supseteq$ 填空：

（1）若 $A \subseteq B$，则 $A \cup B = $ ______；

（2）$A$ ______ $A \cup B$；$A \cap B$ ______ $B$ ______ $A \cup B$。

> [!hint]- 答案
> （1）$A \cup B = B$
>
> （2）$A \subseteq A \cup B$；$A \cap B \subseteq B \subseteq A \cup B$

**3.** 已知集合 $A = \{x \mid -1 < x \leqslant 3\}$，$B = \{x \mid x \geqslant 4 \text{ 或 } x < 0\}$，求 $A \cup B$，$A \cap B$。

> [!hint]- 解答
> **解：**
> - $A \cup B = \{x \mid x \leqslant 3 \text{ 或 } x \geqslant 4\}$，即 $A \cup B = \{x \mid x \neq (3, 4) \text{ 中的数}\}$。
>
>   更准确地：$A = (-1, 3]$，$B = (-\infty, 0) \cup [4, +\infty)$
>
>   $A \cup B = (-\infty, 3] \cup [4, +\infty)$
>
> - $A \cap B = \{x \mid -1 < x < 0\} = (-1, 0)$

**4.** 已知集合 $A = \{x \mid x = 3n,\, n \in \mathbf{N}\}$，$B = \{x \mid x = 6n,\, n \in \mathbf{N}\}$，求 $A \cup B$，$A \cap B$。

> [!hint]- 解答
> **解：**
> - $A = \{0, 3, 6, 9, 12, \ldots\}$（3 的非负整数倍）
> - $B = \{0, 6, 12, 18, \ldots\}$（6 的非负整数倍）
>
> 由于 $B \subseteq A$（6 的倍数一定是 3 的倍数），故
> - $A \cup B = A = \{x \mid x = 3n,\, n \in \mathbf{N}\}$
> - $A \cap B = B = \{x \mid x = 6n,\, n \in \mathbf{N}\}$

## 易错点

> [!warning]
> - **"或"的含义**：数学中的"或"是**含或**（inclusive or），即"属于 $A$ 或属于 $B$"包括同时属于两者的情况。并集不会重复包含公共元素。
> - **并集与交集混淆**：$A \cup \varnothing = A$（并空集不变），但 $A \cap \varnothing = \varnothing$（交空集为空）。两者恰好相反！
> - **子集关系推断**：若 $A \subseteq B$，则 $A \cup B = B$（不是 $A$）；$A \cap B = A$（不是 $B$）。口诀："并取大，交取小"。
> - **区间并集不能合并端点缝隙**：如 $A = (0, 2)$，$B = (3, 5)$，则 $A \cup B = (0, 2) \cup (3, 5)$，不能写成一个区间。
