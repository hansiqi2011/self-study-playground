# 补集

## 定义

> [!definition]
> **全集**（universe）：在研究集合与集合之间的关系时，这些集合往往是某个给定集合的子集。这个确定的集合叫做**全集**，常用符号 $U$ 表示。全集含有我们所要研究的各个集合的全部元素。

> [!definition]
> 设 $U$ 为全集，$A$ 是 $U$ 的子集，则由 $U$ 中所有**不属于** $A$ 的元素组成的集合叫做集合 $A$ 在全集 $U$ 中的**补集**（complementary set），记作 $\complement_U A$，读作"$A$ 补"。即
> $$\complement_U A = \{x \mid x \in U,\, x \notin A\}$$

## 核心内容

### 全集的确定

> [!important]
> 全集 $U$ 的选取取决于研究问题的范围：
> - 讨论方程 $ax^2 + bx + c = 0$ 的**实数解**时，全集为 $\mathbf{R}$
> - 讨论方程的**有理数解**时，全集为 $\mathbf{Q}$
> - 全集必须包含所讨论的所有集合作为其子集

### Venn 图表示

![[图1-4-补集的图示.png]]

- 通常用矩形的内部表示全集 $U$
- 矩形内、集合 $A$ 外的部分（阴影）表示补集 $\complement_U A$

### 重要性质

> [!important]
> - $\complement_U A \cup A = U$（补集与原集合的并集为全集）
> - $\complement_U A \cap A = \varnothing$（补集与原集合无公共元素）
> - $\complement_U(\complement_U A) = A$（补集的补集等于自身）
> - $\complement_U U = \varnothing$（全集的补集为空集）
> - $\complement_U \varnothing = U$（空集的补集为全集）

### 德摩根定律（De Morgan's Laws）

> [!important]
> $$\complement_U(A \cup B) = \complement_U A \cap \complement_U B$$
> $$\complement_U(A \cap B) = \complement_U A \cup \complement_U B$$
>
> 口诀：**"并的补等于补的交，交的补等于补的并"**

## 例题

### 例5

设 $U = \mathbf{R}$，$A = \{x \mid 1 \leqslant x < 2\}$，写出 $\complement_U A$。

> [!hint]- 解答
> **解：**
> $$\complement_U A = \{x \mid x < 1 \text{ 或 } x \geqslant 2\}$$
>
> **理解：** 在实数范围内，不属于 $[1, 2)$ 的数，就是 $(-\infty, 1) \cup [2, +\infty)$。注意端点开闭取反：原来 $1$ 处取"$\leqslant$"（闭），补集中 $1$ 处取"$<$"（开）；原来 $2$ 处取"$<$"（开），补集中 $2$ 处取"$\geqslant$"（闭）。

### 例6

设 $U = \{a, b, c, d, e\}$，$A = \{a, b\}$，$B = \{b, c, d\}$，分别求 $\complement_U A \cap \complement_U B$，$\complement_U(A \cap B)$，$\complement_U(A \cup B)$，$\complement_U A \cup \complement_U B$。

> [!hint]- 解答
> **解：**
>
> $\because\; U = \{a, b, c, d, e\}$，$A = \{a, b\}$
>
> $\therefore\; \complement_U A = \{c, d, e\}$
>
> 又 $B = \{b, c, d\}$，故 $\complement_U B = \{a, e\}$
>
> $$\complement_U A \cap \complement_U B = \{c, d, e\} \cap \{a, e\} = \{e\}$$
>
> $$\complement_U A \cup \complement_U B = \{c, d, e\} \cup \{a, e\} = \{a, c, d, e\}$$
>
> $\because\; A \cup B = \{a, b, c, d\}$
>
> $\therefore\; \complement_U(A \cup B) = \{e\}$
>
> $\because\; A \cap B = \{b\}$
>
> $\therefore\; \complement_U(A \cap B) = \{a, c, d, e\}$
>
> **验证德摩根定律：**
> - $\complement_U(A \cup B) = \{e\} = \complement_U A \cap \complement_U B$ ✓
> - $\complement_U(A \cap B) = \{a, c, d, e\} = \complement_U A \cup \complement_U B$ ✓

## 练习

### 练习 1.3(3)

**1.** 若 $U = \mathbf{R}$，判断下列各运算是否正确：

（1）$\complement_U \mathbf{Q} \cup \mathbf{Q} = \mathbf{R}$；

（2）$\complement_U \mathbf{Q} \cap \mathbf{Q} = \varnothing$；

（3）$\complement_U(\complement_U A) = A$；

（4）$\complement_U \varnothing = \mathbf{R}$。

> [!hint]- 答案
> （1）正确。无理数与有理数合起来就是全体实数。
>
> （2）正确。无理数与有理数没有公共元素。
>
> （3）正确。补集的补集等于原集合（前提是均在同一全集下）。
>
> （4）正确。不属于空集的实数就是全体实数。

**2.** 已知集合 $A = \{x \mid -2 < x \leqslant 1\}$，$U = \mathbf{R}$，求 $\complement_U A$。

> [!hint]- 解答
> **解：** $\complement_U A = \{x \mid x \leqslant -2 \text{ 或 } x > 1\} = (-\infty, -2] \cup (1, +\infty)$
>
> 端点变化：$-2$ 处由开变闭，$1$ 处由闭变开。

**3.** 已知集合 $U = \{x \mid x < 9,\, x \in \mathbf{N}^*\}$，$A = \{1, 2, 3, 7\}$，$B = \{1, 3, 4, 5, 6\}$，求 $\complement_U A \cup \complement_U B$，$\complement_U(A \cap B)$。

> [!hint]- 解答
> **解：** $U = \{1, 2, 3, 4, 5, 6, 7, 8\}$
>
> $\complement_U A = \{4, 5, 6, 8\}$，$\complement_U B = \{2, 7, 8\}$
>
> $\complement_U A \cup \complement_U B = \{2, 4, 5, 6, 7, 8\}$
>
> $A \cap B = \{1, 3\}$，$\complement_U(A \cap B) = \{2, 4, 5, 6, 7, 8\}$
>
> 验证：$\complement_U A \cup \complement_U B = \complement_U(A \cap B)$ ✓（德摩根定律）

**4.** 用图示法表示下列集合：

（1）$\complement_U A \cap \complement_U B$；

（2）$\complement_U(A \cup B)$。

> [!hint]- 答案
> 两者表示的是同一区域：矩形（全集 $U$）内，集合 $A$ 和集合 $B$ 的圆**都不覆盖**的部分。
>
> 这正是德摩根定律 $\complement_U(A \cup B) = \complement_U A \cap \complement_U B$ 的图形验证。

## 易错点

> [!warning]
> - **忘记指定全集**：补集必须相对于全集而言。$\complement_U A$ 中的 $U$ 不能省略，不同全集下同一集合的补集不同。例如 $U = \mathbf{R}$ 时 $\complement_U \mathbf{Q}$ 是无理数集；$U = \mathbf{Q}$ 时 $\complement_U \mathbf{Q} = \varnothing$。
> - **端点开闭取反**：对区间求补集时，开区间端点变闭，闭区间端点变开。
>   - $A = [1, 2)$ → $\complement_{\mathbf{R}} A = (-\infty, 1) \cup [2, +\infty)$
>   - 特别注意：$\pm\infty$ 处永远是开的。
> - **空集的补集**：$\complement_U \varnothing = U$，不是 $\varnothing$！
> - **德摩根定律方向**：
>   - "并"变"交"：$\complement_U(A \cup B) = \complement_U A \,\cap\, \complement_U B$
>   - "交"变"并"：$\complement_U(A \cap B) = \complement_U A \,\cup\, \complement_U B$
>   - 千万不要把"∪"和"∩"搞反。
> - **$A$ 必须是 $U$ 的子集**：求 $\complement_U A$ 的前提是 $A \subseteq U$，否则补集无意义。
