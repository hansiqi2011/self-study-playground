# 交集

## 定义

> [!definition]
> 由集合 $A$ 和集合 $B$ 的所有**公共元素**组成的集合叫做 $A$ 与 $B$ 的**交集**（intersection），记作 $A \cap B$，读作"$A$ 交 $B$"。即
> $$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$

## 核心内容

### 引入

考察集合的元素：
- $A = \{x \mid x \text{ 为 } 10 \text{ 的正约数}\} = \{1, 2, 5, 10\}$
- $B = \{x \mid x \text{ 为 } 15 \text{ 的正约数}\} = \{1, 3, 5, 15\}$
- $C = \{x \mid x \text{ 为 } 10 \text{ 与 } 15 \text{ 的正公约数}\} = \{1, 5\}$

集合 $C$ 的元素恰是集合 $A$ 与 $B$ 的所有公共元素。

### Venn 图表示

![[图1-2-交集的三种情况.png]]

交集 $A \cap B$ 的三种情况：
1. $A$、$B$ 有公共元素，也有非公共元素（部分相交）
2. $A$ 是 $B$ 的子集，即 $A \subseteq B$，此时 $A \cap B = A$
3. $A$、$B$ 没有公共元素，即 $A \cap B = \varnothing$

### 重要性质

> [!important]
> - $A \cap B = B \cap A$（交换律）
> - $A \cap A = A$（幂等律）
> - $A \cap \varnothing = \varnothing$（空集与任何集合的交集为空集）
> - 若 $A \subseteq B$，则 $A \cap B = A$
> - $A \cap B \subseteq A$，$A \cap B \subseteq B$（交集是两集合的子集）

## 例题

### 例1

设 $A$、$B$ 两个集合分别为

$$A = \{(x, y) \mid 2x + y = 10\},\quad B = \{(x, y) \mid 3x - y = 5\}$$

求 $A \cap B$，并且说明它的意义。

> [!hint]- 解答
> **解：**
> $$A \cap B = \left\{(x, y) \middle| \begin{cases} 2x + y = 10 \\ 3x - y = 5 \end{cases}\right\} = \{(3, 4)\}$$
>
> $A \cap B$ 表示方程组 $\begin{cases} 2x + y = 10 \\ 3x - y = 5 \end{cases}$ 的解的集合，也可以理解为两个一次函数图像的交点坐标的集合。

## 练习

### 练习 1.3(1)

**1.** 用 $A, B, \in, \subseteq, \supseteq$ 填空：

（1）若 $A \subseteq B$，则 $A \cap B = $ ______；

（2）$A \cap B$ ______ $A$；$A \cap B$ ______ $B$。

> [!hint]- 答案
> （1）$A \cap B = A$
>
> （2）$A \cap B \subseteq A$；$A \cap B \subseteq B$

**2.** 下列各运算不正确的是（　　）

（A）$A \cap B = B \cap A$；（B）$A \cap A = A$；（C）$A \cap \varnothing = \varnothing$；（D）$A \cap \varnothing = A$。

> [!hint]- 答案
> 选（D）。$A \cap \varnothing = \varnothing$，而非 $A$。

**3.** 已知集合 $A = \{(x, y) \mid y = x + 3\}$，$B = \{(x, y) \mid y = 3x - 1\}$，求 $A \cap B$。

> [!hint]- 解答
> **解：** 解方程组 $\begin{cases} y = x + 3 \\ y = 3x - 1 \end{cases}$，得 $x = 2, y = 5$。
>
> 故 $A \cap B = \{(2, 5)\}$。

**4.** 已知集合 $A = \{x \mid -2 < x \leqslant 1\}$，$B = \{x \mid 0 < x \leqslant 3\}$，求 $A \cap B$，并在数轴上表示出来。

> [!hint]- 解答
> **解：** $A \cap B$ 取两集合的公共部分，即同时满足 $-2 < x \leqslant 1$ 和 $0 < x \leqslant 3$ 的 $x$。
>
> 故 $A \cap B = \{x \mid 0 < x \leqslant 1\}$。
>
> 在数轴上，$A \cap B$ 为从 $0$（空心）到 $1$（实心）的线段。

## 易错点

> [!warning]
> - **空集陷阱**：$A \cap \varnothing = \varnothing$ 恒成立，不是 $A$！注意区分 $A \cap \varnothing$ 和 $A \cup \varnothing$。
> - **元素类型混淆**：例1中的集合元素是**有序对** $(x, y)$，不是单个数。$A \cap B = \{(3, 4)\}$ 是一个含有一个有序对的集合，不能写成 $\{3, 4\}$。
> - **区间端点**：处理不等式描述的集合时，注意端点处的开闭（"<"与"≤"的区别）。
> - **交集方向**：当用数轴求交集时，交集取的是"重叠部分"（两个区间都覆盖的部分）。
