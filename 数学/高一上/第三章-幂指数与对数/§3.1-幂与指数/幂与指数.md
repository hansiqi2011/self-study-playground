# 幂与指数

## 指数幂的拓展路径

正整数 → 整数 → 有理数 → 实数

每一步拓展的原则：**保持三条运算性质不变。**

## 三条运算性质（对 $a, b > 0$，$s, t \in \mathbb{R}$）

1. $a^s \cdot a^t = a^{s+t}$（同底相乘，指数相加）
2. $(a^s)^t = a^{st}$（幂的幂，指数相乘）
3. $(ab)^t = a^t b^t$（积的幂，各取幂）

## 零指数和负整数指数

- $a^0 = 1$（$a \neq 0$）
- $a^{-n} = \frac{1}{a^n}$（$a \neq 0$）

## $n$ 次方根

$x^n = a$ 的解：
- $n$ 为奇数：唯一解 $x = \sqrt[n]{a}$
- $n$ 为偶数，$a > 0$：两个解 $x = \pm\sqrt[n]{a}$
- $n$ 为偶数，$a < 0$：无实数解
- $a = 0$：$x = 0$

**注意：**
- $n$ 为奇数：$\sqrt[n]{a^n} = a$
- $n$ 为偶数：$\sqrt[n]{a^n} = |a|$

## 有理数指数幂（$a > 0$）

$$a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$$

## 幂的基本不等式

$$a > 1, \; s > 0 \implies a^s > 1$$
$$0 < a < 1, \; s > 0 \implies 0 < a^s < 1$$

## 易错点

1. **偶次根号下必须非负**：$\sqrt[4]{-16}$ 无意义
2. **$\sqrt[n]{a^n}$ 偶数次要加绝对值**：$\sqrt[6]{(-8)^2} = \sqrt[6]{64} = 2$，不是 $-8$
3. **负底数不能取分数指数**：$(-8)^{\frac{1}{3}}$ 不定义为 $-2$（课本约定底数为正数）
4. **指数运算易混**：$a^s \cdot a^t$ 是加指数，$(a^s)^t$ 是乘指数
