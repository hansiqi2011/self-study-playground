# 对数

## 定义

$a > 0$，$a \neq 1$，$N > 0$ 时：

$$a^x = N \iff x = \log_a N$$

**对数是指数的逆运算。**

核心恒等式：$a^{\log_a N} = N$

## 基本值

- $\log_a 1 = 0$（因为 $a^0 = 1$）
- $\log_a a = 1$（因为 $a^1 = a$）

## 三条运算性质（$M, N > 0$）

| 性质 | 公式 | 口诀 |
|---|---|---|
| 性质1 | $\log_a(MN) = \log_a M + \log_a N$ | 乘变加 |
| 性质2 | $\log_a\frac{M}{N} = \log_a M - \log_a N$ | 除变减 |
| 性质3 | $\log_a N^c = c \log_a N$ | 指数提前 |

**本质：** 对数把乘除变加减，乘方变乘法。

## 换底公式

$$\log_b N = \frac{\log_a N}{\log_a b}$$

**推论：** $\log_b a = \frac{1}{\log_a b}$（互为倒数）

**推论：** $\log_{a^m} N^n = \frac{n}{m} \log_a N$

## 常用对数与自然对数

- $\lg N = \log_{10} N$（常用对数）
- $\ln N = \log_e N$（自然对数，$e \approx 2.71828$）

## 常见技巧

1. **统一底**：遇到不同底的对数，用换底公式统一
2. **凑真数**：$2\log_5 10 + \log_5 3 - \log_5 12 = \log_5 \frac{100 \times 3}{12} = \log_5 25 = 2$
3. **指对互化**：$a^{\log_a N} = N$ 可直接消去

## 易错点

1. **对数底和真数的条件**：$a > 0, a \neq 1, N > 0$（缺一不可）
2. **$\log_a(M+N) \neq \log_a M + \log_a N$**（加法不能拆！）
3. **$\log_a M^c$ 中 $c$ 可以是任意实数**，但 $M$ 必须为正
4. **换底时分子分母别写反**
