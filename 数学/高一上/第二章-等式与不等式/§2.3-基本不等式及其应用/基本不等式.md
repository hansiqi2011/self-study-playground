# 基本不等式

## 一、平均值不等式（AM-GM）

### 核心公式

对于正数 $a, b$：

$$\frac{a+b}{2} \geq \sqrt{ab}$$

等号当且仅当 $a = b$ 时成立。

**等价形式：**
- $a^2 + b^2 \geq 2ab$（对任意实数成立，证明：$(a-b)^2 \geq 0$）
- $\left(\frac{a+b}{2}\right)^2 \geq ab$（对任意实数成立）

### 经典变形

1. $x + \frac{1}{x} \geq 2$（$x > 0$），等号 $x = 1$
2. $\frac{b}{a} + \frac{a}{b} \geq 2$（$ab > 0$），等号 $a = b$

### 求最值的三个条件（一正二定三相等）

用 AM-GM 求最值必须同时满足：
1. **一正**：各项为正数
2. **二定**：和或积为定值
3. **三相等**：等号能取到（即 $a = b$ 时满足约束）

**积定和最小：** $ab = k$（定值）→ $a + b \geq 2\sqrt{k}$，等号 $a = b = \sqrt{k}$

**和定积最大：** $a + b = s$（定值）→ $ab \leq \left(\frac{s}{2}\right)^2$，等号 $a = b = \frac{s}{2}$

### 典型技巧

- **凑积为定值：** $a + 2b = 1$，求 $ab$ 最大 → $ab = \frac{1}{2}(a \cdot 2b) \leq \frac{1}{2}\left(\frac{a+2b}{2}\right)^2 = \frac{1}{8}$
- **凑和为定值：** $xy = k$（定值），求 $ax + by$ 最小

## 二、三角不等式

### 核心公式

对于任意实数 $a, b$：

$$|a + b| \leq |a| + |b|$$

等号当且仅当 $ab \geq 0$（同号或有零）时成立。

### 推论

$$|a| - |b| \leq |a - b|$$

即"绝对值之差 $\leq$ 差的绝对值"。

### 重要应用

$$|x - a| + |x - b| \geq |a - b|$$

等号条件：$x$ 在 $a$ 和 $b$ 之间（含端点）。

几何直觉：数轴上 $x$ 到 $a$ 和 $b$ 两点的距离之和，最小值就是 $a$ 和 $b$ 之间的距离。

## 易错点

1. **忘记检验等号条件**：求最值时必须验证等号能否取到
2. **对非正数用 AM-GM**：$a, b$ 必须为正才能用 $\frac{a+b}{2} \geq \sqrt{ab}$
3. **凑配时系数出错**：如把 $a + 2b$ 错误地直接用 AM-GM（应凑成 $a \cdot 2b$）
4. **三角不等式方向**：是 $\leq$ 不是 $\geq$
