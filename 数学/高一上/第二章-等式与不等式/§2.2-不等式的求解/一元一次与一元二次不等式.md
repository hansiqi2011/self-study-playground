# 一元一次与一元二次不等式

## 核心思路

**解不等式 = 通过等价变形，把复杂不等式化为简单不等式（组）。**

## 一元一次不等式

$ax < b$（$a \neq 0$）：
- $a > 0$：$x < \frac{b}{a}$
- $a < 0$：$x > \frac{b}{a}$（乘负翻号）
- $a = 0$：看 $b$ 的正负（$0 < b$ 恒成立 → $\mathbb{R}$；$0 < b$ 不成立 → $\varnothing$）

## 一元二次不等式（核心）

设 $a > 0$（若 $a < 0$，两边乘 $-1$ 翻号），方程 $ax^2+bx+c=0$ 的判别式 $\Delta = b^2-4ac$。

### 万能口诀表

| $\Delta$ | $ax^2+bx+c > 0$ | $ax^2+bx+c < 0$ |
|---|---|---|
| $\Delta > 0$，两根 $x_1 < x_2$ | $(-\infty, x_1) \cup (x_2, +\infty)$ | $(x_1, x_2)$ |
| $\Delta = 0$，重根 $x_0$ | $\mathbb{R} \setminus \{x_0\}$ | $\varnothing$ |
| $\Delta < 0$ | $\mathbb{R}$ | $\varnothing$ |

**口诀：** "$> 0$ 取两边，$< 0$ 取中间"（$\Delta > 0$ 时）。

### $\geq$ 和 $\leq$ 的区别

- $\geq 0$：在 $> 0$ 基础上并上根
- $\leq 0$：在 $< 0$ 基础上并上根
- 特别：$\Delta = 0$ 时，$\leq 0$ 解集为 $\{x_0\}$（仅取重根）

## 分式不等式

$$\frac{f(x)}{g(x)} > 0 \iff f(x) \cdot g(x) > 0$$

$$\frac{f(x)}{g(x)} \leq 0 \iff \begin{cases} f(x) \cdot g(x) \leq 0 \\ g(x) \neq 0 \end{cases}$$

**关键：** $\leq$ 或 $\geq$ 时必须排除分母为零的点！

## 含绝对值不等式

- $|x| < a$（$a > 0$）$\iff -a < x < a$
- $|x| > a$（$a > 0$）$\iff x > a$ 或 $x < -a$
- 复杂绝对值：**零点分段法**——找出绝对值内表达式为零的点，分段去绝对值

## 含参数不等式的套路

1. 先化为标准形式
2. 对参数分类讨论（$a > 0$、$a = 0$、$a < 0$）
3. 每种情况求解集

## 逆向问题（已知解集求参数）

已知 $ax^2+bx+c < 0$ 的解集为 $(p, q)$：
- $p, q$ 是方程 $ax^2+bx+c = 0$ 的两根
- 由韦达定理：$p+q = -\frac{b}{a}$，$pq = \frac{c}{a}$

## 易错点

1. **忘记翻号**：$a < 0$ 时两边乘 $-1$ 必须翻转不等号
2. **$\Delta \leq 0$ 的特殊解集**：$\leq 0$ 且 $\Delta = 0$ 时解集是单点 $\{x_0\}$，不是 $\varnothing$
3. **分式不等式漏排除分母零点**：$\leq$ 时端点要检验
4. **绝对值分段忘取并集**：各段解集最后要合并
