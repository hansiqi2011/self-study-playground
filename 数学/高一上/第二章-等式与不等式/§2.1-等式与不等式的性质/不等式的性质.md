# 不等式的性质

## 实数大小关系的定义

对于两个实数 $a$、$b$：

$$b > a \iff b - a > 0$$
$$b = a \iff b - a = 0$$
$$b < a \iff b - a < 0$$

**核心思想：** 比大小 = 看差的符号。这是研究一切不等式的基础。

## 三条基本性质

### 性质一：传递性

$$a > b \text{ 且 } b > c \implies a > c$$

**证明：** $(a-b) + (b-c) = a-c > 0$。

### 性质二：加法性质

$$a > b \implies a + c > b + c$$

- 两边加（减）同一个实数，不等号方向不变
- 推论（同向可加性）：$a > b, c > d \implies a+c > b+d$
- 移项法则：$a + b > c \iff a > c - b$

### 性质三：乘法性质

$$a > b, \; c > 0 \implies ac > bc$$
$$a > b, \; c < 0 \implies ac < bc$$

- 乘正数：方向不变
- **乘负数：方向翻转**（最容易出错的点！）

## 重要推论

### 倒数性质

$$a > b > 0 \implies \frac{1}{b} > \frac{1}{a} > 0$$

**证明：** $a > b > 0 \implies ab > 0$，两边同乘 $\frac{1}{ab}$。

### 乘法（同向可乘性）

$$a > b > 0, \; c > d > 0 \implies ac > bd$$

**注意：** 同向可乘性要求 **各项为正**。不像加法可以随意用。

### 乘方性质

$$a > b > 0 \implies a^n > b^n \quad (n \in \mathbb{Z}^+)$$

反过来：$a^n > b^n$（$a, b > 0$）$\implies a > b$（反证法证明）。

### 开方性质

$$a > b \geq 0 \implies \sqrt{a} > \sqrt{b}$$

## 比较大小的通用方法——作差法

比较 $A$ 与 $B$ 的大小：

1. 计算 $A - B$
2. 化简（因式分解、配方等）
3. 判断符号

**定理（均值不等式的雏形）：**

$$a^2 + b^2 \geq 2ab$$

等号当且仅当 $a = b$ 时成立。

**证明：** $a^2 + b^2 - 2ab = (a-b)^2 \geq 0$。

## 易错点

1. **乘除负数忘翻号**：$a > b$ 两边乘 $-1$ 后变 $-a < -b$
2. **同向可乘要求正数**：$a > b$, $c > d$ 不能直接推 $ac > bd$（需要各项为正）
3. **倒数要求同号**：$a > b$ 不能直接推 $\frac{1}{a} < \frac{1}{b}$（需知道 $a, b$ 同号且非零）
