# 土壤的形成与性质

## 一、土壤的概念

陆地表面由矿物质、有机质、水分和空气四种物质组成的、具有一定肥力的、能够生长植物的疏松表层。

## 二、土壤的组成

| 组成 | 来源 | 作用 |
|---|---|---|
| **矿物质**（约45%） | 成土母质（岩石风化物） | 土壤的"骨架"，提供矿物养分 |
| **有机质**（约5%） | 生物残体分解 | 土壤肥力的关键标志（越多越肥） |
| **水分**（约20-30%） | 降水、地下水 | 供植物吸收，溶解养分 |
| **空气**（约20-30%） | 大气 | 根系呼吸需要 |

> 🔑 **有机质含量是衡量土壤肥力的重要标志**。有机质多→颜色深（黑色）→肥沃。

## 三、土壤的质地

按矿物颗粒大小分：

| 质地 | 颗粒 | 特点 | 农业适宜性 |
|---|---|---|---|
| **砂土** | 砂粒为主 | 通气透水好，保水保肥差 | 易耕作，但贫瘠 |
| **黏土** | 黏粒为主 | 保水保肥好，通气透水差 | 质地黏重，不易耕作 |
| **壤土** | 砂粒黏粒比例适中 | 兼有砂土和黏土的优点 | ⭐ **最理想的农业土壤** |

## 四、土壤剖面构造

### 自然土壤剖面（森林土壤）

从上到下：

| 层次 | 特征 |
|---|---|
| **有机层** | 枯枝落叶和半分解有机物 |
| **腐殖质层** | 有机质积累，颜色深（灰黑色） |
| **淋溶层** | 矿物质随水向下淋失，颜色较浅 |
| **淀积层** | 上层淋失物质在此沉淀积累，质地黏重，呈棕/红色 |
| **母质层** | 疏松的风化碎屑物质 |
| **母岩层** | 坚硬的未风化岩石 |

### 耕作土壤剖面

| 层次 | 特征 |
|---|---|
| **耕作层**（表土层/熟土层） | 疏松、有机质多、颜色较暗 |
| **犁底层**（亚表土层） | 紧实、颜色较浅，有保肥保水作用 |
| **自然土层** | 未经耕作熟化 |

## 五、土壤的形成因素

| 因素 | 作用 |
|---|---|
| **成土母质** | 岩石风化产物，决定土壤矿物质成分和质地（物质基础） |
| **生物** | ⭐ **最活跃的因素**——提供有机质，没有生物就没有土壤 |
| **气候** | 控制土壤形成速度和方向；湿热→形成快；冷干→形成慢 |
| **地貌** | 影响水热条件（山顶vs山麓）；影响颗粒分选（山顶粗、山前细） |
| **时间** | 越长→土层越厚、分化越明显；形成20cm可耕土约需100~1000年 |
| **人类活动** | 耕作、施肥可改良土壤；过度开垦可退化土壤 |

> 🔑 **生物是最活跃的因素**——必考填空。

## 六、土壤的功能与养护

### 功能

- 为植物生长提供扎根条件和养分
- 联系有机界和无机界的关键环节
- 是许多微生物和小动物的栖息地

### 养护

| 问题 | 对策 |
|---|---|
| 水土流失 | 植树造林、梯田 |
| 土壤盐碱化 | 合理灌溉、排水 |
| 土壤板结 | 增施有机肥、合理耕作 |
| 土壤污染 | 减少农药化肥使用 |

---

## 易错点

1. **生物是土壤形成最活跃的因素**——不是气候，不是母质
2. **壤土最适合农业**——不是砂土也不是黏土
3. **有机质含量 = 肥力标志**——颜色越深通常有机质越多
4. **形成20cm土壤需100~1000年**——土壤是不可再生资源（时间尺度上）
