# 热力环流

## 一、概念

由于地面**冷热不均**而形成的空气环流，是大气运动**最简单**的形式。

## 二、形成过程

### 逻辑链（必须能自己推出来）

```
地面冷热不均
    ↓
热处空气膨胀上升，冷处空气收缩下沉（垂直运动）
    ↓
热处近地面空气减少→形成低气压
冷处近地面空气堆积→形成高气压
    ↓
同一水平面上出现气压差
    ↓
空气从高压流向低压（水平运动=风）
    ↓
形成闭合环流
```

### 图示

```
        高空：高压 ←←← 低压
          ↓                ↑
近地面：低温(高压) →→→ 高温(低压)
         冷处              热处
```

## 三、关键规律

| 规律 | 说明 |
|---|---|
| **热升冷降** | 受热的地方空气上升，冷却的地方空气下沉 |
| **近地面：热低压，冷高压** | 受热→空气上升→近地面气压降低 |
| **高空与近地面气压相反** | 近地面低压的上空为高压（空气堆积） |
| **风从高压吹向低压** | 同一水平面上，空气总是从高压区流向低压区 |

> 🔑 **核心口诀**：热升冷降，近地面热低冷高，高空反过来。

## 四、典型案例

### 1. 海陆风

| | 白天 | 夜晚 |
|---|---|---|
| 谁热？ | 陆地（升温快） | 海洋（降温慢） |
| 谁升？ | 陆地上空气上升 | 海洋上空气上升 |
| 近地面风向 | **海 → 陆**（海风） | **陆 → 海**（陆风） |

原因：陆地比热容小，升温和降温都比海洋快。

### 2. 山谷风

| | 白天 | 夜晚 |
|---|---|---|
| 谁热？ | 山坡（受热升温快） | 谷底（山坡散热快，冷空气下滑） |
| 近地面风向 | **谷 → 山**（谷风） | **山 → 谷**（山风） |

### 3. 城市热岛环流

- 城市中心：建筑密集、人为排热多 → 气温高于郊区（热岛）
- 结果：城市中心空气上升 → 近地面风从**郊区吹向城市**
- 城市规划启示：有污染的工厂不能放在热岛环流范围内的郊区（否则污染物会被吹向市区）

## 五、等压面的弯曲

- 受热处：近地面等压面**下凹**（低压），高空等压面**上凸**（高压）
- 冷却处：近地面等压面**上凸**（高压），高空等压面**下凹**（低压）

> 记忆：等压面总是**向高压方向凸出**。

---

## 易错点

1. **近地面热→低压**（不是高压！）——很多人搞反。热→空气上升→密度减小→气压降低
2. **高空气压与近地面相反**——近地面是低压的地方，上空反而是高压
3. **风是水平运动**——热力环流中垂直运动是成因，水平运动才是"风"
4. **海陆风白天吹海风（从海到陆）**——不是从陆到海
