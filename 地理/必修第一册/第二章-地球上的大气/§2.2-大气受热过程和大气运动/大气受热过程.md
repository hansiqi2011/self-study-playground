# 大气受热过程

## 一、三种辐射的区分

| | 太阳辐射 | 地面辐射 | 大气辐射（含逆辐射） |
|---|---|---|---|
| 发射体 | 太阳（6000K） | 地面 | 大气 |
| 波长类型 | **短波**（主要是可见光） | **长波**（红外线） | **长波**（红外线） |
| 方向 | 太阳→地球 | 地面→大气/太空 | 向上+向下（向下的叫**大气逆辐射**） |

> 🔑 温度越高，辐射波长越短。太阳6000K→短波；地面和大气几百K→长波。

## 二、大气对太阳辐射的削弱作用

太阳辐射穿过大气层时，被削弱了一部分：

| 削弱方式 | 含义 | 举例 |
|---|---|---|
| **吸收** | 大气中某些成分选择性吸收特定波段 | O₃吸收紫外线；CO₂、水汽吸收红外线 |
| **反射** | 云层、尘埃将太阳光反射回太空 | 厚云层反射率可达 70%+ |
| **散射** | 空气分子和微粒将光向四面八方散射 | 天空呈蓝色（蓝光波短易被散射） |

> 注意：大气对太阳辐射中的**可见光**吸收很少——所以太阳光能"穿透"大气到达地面。

## 三、大气受热过程——核心链条

$$\boxed{\text{太阳暖大地，大地暖大气，大气还大地}}$$

### 详细过程

```
Step 1: 太阳短波辐射 → 大部分穿过大气 → 到达地面 → 地面吸收升温
Step 2: 地面升温后发出长波辐射 → 被大气中CO₂和水汽吸收 → 大气升温
Step 3: 大气升温后向各方向辐射 → 其中向下的部分 = 大气逆辐射 → 补偿地面热量损失 → 保温
```

### 三步的功能

| 步骤 | 功能 |
|---|---|
| 太阳辐射→地面 | **加热地面**（太阳暖大地） |
| 地面辐射→大气 | **加热大气**（大地暖大气） |
| 大气逆辐射→地面 | **保温**（大气还大地） |

## 四、大气的保温作用（温室效应）

- 大气逆辐射把部分热量归还地面 → 使地面实际散失的热量减少
- 地面温度比没有大气时高了约 33°C（无大气 → -18°C；有大气 → +15°C）
- CO₂ 和水汽是主要的温室气体（吸收长波辐射的能力强）

### 影响大气保温强弱的因素

| 因素 | 保温效果 |
|---|---|
| 大气层厚（低海拔） | 强 |
| CO₂、水汽含量高 | 强 |
| 云量多（夜间） | 强（云层增强大气逆辐射） |
| 大气稀薄（高海拔） | 弱 |

## 五、应用举例

| 现象 | 解释 |
|---|---|
| 晴天昼夜温差大 | 白天：无云→大气削弱少→日温高；夜晚：无云→逆辐射弱→散热快→夜温低 |
| 阴天昼夜温差小 | 白天：云反射→日温偏低；夜晚：云增强逆辐射→夜温偏高 |
| 青藏高原白天太阳辐射强但年均温低 | 大气稀薄→吸收地面辐射少→逆辐射弱→保温差 |
| 温室大棚 | 玻璃/薄膜允许短波进入但阻挡长波辐射出去→类似大气保温 |

---

## 易错点

1. **大气直接吸收太阳辐射很少**——太阳短波中的可见光部分大气几乎不吸收
2. **大气增温主要靠地面长波辐射**，不是靠太阳直接加热
3. **大气逆辐射 ≠ 大气辐射**：大气辐射包括向上和向下两部分，向下的才叫逆辐射
4. **"吸收"≠"反射"**：CO₂吸收长波辐射（energy absorbed），不是反射
