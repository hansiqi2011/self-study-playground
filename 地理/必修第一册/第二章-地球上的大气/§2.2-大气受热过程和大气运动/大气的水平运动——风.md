# 大气的水平运动——风

## 一、风的形成

### 直接原因

**水平气压梯度力**——同一水平面上存在气压差异时，空气从高压区向低压区运动。

> 气压梯度 = 单位距离上的气压差。等压线越密集，气压梯度越大，风力越大。

### 水平气压梯度力的特征

- 方向：**垂直于等压线**，由高压指向低压
- 大小：等压线越密→梯度力越大→风力越强

## 二、影响风的三个力

| 力 | 方向 | 对风的影响 | 存在条件 |
|---|---|---|---|
| **水平气压梯度力** | 垂直等压线，高压→低压 | 风的**直接原因**，决定风速大小和初始方向 | 始终存在 |
| **地转偏向力** | 垂直于风向（北半球向右，南半球向左） | 只**改变风向**，不改变风速 | 地球自转产生 |
| **摩擦力** | 与风向**相反** | 既减小风速，又改变风向 | 近地面存在 |

## 三、三种情景下的风向

### 情景1：只有气压梯度力（理想状态）

- 风向**垂直于等压线**，从高压直吹低压
- 现实中不存在（地球在转）

### 情景2：气压梯度力 + 地转偏向力（高空风）

- 高空摩擦力可忽略
- 地转偏向力逐渐使风向偏转
- 最终平衡时：风向**平行于等压线**
- 北半球高空风：背风而立，高压在右，低压在左

### 情景3：气压梯度力 + 地转偏向力 + 摩擦力（近地面风）

- 摩擦力使风速减小→地转偏向力也减弱→无法完全偏转到平行等压线
- 结果：风向**与等压线斜交**（夹角通常 30°~45°）
- 北半球近地面：风向向右偏，斜穿等压线指向低压

## 四、风向判断方法（北半球近地面）

1. 画出**水平气压梯度力**方向（垂直等压线，高压→低压）
2. 将此方向**向右偏转** 30°~45°
3. 所得方向即为风向

> 南半球向左偏。

## 五、风力（风速）判断

- 等压线**越密集** → 气压梯度力越大 → 风力越大
- 等压线**越稀疏** → 气压梯度力越小 → 风力越小

## 六、高空风与近地面风对比

| | 高空风 | 近地面风 |
|---|---|---|
| 受力 | 气压梯度力 + 地转偏向力 | 气压梯度力 + 地转偏向力 + 摩擦力 |
| 风向与等压线关系 | **平行** | **斜交** |
| 风速 | 较大（无摩擦力阻碍） | 较小 |

---

## 易错点

1. **地转偏向力只改变风向，不改变风速**——它永远垂直于运动方向
2. **近地面风斜穿等压线**（不是平行！）——平行是高空风的特征
3. **北半球右偏，南半球左偏**——"南左北右"
4. **等压线密=风大**——这是最基础的读图技能
5. **水平气压梯度力是风的直接原因**——不是地转偏向力或摩擦力
