# 地球的演化历程

## 一、前寒武纪（46亿年前—5.41亿年前）

| 时期 | 大气/环境 | 生物 | 矿产 |
|---|---|---|---|
| 冥古宙 | 大气主要成分：CO₂、CO、甲烷、氮，缺少O₂ | 只有一些有机质，无生命迹象 | — |
| 太古宙 | 开始有氧气 | 出现**蓝细菌**（原核生物），能光合作用制造O₂ | 铁矿 |
| 元古宙 | 蓝细菌大爆发，O₂增多，大气成分改变 | 演化出**真核生物**和**多细胞生物** | 铁、金、镍、铬 |

> 💡 前寒武纪是重要的**成矿时期**——大量铁、金、镍、铬等矿藏出现在这一时期的地层中。

## 二、古生代（5.41亿年前—2.52亿年前）

分为**早古生代**（寒武纪、奥陶纪、志留纪）和**晚古生代**（泥盆纪、石炭纪、二叠纪）。

### 早古生代

| 要素 | 特征 |
|---|---|
| 海陆格局 | 海洋面积远大于现在 |
| 动物 | 海洋无脊椎动物空前繁盛（三叶虫、笔石、鹦鹉螺） |
| 植物 | 后期陆地上开始出现低等植物 |
| 标志 | **海洋无脊椎动物时代** |

### 晚古生代

| 要素 | 特征 |
|---|---|
| 海陆格局 | 海洋面积缩小，各大陆汇聚成**联合古陆（泛大陆）** |
| 动物 | 鱼类大量繁衍→两栖类出现→爬行动物开始出现 |
| 植物 | 蕨类植物繁盛，形成茂密森林 |
| 矿产 | 重要的**成煤期** |
| 结束标志 | 古生代末期发生**地球史上最大的物种灭绝事件**（~95%物种消失） |

## 三、中生代（2.52亿年前—6600万年前）

分为三叠纪、侏罗纪、白垩纪。

| 要素 | 特征 |
|---|---|
| 海陆格局 | 联合古陆在三叠纪晚期**开始解体**，各大陆向现在的位置漂移 |
| 动物 | **爬行动物盛行**（恐龙），被称为"爬行动物的时代"；鸟类出现；小型哺乳动物出现 |
| 植物 | **裸子植物**极度兴盛，占陆地植物主导地位 |
| 矿产 | 重要的**成煤期** |
| 结束标志 | 中生代末期**物种大灭绝**（恐龙灭绝，~75%物种消失） |

> 1996年辽宁发现的**中华龙鸟**化石是第一个被发现的带羽毛恐龙化石，为鸟类起源于恐龙提供了重要证据。

## 四、新生代（6600万年前—至今）

分为古近纪、新近纪、第四纪。

| 要素 | 特征 |
|---|---|
| 海陆格局 | 联合古陆**最终解体**，各大陆漂移到现在的位置；形成现代海陆分布格局 |
| 地壳运动 | 剧烈，形成现代地势起伏的基本面貌（阿尔卑斯山脉、喜马拉雅山脉、落基山脉、安第斯山脉） |
| 动物 | **哺乳动物**快速发展；第四纪出现**人类** |
| 植物 | **被子植物**高度繁盛，草原面积扩大 |
| 标志 | 生物界逐渐呈现现代面貌 |

## 五、演化总趋势

### 生物演化趋势

$$\text{低级} \to \text{高级} \quad\quad \text{简单} \to \text{复杂} \quad\quad \text{水生} \to \text{陆生}$$

### 各代主导生物对照

| 时代 | 动物代表 | 植物代表 |
|---|---|---|
| 古生代早期 | 海洋无脊椎动物 | 低等植物 |
| 古生代晚期 | 鱼类→两栖类 | 蕨类植物 |
| 中生代 | 爬行动物（恐龙） | 裸子植物 |
| 新生代 | 哺乳动物→人类 | 被子植物 |

### 两次大灭绝

| | 古生代末期 | 中生代末期 |
|---|---|---|
| 灭绝比例 | ~95% | ~75% |
| 标志性事件 | 海洋生物大灭绝 | 恐龙灭绝 |

---

## 易错点

1. **成煤期有两个**：古生代晚期（蕨类）和中生代（裸子植物）——不要只记一个
2. **联合古陆的形成和解体**：形成在古生代后期，解体始于中生代（三叠纪晚期），完成于新生代
3. **"爬行动物时代"是中生代**，不是古生代——古生代晚期只是爬行动物"开始出现"
4. **被子植物繁盛在新生代**，裸子植物繁盛在中生代——这两个容易搞混
