# 地质灾害

## 一、地震

### 基本概念

| 术语 | 含义 |
|---|---|
| **震源** | 地球内部岩层断裂释放能量的位置 |
| **震中** | 震源正上方的地面点 |
| **震源深度** | 震源到地面的垂直距离 |
| **震中距** | 地面上某点到震中的距离 |
| **等震线** | 破坏程度相同的各点连线 |

### 震级与烈度

| | 震级 | 烈度 |
|---|---|---|
| 含义 | 地震释放能量的大小 | 地面受到的破坏程度 |
| 数量 | 一次地震只有**一个**震级 | 一次地震有**多个**烈度 |
| 影响因素 | — | 震级、震源深度、距震中远近、地质条件、建筑质量 |

> 🔑 **一次地震一个震级，多个烈度**。

### 地震分布

- 世界两大地震带：**环太平洋地震带**、**地中海-喜马拉雅地震带**
- 中国地震多发区：台湾、西藏、新疆、青海、云南、四川
- 原因：位于板块交界处，地壳活跃

### 地震的危害

- 直接：房屋倒塌、基础设施破坏、人员伤亡
- 次生：滑坡、泥石流、火灾、海啸、瘟疫

### 防御措施

- 加强地震监测预报
- 建筑物抗震设防
- 制定应急预案
- 地震发生时：室内躲在坚固物下，室外远离高楼和电线

## 二、滑坡

| 要素 | 内容 |
|---|---|
| **定义** | 山地斜坡上的岩体或土体沿滑动面整体下滑 |
| **条件** | 岩体破碎、地势起伏大、植被覆盖差、有人工切坡 |
| **触发因素** | 暴雨、地震、河流冲刷、人工开挖 |
| **危害** | 掩埋农田、道路、建筑物；堵塞河道 |
| **多发区** | 山地丘陵区；我国西南地区最多 |

## 三、泥石流

| 要素 | 内容 |
|---|---|
| **定义** | 山区沟谷中，由暴雨或冰雪消融激发的、含有大量泥沙石块的特殊洪流 |
| **三大条件** | ① 地形陡峻 ② 有丰富的松散碎屑物 ③ 短时间内有大量水流 |
| **危害** | 冲毁聚落、道路、森林、淤塞河道 |
| **多发区** | 我国西南山区最为多发 |

## 四、三者之间的关联（链式灾害）

```
地震 → 山体松动 → 暴雨触发 → 滑坡/泥石流
```

地质灾害往往具有**关联性**（一种灾害可以引发另一种）：
- 地震 → 引发滑坡、泥石流
- 暴雨 → 引发滑坡、泥石流
- 滑坡 → 堵塞河道 → 堰塞湖溃决 → 洪水

---

## 易错点

1. **震级只有一个，烈度有多个**——这是必考辨析
2. **中国西南地区是滑坡和泥石流的高发区**——地形陡峻+降水多+地震活跃
3. **地质灾害具有关联性**——地震→滑坡→泥石流→堰塞湖→洪水，链式反应
4. **泥石流三条件：陡、碎、水**——缺一不可
