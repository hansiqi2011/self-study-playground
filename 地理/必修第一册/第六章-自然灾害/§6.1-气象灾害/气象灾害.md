# 气象灾害

## 一、概念

大气对人类的生命财产和经济建设以及国防建设等造成的直接或间接的损害，称为气象灾害。主要包括**洪涝、干旱、台风、寒潮**等。

## 二、四种主要气象灾害

### 1. 洪涝灾害

| 要素 | 内容 |
|---|---|
| **成因** | 连续暴雨或短时强降水→河水暴涨→淹没低地 |
| **多发地区** | 地势低洼、河流中下游；我国东部季风区（长江中下游等） |
| **多发季节** | 夏秋季（降水集中） |
| **危害** | 淹没农田、毁坏建筑、人员伤亡、瘟疫 |
| **防御** | 修建水库和堤坝、疏浚河道、退耕还湖、预警转移 |

### 2. 干旱灾害

| 要素 | 内容 |
|---|---|
| **成因** | 长时间降水偏少或无降水→水分严重不足 |
| **特点** | 渐发性（不像洪涝突然发生）、持续时间长、影响范围广 |
| **多发地区** | 我国华北地区（春旱）、西北地区（常年干旱） |
| **危害** | 农业减产/绝收、水资源短缺、生态退化 |
| **防御** | 兴修水利、发展节水农业、跨流域调水、人工增雨 |

> 🔑 干旱是中国**影响范围最广**的气象灾害。

### 3. 台风（热带气旋）

| 要素 | 内容 |
|---|---|
| **成因** | 热带或副热带洋面上的强烈发展的气旋（低压系统） |
| **结构** | 台风眼（无风无雨）→旋涡风雨区（最猛烈）→外围大风区 |
| **多发地区** | 西北太平洋最多；我国东南沿海 |
| **多发季节** | 夏秋季（7-10月） |
| **危害** | 狂风、暴雨、风暴潮 |
| **防御** | 加强监测预警、加固建筑、船只进港避风 |
| **有利影响** | 带来充沛降水缓解旱情、调节热量平衡 |

> 🔑 台风有**利有弊**——这是常考辩证题。

### 4. 寒潮

| 要素 | 内容 |
|---|---|
| **定义** | 强冷空气迅速入侵，24h内气温下降≥8°C，且最低气温≤4°C |
| **源地** | 蒙古-西伯利亚地区（冬半年高压中心） |
| **多发季节** | 深秋到初春（冬半年） |
| **危害** | 剧烈降温→冻害；大风、暴雪、冰冻→交通瘫痪、电线倒塌 |
| **影响范围** | 除青藏高原、云贵高原以外的中国大部分地区 |
| **防御** | 提前预警、农作物防寒、牲畜入棚 |

> 🔑 **青藏高原和云贵高原受寒潮影响较小**——地势高，冷空气难以翻越（常考）。

---

## 易错点

1. **干旱是影响范围最广的气象灾害**——不是洪涝，不是台风
2. **台风有有利影响**（带来降水缓解旱情）——辩证看待
3. **寒潮的标准是"24h降温≥8°C且最低≤4°C"**——不是简单的"冷就算寒潮"
4. **台风眼无风无雨**——最危险的是"旋涡风雨区"
