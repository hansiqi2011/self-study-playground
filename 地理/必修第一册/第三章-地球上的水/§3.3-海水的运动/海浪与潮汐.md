# 海浪与潮汐

## 一、海水运动的三种基本形式

| 形式 | 运动特征 | 成因 |
|---|---|---|
| **海浪** | 波状起伏 | 风力（最常见）、地震、火山 |
| **潮汐** | 周期性涨落 | 月球和太阳的**引潮力** |
| **洋流** | 大规模定向流动 | 盛行风、密度差、地形等 |

## 二、海浪

### 概念

海水的波状起伏运动。用**波峰、波谷、波高、波长**来描述。

### 成因

| 类型 | 成因 | 特点 |
|---|---|---|
| **风浪** | 风力作用 | 最常见，风越大浪越高 |
| 海啸 | 海底地震或火山喷发 | 能量巨大，破坏力极强 |
| 风暴潮 | 台风/强风暴引起 | 沿海地区水位暴涨 |

### 对人类活动的影响

| 方面 | 影响 |
|---|---|
| 航海 | 大浪威胁船舶安全 |
| 海岸工程 | 需要防浪堤抵御海浪侵蚀 |
| 冲浪/旅游 | 适当海浪是冲浪运动的条件 |
| 波浪能 | 可利用海浪发电 |

## 三、潮汐

### 概念

海水在**月球和太阳引潮力**作用下产生的周期性涨落现象。

- **潮**：白天的海水涨落
- **汐**：夜晚的海水涨落

### 规律

| 特征 | 说明 |
|---|---|
| 周期 | 一天两次涨潮、两次落潮（约每12小时25分钟一次） |
| **大潮** | 农历初一、十五前后（日、月、地大致在一条线上，引潮力叠加） |
| **小潮** | 农历初八、二十三前后（日、月引潮力相互抵消部分） |

> 🔑 **初一十五大潮，初八二十三小潮**

### 钱塘江大潮

- 时间：农历八月十八前后（中秋节后）
- 原因：
  1. 天文大潮（引潮力大）
  2. 河口呈**喇叭形**（外宽内窄），潮水涌入后被挤压抬高
  3. 东南风助推（风和潮水方向一致）

### 潮汐对人类活动的影响

| 方面 | 影响 |
|---|---|
| 航运 | 涨潮时水深利于大船进出港口 |
| 赶海/滩涂养殖 | 利用潮汐规律安排作业时间 |
| 潮汐发电 | 利用潮涨潮落的水位差发电 |
| 军事 | 诺曼底登陆选择潮汐配合时机 |

---

## 易错点

1. **潮汐的成因是引潮力（月球+太阳引力）**，不是风力——风力产生的是海浪
2. **大潮在初一和十五**（朔望日），不是初八——初八是小潮
3. **海啸不是潮汐**——海啸是海底地震引起的，和月球无关
