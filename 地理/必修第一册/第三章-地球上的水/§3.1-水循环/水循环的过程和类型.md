# 水循环的过程和类型

## 一、水循环的概念

自然界的水在水圈、大气圈、岩石圈和生物圈中，通过**蒸发（蒸腾）、水汽输送、降水、下渗、径流**等环节不断运动、转化，形成周而复始的运动过程。

## 二、水循环的环节

| 环节 | 含义 |
|---|---|
| **蒸发/蒸腾** | 水从液态变为气态进入大气（海面蒸发量最大；植物蒸腾也参与） |
| **水汽输送** | 大气环流将水汽从一个地方输送到另一个地方（如从海洋上空吹向陆地） |
| **降水** | 水汽凝结后以雨、雪等形式降落到地面或海面 |
| **下渗** | 地表水渗入地下，补给地下水 |
| **地表径流** | 水沿地表流动（河流、溪流） |
| **地下径流** | 水在地下岩层中流动 |

## 三、水循环的三种类型

| 类型 | 路径 | 涉及环节 | 水量 |
|---|---|---|---|
| **海陆间循环** | 海洋 ↔ 陆地 | 蒸发→水汽输送→降水→径流（全部环节） | 最重要，使陆地水得到补充 |
| **陆地内循环** | 陆地 ↔ 陆地上空 | 蒸发/蒸腾→降水 | 水量小，补给有限 |
| **海上内循环** | 海洋 ↔ 海洋上空 | 蒸发→降水 | 水量最大（但水还是落回海里） |

> 🔑 **海陆间循环最重要**——它是陆地获得淡水资源的根本途径。

## 四、水循环的意义

| 意义 | 说明 |
|---|---|
| 维持全球水量动态平衡 | 各水体之间相互转化，总量基本不变 |
| 更新陆地淡水资源 | 海水蒸发→降到陆地→河流流回海洋，淡水不断更新 |
| 物质迁移和能量转换 | 水流侵蚀、搬运泥沙改造地表；蒸发吸热、凝结放热调节气温 |
| 联系四大圈层 | 水循环是岩石圈-大气圈-水圈-生物圈的纽带 |

## 五、人类活动对水循环的影响

| 人类活动 | 影响的环节 |
|---|---|
| 修建水库 | 改变地表径流的时间分配（削峰补枯） |
| 跨流域调水 | 改变地表径流的空间分配 |
| 植树造林 | 增加下渗，减少地表径流，增加蒸腾 |
| 铺设不透水地面（城市化） | 减少下渗，增加地表径流 |
| 人工降雨 | 影响降水环节 |

> ⚠️ 人类**无法影响**蒸发和水汽输送这两个大尺度环节（至少目前无法大规模干预）

---

## 易错点

1. **海上内循环水量最大**，但对陆地无意义——别把"水量最大"和"最重要"搞混
2. **海陆间循环才是"最重要"的**——因为它给陆地送来了淡水
3. **人类能影响的主要是地表径流和下渗**——不能大规模影响蒸发和水汽输送
